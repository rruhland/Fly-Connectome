# Moving an experienced arm along the table edge

On 32 preassigned full points, moving the same clamp 12 cm right and carrying its motor memory in joint-and-base coordinates produced one legal, answered low-central return in normal play. It was the fifth return of a seven-return point, at x = −71.8 mm, with a projected deep-line height of 0.991 m. Independent action replay reproduced all seven own returns, eight opponent returns and continuously sampled placements in a single launch. The 6,107 native CAD states had at least 15.8 mm clearance. Each learner saw two exterior RGB cameras and encoders and used a calibrated private plant. All three started with the same 48-game motor memory and learned as they played. The moved actors used the measured new home and corresponding body in their private dynamics. Re-registering queries, temporal predictions and newly earned motor fragments recovered 59 of the 106 returns lost immediately after moving. One new rare skill does not establish superior whole-game play. The three arms changed what they sent back, so the shots in the denominators can differ.
