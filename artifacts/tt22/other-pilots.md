# Receiving policies that failed to extend rallies consistently

A ranker trained from actual legal credit for proposed strokes lengthened a five-start development set from 2, 4, 0, 4, 6 to 2, 4, 0, 6, 12. The same ranker then reduced the frequency of ten-return rallies from two to one across twelve wider held starts with the learned five-axis partner. A spin and velocity correction fitted against previous observed outgoing shots reached 2, 4, 0, 4, 9 on the development set. [Stroke success ranker](point-feedback-pilot.json.gz) · [Five-axis comparison](paired-course.json.gz) · [Optical calibration](identification-pilot.json.gz)

Retrieving motor recipes from prior scored optical shots while omitting candidate collision simulation yielded one two-return exchange in ten starts. A random recipe control yielded two. A short sequence imitator that retrieved joint targets from raw visual features made seven legal near-arm returns in eight starts. Its blind version made nine on those same starts. A 12-proposal physics search using successful motor recipes reached 4, 4, 4, 2, 10 alternating returns in five points. A random library of equal size reached 8, 4, 6, 7, 6. None of these comparisons justifies promoting the prior recipe library as the default motor policy.
