# Does Pong rank the motor options that work on the arm?

Freeze all sixteen signed spatial preferences from the native Pong duration experiment. The arm uses the same target-trained clock stroke and anonymous motion tracker for every preference. Evaluate every option on each of the 48 already designated practice-source openings, then on 64 new balanced openings (32 per generator, seed 178329541). Include every start including failed sightings. The first 48 target openings may be used as bandit practice; none of the 64 evaluation starts may be used for fitting.

Report the rank of the Pong-selected winner and the association between all sixteen native mean episode durations and held physical first-return rates. Compare the selected winner with the average unselected option, and replay the neutral control. Report paired differences across serves, keeping all sixteen policies on the same held start together. Shuffle labels across the entire population for the rank-correlation control.

For learning speed, each target learner observes only the actual legal-return outcome for the single option it chose per serve. Compare a uniform Beta prior with a graded weak prior from the rank of native duration, also with that prior assigned to permuted option IDs. Give all of them the same 48 real starts in the same order and the same per-option exploration uniforms. At 0, 4, 8, 16, 32 and 48 personal practice opportunities, freeze the greedy policy and score on the independent set. Average over paired orders and exploration seeds; reuse of physical outcomes gives no new independent test starts. This is a one-stroke sample-efficiency test; later stroke control is a separate problem.
