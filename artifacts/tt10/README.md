# Transfer between table tennis and 3D reaching

A motor map learned in simulated table tennis let the arm reach 36 of 42 first targets in a new cursor game, compared with 4 from an empty map under the same procedure. Two short sessions in the cursor game also taught an actuator timing correction that won two full table-tennis games on one arm installation and lost points on a second. This is evidence for useful transfer of body knowledge in both directions. Selecting which experience to reuse across installations remains open. [Forward transfer and rewiring](target-transfer.md) · [Return to table tennis](target-return.md)

|---|---|
| Cursor-trained timing | A turned 8–11 and 3–11 into 11–9 and 12–10. B lost points twice. [Scores, commands and checkpoints](target-return.md) |
| Cursor-trained geometry activated after the opponent hit | First legal follow-ups rose from 5/12 to 7/12 on identical replies. The full-game effect was smaller. [Gated comparison](cursor-reply.md) |

| Sideways serve placement | The opponent physically moved. On held throws, adapting placement won 7 points versus 13 for the registered serve. [Placement study](strategy.md) |
| Five consecutive games per arm | Carrying learning between games and restarting between games each earned 74 points and sustained 34 rallies across ten fixtures. Both players continued learning within games. [Series and resumable checkpoints](series.md) |
