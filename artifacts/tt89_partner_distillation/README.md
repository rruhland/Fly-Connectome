# Can the arm use the partner forecast before it actually hits?

A private opponent faced 256 previously scored physical departures, each with eight independent continuously drawn target placements. Each simulated reply trained a local prediction of the next ball’s returnability. At decision time the student saw only the candidate’s estimated outgoing movement, current observed ball location and estimated contact delay. None of the actual departure, spin, opponent target or future reply entered that ranking. [Training releases and draws](protocol.json) · [Readout](policy.npz)

The ranking did not improve choices on the independent physical paired-stroke test. Of 17 held releases, 16 had causal candidate descriptors for both previously scored actions. Relative to the established rule, choosing with the student predicted a change of +0.5 percentage points in the chance of the next actual return. The release bootstrap interval ran from −6.8 to +6.3 points. On the 30 eligible development releases it lost 6.7 points. We kept the established action ranking. Watching an achieved outgoing ball remains more informative than guessing its effect before the arm has struck it.
