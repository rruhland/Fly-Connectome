# From a better motor model to a better second return

**An arm can learn how coupled controls move its tool during ordinary points.** On fresh action sequences, the learned correction roughly halved prediction error on both simulated arms. The gantry won its first changed-controls game 11–4, compared with 4–11 for the original controller. On an independent wiring it lost 6–11, compared with 4–11 for the original and 6–11 for a new local fit. The five-axis arm lost its first coupling game 3–11, then won 11–8 when the original controls returned. [Watch the 11–4 game](gain-gantry-coupling.mp4) · [All motor conditions and fixtures](gain.md)

| Question | Result |
| --- | --- |
| What happened under reduced motor gain alone? | While gain was reduced in the first games, the gantry and five-axis players landed 11 and 10 legal returns respectively. Both fixed controls landed zero. The adaptive players still lost those games 9–11 and 4–11. |
| Does the motor correction predict unseen physical motion? | Mean error in predicting the coupling-induced displacement fell from 54 to 28 mm on the gantry and 78 to 33 mm on five-axis across 24 fresh command sequences each. |
| Did changing the stroke improve six-joint rotary rallies? | The camera-trained speed and loft changes improved scores on the first two games but produced zero second returns there. Bringing the arm back toward neutral between strokes produced a six-return rally on a fresh held serve. The matched original stroke landed one return. Across the repeated held cohort, all five additional later returns occurred on that one rally. The rotary arm still lost every complete game. |
| Does motor knowledge carry into a genuinely different task? | On a hidden-source search with coupled five-axis controls, the table-tennis maps found 11/12 sources versus 8/12 for learning from scratch. On the coupled gantry, adapted and fresh players both found 11/12. On the earlier signed wirings, equal initial probes favored learning the map from scratch in total frames on target. |
| Can the learner adapt when the reward changes? | On 16 unannounced relocations, a detector using only the mismatch between predicted and observed signal strength reacquired the source 14 times. Continuing to fit the old reward surface reacquired zero. Both table-initialized and fresh motor learners achieved 14/16 with the detector. The 16 stable controls produced no false switches. |
| Did the table-tennis changes affect native Pong? | The five-axis player after its restoration game and the rotary recovery player each reproduced all 180 reference action tapes and earned the same 41 points. |

On separate fixtures with unchanged hardware, the gantry switched maps four times and the five-axis player switched five times. The gantry won 12–10 versus fixed 8–11, and five-axis lost 5–11 versus fixed 6–11. A map switch can compensate for a stroke or prediction error even when the motor wiring stays fixed.

The motor correction uses requested commands and first-person stereo blade sightings. The rotary intervention uses calibrated tracking and a supplied stroke planner. The hidden-source benchmark supplies a two-view tool marker, scalar signal and a field-maximization objective. The experiments test separate mechanisms.
