# Learning several ways to move from the same observed state

A conditional mixture learns from 13,817 physically rewarded and 2,264 failed movement windows on 133 earlier release recordings. Each window contains camera-derived positions and motion, the actual issued joint reference and its recent changes. Within each of 63 learned groups, a regularized local regression maps the current observation to the next 21 joint references. The groups are learned jointly from the pictures’ motion features and the commands. The model can represent different successful arm motions from similar observations. No one labels a forehand, names the next stroke or supplies a future interception point.

On 24 excluded releases, the most likely mode predicted the first five joint steps with mean RMS error 0.074 rad, compared with 0.102 rad for holding the current reference. Choosing the best of four after seeing what happened gave 0.057 rad. The latter is an estimate of motion coverage. In live play the policy uses only information available at decision time. Rewards update local motion regressions, and both hits and misses adjust the relative weight of motions the arm actually issued. On 32 full games with independently sampled physical replies, the ordinary learner made 196 legal returns. Letting the arm's existing dynamics search choose among four additional learned joint sequences made 189. The best rally on that controller reached 45, but median rally length fell from 2.5 to 1.5. Of 33 physically identical incoming shots, both controllers returned 24, both missed seven and the new controller lost two. Allowing it to issue a likely sequence directly after the search found no legal action made 141 returns, with a peak of 19. Better prediction of previous joint commands did not improve typical play on this course.
