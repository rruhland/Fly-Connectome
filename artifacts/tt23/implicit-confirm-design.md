# Direct prospective test of online learning speed with anonymous actions

A four-stream choice-only replay on fresh physical alternatives favored native Pong experience over equal initial values in average launches to ten. The prespecified pooled randomized source happened to make the same choices, and on a separate direct deployment both learners first reached ten on point six. This mixed evidence motivated the independent confirmation. The source prior supplies only a camera-conditioned preference among fixed left, center and right actions. Each method has the same .09 workspace jog, camera, arm-specific practiced swing and full-rally continuation. No new spatial goal rule is added. [Fixed policy and training procedure](implicit-online-design.md)

Draw sixteen independent eight-point streams from the constants in the runner. They balance ordinary moderate and wide receiving starts, both lateral sides, in the same way as the previous pilot. Use the same ordinal model, two prior observations, set the flat learner's initial tie to center, use common random draws and update only the selected action from its actual full-point duration. Each condition plays directly in simulation until first reaching ten or completing its eight points. Source and flat may share the same physical trajectory only when they chose exactly the same action before either update. Every included trajectory must pass strict two-arm command replay. Run all sixteen streams without interim model selection. The destination process receives eight initial native camera frames at each decision and retains learning across points.

Primary endpoint is paired number of launches to the first ten, scoring nine for an eight-point stream with no success. Report all pairs, average capped launches, success out of sixteen, and an exact one-sided paired randomization of signed launch differences. Secondary endpoints are which learner first reaches ten within a 40-second and eight-point budget, and actual elapsed seconds on streams solved by both. Include censored exposures if the budget ends without success. No estimate treats multiple exploration draws or physical alternatives on one start as separate games. These streams are independent of source decisions, source fitting and the first four practice streams. [Runner](../../scripts/experimental/tt23_implicit_online.py)
