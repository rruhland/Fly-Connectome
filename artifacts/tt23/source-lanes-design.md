# Do native Pong gains help the arm learn to rally on alternate lanes?

Use the stock five-axis simulated opponent and its previously trained target profile, with the requested lateral coordinate changed to alternating ±12 cm on successive replies. Measure actual lateral placements and strict returns. The two cohorts start the alternating sequence on opposite sides. Each starts with the same shaped near-arm service program and stock service observation. Both arms run until the native referee ends the point.

The target chooses one signed gain pair for the entire point. Three candidates from the original native Pong duration screen cover the winner (6), the strongest positive-motion candidate above unit positional gain (10), and the strongest negative-motion candidate with positional gain in [0,.5] (7). All three are native behavior policies. Ignore the 2D bias, retaining the position and motion gains. The stock near controller can aim anywhere in the selected eight-centimetre cell with the original optical flight and motor search. The cell rule, flight fit, existing arm calibration and opponent controller are shared.

Use two separate practice and two separate held seeds per cohort. For each seed, run all three policies physically and replay both arms' complete commands. Replay paired target learners over the practice seeds, one selected point for each observation. Use the same exploration uniforms per choice, and update from the strict alternating return count transformed to a bounded reward. Initialize matched Beta estimates from native duration ranks, a uniform midpoint, or the same duration ranks assigned to different options. At zero through four new target points, freeze each learner's greedy choice and report held strict return lengths, mean legal returns, and ten- and twenty-return frequency. Give the results both left-first and right-first. These starts test the comparison on a small fixed sample.
