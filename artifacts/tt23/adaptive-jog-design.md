# Does native Pong duration accelerate a later arm learner?

Use both existing 64-start arm banks in their recorded order, with each bank serving once as practice and once as independent evaluation. All seven available jog displacements on each start have already been executed in native physics. The practice interface reveals only the complete elapsed duration of the one displacement chosen by each learner. The held evaluator records first legal returns from frozen greedy choices. The learner never receives those return labels.

Use the four pooled independent native Pong sets as the primary initialization and the original 72-start native fit as a sensitivity comparison. The source value for each action comes from an optical context kernel applied to the logarithm of one plus elapsed Pong seconds. Compare with the same kernel fitted to within-launch permuted duration labels, a prior flat across actions at the same context average, and a policy fixed at the centered command. The three adaptive policies start with the same three effective observations per action. They add one outcome per selected arm trial using the same optical kernel and reflection symmetry, with half an observation for each orientation. They share the 30% exploration gate, random action ID, and tie-breaks on every matched choice.

At 0, 4, 8, 16, 32, 48 and 64 completed arm trials, evaluate frozen greedy choices. Also evaluate after 0, 15, 30, 60, 90 and 120 simulated seconds. For a time checkpoint use only completed points. Report mean early held legal returns over 4, 8 and 16 trials as the main contrast. Count actual selected target frames and audit cumulative elapsed time through each learner's first practice point with a legal return. Keep all 64 seeds in each assessment, including failed visual tracks.

Advance to complete-point live continuation if the primary native prior improves the early mean by at least four returns out of 64 over each control on both physical banks, with positive paired 95% interval lower bounds. The two banks remain distinct. Repeated exploration draws reuse their physical histories.
