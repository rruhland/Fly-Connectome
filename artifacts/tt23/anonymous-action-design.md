# Can Pong identify a useful movement without a supplied interception formula?

Give a native Pong paddle seven fixed motor displacements, distributed symmetrically about its resting pose. None depends on a moving object's position. On each training episode the paddle tries one displacement, using visual motor calibration to hold that position. A nonparametric value fit learns which displacements predict longer native points given the observed motion at the time of choice. Shared descriptors are the moving region's position relative to the body and its velocity in the body's visually identified motion frame. The policy receives no crossing prediction, alignment objective, collision label, simulator state or signed reward. The previously learned Pong visual-role tracker and motor servo remain available.

First evaluate the source fit, a within-start shuffled-duration fit, and a policy that always uses zero displacement on separate real Pong starts, scoring elapsed time and evaluator-counted legal contacts. Then carry the same scores into the eight-frame anonymous table-tennis opening. Convert normalized displacements into metres using the observed compact-court width. The common SO-101 primitive and continuation controller already know how to swing and return a ball. This test isolates discovery of the first lateral movement.
