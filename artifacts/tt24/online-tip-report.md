The same reward-trained native player moved the physical arm. Its actual requested rate and next measured encoder sample went immediately into an eight-tick causal displacement window. Four candidate response filters each used an uncertainty-aware robust recursive least-squares state. An exponentially weighted prediction error, measured before the update, selected the response lag for each output. The program visited each training sample once and retained no full clip inside the estimator. Its retained numeric state and ring require 7,608 bytes independent of source length, excluding Python overhead, temporary arithmetic arrays and the frozen game policies.

Both learners saved and reloaded their exact numeric state after the sixth of twelve physically played source points. The source exposures were 3,545 and 4,081 physical control frames. The wrist test used the saved portable policy and learned map. Its first example wrist run and a native source point reproduced their live behavior after reloading. The original map was stored separately and reproduced six earlier unaltered stock runs. All 32 new wrist tapes replayed exactly.
