# Recognizing a returning body and changed gravity

A context-dependent motor readout reused the 32 scored target attempts already collected for the original four physics settings, along with twelve earlier donor tapes. A small fitted model used the initial wrist image and joint angles to recognize the donor bodies. A second model used the recent optical trajectory and encoder response to infer which target dynamics were active. Distinct residuals had previously been learned using reward on each of the four target settings. [Target learning and weights](donor-adaptation.md) · [Context implementation](../../scripts/experimental/tt24_context_residual.py)

On 21 fresh revisits to seven contexts, wrist observations identified all twelve target contexts by tick 18. On all nine donor returns the selected head reproduced the original wrist actions exactly. With stock and donor groups each summed separately, the recognition policy scored 160/54, the unmodified controller 188/54, applying the average residual everywhere 174/49, and the evaluator supplying the true context 182/54. Thus the learner preserved donor behavior, but the previously trained target adjustments did not improve the new fixed-context starts. Under the separate historical donor sensing setup, the same gate preserved 123 summed streaks, while carrying the latest nonzero residual everywhere scored 66. [Actions, recognition and controls](context-residual.json.gz)

Across four further starts with hidden gravity switching at tick 24, the context-dependent controller totaled 56 longest rebounds versus 43 frozen and 43 for supplied context. Most of the gain came from one 19-versus-3 start. The system detected three of the four switches within eight frames. [In-flight interventions](context-residual-switch.json.gz)
