# Does the simulator-trained arm know where its own paddle is?

The control system propagates a separate arm model from its calibration, issued references and current joint encoders. We replayed eight centered and eight canted games and compared the paddle reported by that internal model with the actual freely attached simulation paddle at each incoming search window. All 16 physical tapes reproduced the original events. No ball-state measurement was supplied to the body model. The ground-truth comparison was made after its prediction.

Across 120 centered and 214 canted search windows, the 99th percentile position discrepancy was under 0.000001 mm, and the 99th percentile face discrepancy under 0.000002 degrees. The velocity discrepancies were also below 0.000001 m/s. For these calibrated simulated installs, adding vision to locate the present blade is unlikely to materially improve receiving. The test does not measure how well the arm predicts where a proposed movement will put the paddle several ticks later, and the simulated model match is much closer than one would expect on a real arm.
