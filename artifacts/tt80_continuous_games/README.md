# A fresh unfiltered test of continual rally learning

One original centered SO-101 carries its learned motor memory through 128 preassigned games. Each group of 32 contains a shuffle of the same measured starting-release roster with newly and independently sampled opening and reply streams. The target is 100 legal returns by the learner within one unbroken point, with a finite-mass opponent reacting to every actual incoming stroke.

A frozen copy of the same starting memory completed the first 32 assignments. It scored 147 returns, median 3.5, versus 135 and a median of three for the continually updating copy. Each arm improved on eight relative to the other and they tied on 16. Both had nine zero-return games. Learning sometimes changes the next opponent ball favorably, but its benefit did not generalize across this block.
