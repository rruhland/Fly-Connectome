# What did the 63-return rally teach the next game?

Both copies faced the same 22 unfamiliar releases and independent opponent streams, with their memory frozen during assessment. The first carried the exact memory at entry to the 63-return point. The second carried its memory at exit. Its 272 newly earned movement fragments replaced the oldest 272 of 768. The overlapping fragments and original per-point memory fingerprints were checked when reconstructing those checkpoints. Four points lengthened, eight shortened and ten tied. The paired bootstrap interval for the mean change was −7.59 to +1.45 returns per game. The first different command occurred on an identical physical delivery in all 18 games with a different command. Both arms returned that same ball in 17 cases and missed it in one. Different successful strokes can lead to different subsequent opponent responses. These totals measure how long the games lasted. They do not isolate same-ball loss of competence at the eventual terminal offer.
