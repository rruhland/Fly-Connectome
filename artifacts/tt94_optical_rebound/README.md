# Reading an opponent's likely reply from the far-table bounce

Using two new post-bounce sightings and the preceding descent from ordinary stereo RGB, the arm can make a forecast a median of 158 ms before the opponent strikes. This anticipates a distribution of possible replies. The opposite paddle still sees the actual incoming stroke and independently samples its next goal. Of 128 held optical trajectories with a later measured reply, 123 gave a timely cue. Each individual forecast saw only its own past frames. The evaluator averages over independent physical redraws of a given outgoing stroke.

The first learner used 218 optical trials from 42 earlier outgoing contexts. On 22 held contexts its mean absolute error for the expected height was 24.0 mm. The same type of optical cue calibrated from 2,593 physical transitions across 64 separate release recordings brought this to 16.5 mm. A constant forecast gave 29.4 mm, and using only the descending arc gave 17.4 mm. On the broader fit the correlation between predicted and measured mean height was 0.83. This is advance information about a typical reply, with substantial remaining variability. Native motion is used to calibrate the broader teacher. The actor in a game receives camera measurements.
