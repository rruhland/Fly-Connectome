# Would knowing the opponent's exact recovery position improve tactical choice?

On 3,568 stored outgoing decisions from 112 releases, pre-contact candidate shape and observed incoming ball position predicted the next receiving height with 40.3 mm RMSE. Giving the evaluator the previous actual opponent contact and elapsed time yielded 40.7 mm. Giving it the carriage's exact location just as the arm's outgoing stroke began yielded 41.1 mm. Next-return Brier scores were .0997, .1016, and .1026. All comparisons held out entire release IDs. The later exact carriage location was deliberately privileged for this diagnostic. Its longitudinal standard deviation was 84 mm, but the selected regression found no predictive advantage from that variation. The test concerns the phase *before the arm's stroke*.
