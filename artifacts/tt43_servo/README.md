# Does history improve early joint positioning?

The fixed temporal motor readout combines the current visual ball estimate and five joint angles with differences across one, three and six control ticks. A fixed nonlinear expansion and ridge regression learn direct joint corrections from previously successful movements. It changes only early inward movement. The existing close-range joint search and stereo tracker still run during physical evaluation. A robot table-tennis study used short observation histories and a gated temporal network to command joint motion, including a derivative-free training comparison. Here the feature weights are fixed and only the linear motor readout is fitted. [Robotic Table Tennis with Model-Free Reinforcement Learning](https://www.columbia.edu/~wg2279/rtt/rtt.pdf)

On 2,978 early observations from 26 releases, withholding whole releases gave an average joint correction error of 0.0774 rad with history versus 0.0768 rad using only the current observation. Fourteen releases improved. This score measures how closely the readout reconstructs recorded motor commands. It cannot establish better returns. ## Complete games

Across 12 paired games with motor memory frozen after 12 practice games, the temporal feedback made 85 legal returns to the original controller's 77. The three improvements were 10 to 41, four to 16 and four to nine. Four games were shorter and five tied. The original controller had higher typical performance (median four against 2.5). A direct readout fitted to just the current measurement made 20 returns across the first six games, compared with 73 for the temporal readout and 36 for the original. The two fitted readouts use the same training rows, output targets and nonlinear feature count. Both are fits to earlier demonstrated joint commands.
