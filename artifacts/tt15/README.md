# Transferring a motor skill across tasks and identifying what changed

**The simulated arms could bring useful motor knowledge back to table tennis after searching for a hidden source.** The search task exposed tool position but barely exposed the direction of the wrist. Fitting the search movements recovered the right axis for all 18 ports across four unfamiliar wirings, with three sign errors. One 0.4-second RGB pitch probe at the task transition resolved all three. The resulting players won three of four complete games and made 61 legal returns. A player given exactly the same pitch probe without the search-derived correspondence lost all four and made zero legal returns. Relearning the map directly from scored table-tennis points also produced three wins and 61 returns. | Research question | What changed the result |
| --- | --- |
| Did the learner distinguish body changes from goal changes? | With two previously learned table-tennis motor maps, normal play identified 40/40 wiring changes and 37/40 hidden-source relocations. Twenty stable intervals raised no alarms. Preserving the reward model on motor-only changes raised on-target time from 886 to 1,338 frames compared with resetting both learned models. |
| Could it learn on a wiring it had never seen? | When allowed to create motor maps from new task experience, it acquired the source in 44/64 intervals starting with table-tennis geometry versus 36/64 from scratch. On gantry even a reversed-column prior acquired 25/32, compared with 24/32 for the carried geometry. |
| Was motor-change detection robust in actual table tennis? | Requiring passive evidence from two separate points cut false switches from five to one in fresh stable games but missed both restorations. Confirming a suspected change with a repeated dry movement recognized four changed harnesses within two affected starts and preserved all 38 stable action tapes. Across the four changed fixtures that method landed 35 returns, the earlier selector 27, and a fixed map four. It consumed 52 unscored diagnostic movements across its tests. |
| Did the six-joint arm sustain rallies on more distinct points? | Optical recovery, bounded planning and timed feedback all sustained a subset of the same two held points as blind recentering. Across three complete fixtures, every sustained game rally came on one point. Bounded planning won that point with two returns and timed feedback lost it after three. Further tuning of neutral recovery has little support from these games. |
| Was Pong retained? | The five-axis passive, repeated-movement, search-transfer and rotary optical checkpoints each reproduced all 180 native Pong action tapes, including the same 41 points. |

The 12-command wrist probe at a task transition and the repeated dry movements used to diagnose gain changes during games are different experiments with different budgets. Every scored game used first-person stereo, ordinary rewards, alternating service and changing disturbances. The hidden-source task used a calibrated marker display and scalar strength.
