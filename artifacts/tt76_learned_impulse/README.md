# Learning a better ball departure from scored and weak movements

The learner observed the outgoing position and velocity of balls it had actually returned, using ordinary stereo pictures. On a later modeled contact that would send a ball into trouble, it tested paired joint-reference changes around the same predicted contact. Independent pulses before impact let it change the blade velocity with less displacement. Only paired perturbations in which the ball still touched both times informed the velocity correction. Three forward-model votes were needed to issue it.

Across 32 preassigned continuously random games, the ordinary learner made 196 returns and the new learner made 199. The first 15 points had exactly the same issued commands. Only one additional movement cleared all checks, during game 16 on release 9060, which shortened from 19 returns to 14. The resulting motor memories then acquired different experience. On release 5463 three games later, that carried memory turned the same opponent’s third delivery from a miss into a legal return. Independent action replay reproduced all four own returns, five opponent returns and positive clearance across 3,934 solver states. On the last release the arm made 35 returns versus two. Across the schedule two games improved, seven shortened and 23 tied. This establishes a small instance of transferable motor credit and leaves aggregate advantage unresolved.
