# Which early moves leave useful later moves?

The arm can earn a return in a situation where its earlier controller ran out of usable joint movements. On measured release 11884, both policies returned the first 16 shots, drove exactly the same first 1,613 commands, and received the same physical 17th ball. The new joint sequence returned that ball. The previous controller missed it. The point ended at 18 arm returns. [Decision and matched incoming bounce](matched.json)

The controller tries an early joint movement for three or six control ticks in its private camera-initialized model. It uses the resulting visual and encoder state to retrieve a later movement that earned a return in an earlier game. It then screens the *combined* movement from the original state for a legal landing. It consults this branch when the ordinary screen has no robust choice and checks alternative camera estimates before acting. This is a search over previously earned direct movements. It uses a pretrained model and full calibrated local dynamics. No backpropagation or true game state enters the live search.

Across eight matched starts with frozen memory, the previous feedback made 76 arm returns and the composed movements made 89. Four games improved, one shortened and three tied. The median rose from 3.5 to 13, and the maximum fell from 41 to 24. The new branch screened 910 combinations across the course, found 94 nominally legal and issued nine. The runs used 238 and 288 CPU seconds for 133 and 155 simulated seconds respectively. The same input releases and same starting memory were used in both arms. Independent random target requests remained identical through each shared point prefix, with subsequent physical trajectories determined by the actual shots. On a separate 24-game course with both early motor feedback and outgoing scoring already enabled, composing movements reduced 197 arm returns to 160. Six games improved, nine shortened and nine tied. Median rally length fell from seven to three. The initial rescue of an identical seventeenth delivery holds, but this broader result favors keeping the ordinary motor search as the default.
