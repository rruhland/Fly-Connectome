# What the arm retained after the clamp moved

Four frozen copies played the same 16 independent, continuously randomized opening streams. The first memory came from 48 original-fixture games. The second added 32 normal games with the clamp 12 cm right and base-registered movement credit. The original and shifted fixtures each played both memory states. All 16 opening recordings were separate from both practice courses.

| Physical fixture | Before shifted practice | After 32 shifted games | Median before → after | Zero-return games |
|---|---:|---:|---|---|
| Original | 73 | 77 | 5 → 3.5 | 3 → 4 |
| Shifted 12 cm | 46 | 57 | 2 → 3 | 5 → 5 |

The shifted copy rescued one physically identical delivery and lost another. The original copy lost one previously returned identical delivery. The paired intervals for mean change span −1.0 to +2.7 returns per shifted point and −2.5 to +3.6 on the original fixture. Practice gave a small observed increase in the total on both bodies.
