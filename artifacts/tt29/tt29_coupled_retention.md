# Wrist-only bounce retention across the coupled 100-return archive

The retained four-drop wrist controller was physically run on eight previously held release seeds. Next, the existing camera-rally replay entry point replayed all commands for point 4187 with the coupled drive model and its original independently computed far opponent. The table motor memory was restored from the archive through the same `Experience` class used by live table control. The identical eight wrist-only releases then ran again. [Matched command and state receipt](tt29_coupled_retention.json) · [Experiment entry point](../../scripts/experimental/tt29_coupled_retention.py)

The wrist controller made 10 qualified rebounds before and after the table point. The longest streak was five and the median was one in both assessments. All eight wrist action streams and their referee outcomes were identical. The table point reproduced all 100 alternating returns, 503 referee events and the original state trajectory hash. Full-CAD evaluation covered 33,209 solver states with zero penetrations. The restored 193-example table memory hash also stayed identical through the post-table bounce assessment. [Exact replay evidence](tt29_coupled_retention.json)

The camera-coupled point used both fixed RGB cameras. Its original live course added 50 rewarded stroke examples, from 143 to 193. This retention assay replayed the archived physical point and reloaded the verified table state. The 4187 route used neither a wrist-registration checkpoint nor a solo-timing checkpoint. The table examples and the bounce checkpoint are separate parameters. This assay measures preservation through a switch between those routes. In the separate delayed-table experiment, the table feedback controller explicitly consumed a timing estimate learned during solo play. Returns increased from 10 to 60 and from 16 to 30 on the two matched points. This transfer concerned actuator timing. [Matched timing transfer](adaptation.md)

The existing promotion gate accepted the four-drop checkpoint on a separate validation deck. It subsequently rejected the new motion fit and the visual drift controller after each received its own fresh practice and gate. Those experiments used additional solo interactions. The retention assay uses frozen checkpoints and does not supply a new training or promotion result.
