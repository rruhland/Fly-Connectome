# When should the learner use its new motor memory?

The arm starts with the motor memory earned by playing on the shifted clamp. On returning to the original centered arm it retains an immutable copy and a continuously updating copy. The established motor policy is allowed to finish its normal decision. When it finds no legal action and has no outstanding earlier commitment, the learner retries its internal action search using only its newer experience, initialized with the same planning randomness. A new movement must land in the nominal model and in two perturbed camera-state models to be issued. All scores come from the single uninterrupted physical point.

The 32 normal coupled games have two controls on the identical draws, ordinary continuous updating from that checkpoint and freezing it throughout. Both controls matter because an apparent gain could come entirely from preserving earlier experience. This experiment takes inspiration from using a baseline policy where information is uncertain. The acceptance mechanism here is an empirical test in a simulated robot with continuous observations.
