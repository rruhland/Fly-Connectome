# Which direct joint movements turn a physical miss into a return?

Seventeen matched forks from thirteen releases contained both a legal movement and a miss following an identical action history. Interpolating actual issued joint rates between the two endpoints yielded a monotonic legality transition in sixteen forks. Only four of seventeen landed using the halfway movement. Six needed the complete winning endpoint. [Physically paired motions](pairs.json.gz) · [Interpolated physical returns](lines.json.gz)

Under camera-initialized private dynamics, perturbing the timing or amplitude of each known endpoint's commands favored the actual winner in fourteen comparisons and tied three. The unperturbed binary modeled landing favored it in seven and tied ten. Applying this tolerance metric to candidate selection during new actual play made 144 returns on 24 broad-random games. Restricting the action change to recovery made 170. The original live learner scored 179 on the same assignments. This test did not justify replacing the existing decision rule.
