# Does early motor exploration leave useful experience?

Over 48 assigned games, always exploring earned 249 arm returns, limiting exploration near prior failures earned 234, and the established learner earned 360. All started with the same motor memory and played the same random opponent schedule. Each exploratory action was a continuously valued perturbation in three joint directions inferred from earlier motor residuals. Real legal returns and optically observed near misses updated a local reward-weighted policy. [Practice and complete commands](practice-48.json.gz) · [Failure-conditioned practice](selective-48.json.gz)

After 24 exploratory games, a frozen snapshot returned 199 balls on the same 24 held points where the pre-practice learner returned 189 and ordinary additional practice returned 135. Medians were five, six and 3.5 respectively. During this original frozen evaluation, the most recent perturbation could persist into the first few optical samples of the next delivery before a new context was registered. The separate deployment comparison clears it on outgoing flight and uses fresh independent opponent draws.
