# Choosing a motor memory from the arm's own results

On 96 matched full games, switching between four motor memories using rewards from the current and following return gave 492 returns compared with 483 for the ordinary continually updated bank. The median rose from two to three, but zero-return games increased from 23 to 26, and the longest point fell from 42 to 29. The release-paired interval for the average difference spans −1.30 to +1.48 returns per point. On the first 64 games the adaptive selector made 345, uniform selection made 349, and the ordinary learner made 352. There is no consistent gain to carry forward. The weights and chosen memories are recorded along with every issued command.
