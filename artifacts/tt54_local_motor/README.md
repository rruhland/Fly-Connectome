# Generalizing a rewarded motion from nearby body and camera observations

A local linear fit adjusts each stored joint-reference sequence from differences between observations on other physically rewarded strokes. On 179 later returned balls from 14 scoring games, the first predicted action's mean four-tick RMS error fell from .084 to .059 rad. On 12 complete live games the generalized policy scored 60 returns, compared with 125 using the original proposals. Predicting the chosen motion on an existing successful trajectory did not improve sustained play when the predicted motion changed what the opponent received.
