# TRAIN-only relational feedback mechanism review

The fixed compact-servo search's first round selected an anonymous position-only relation: observed cardinality 3, horizontal ranks 0/1, coordinate 0, polarity −1, all five numeric coefficients zero. On the same nested TRAIN starts it earned 18 versus 12 returns on 4 games, 34 versus 23 on 8, and 64 versus 44 on 16. These are selection results, not fresh qualification. They support the usefulness of direct feedback; a failed 64-proposal search would not refute the whole controller family, and a successful TRAIN endpoint still requires fresh transfer.

The frozen endpoint subsequently earned 130 versus 83 returns on TRAIN32. The parent reports its separately designated fresh32 comparison earned 131 versus 90, later returns 101/113 versus 60/84, with first returns unchanged at 30. Fresh traces were not inspected for this mechanism analysis. The parent’s TRAIN-only final-trace review found all nine post-hit terminal misses had cardinality fallback in the last 32 decisions: [19,14,17,32,19,17,22,11,32] cameras; overall post-hit fallback was 5,086/21,927 (23.2%). These windows can include consequences of a missed trajectory and do not establish causation.

Saved-data analysis used the frozen 114,229-transition archive only. Among 90,575 post-hit rows, 65,832 have three observed entities and 21,999 have two. There are no genuinely empty post-hit scenes: the 230 compact zero encodings represent overflow. Across 55,247 adjacent three-observation scenes, exhaustive position/velocity correspondence changes either selected rank only 162 times (0.293%). Thus frequent within-cardinality rank swapping is not supported as the main bottleneck. Cardinality gating is much more common.

All 21,999 two-observation post-hit scenes retain unobserved entities in the existing visual memory; 21,969 retain an unobserved entity with known velocity. Of 9,991 clear three-to-two correspondence events, the missing source rank counts are [198, 9,741, 52]. Every event retains an unobserved row; its nearest position differs from the missing entity's one-camera extrapolation by median 0.156 pixels and 90th percentile 0.500 pixels. These are continuity checks, not ground-truth occlusion accuracy. Six-field archives omit public tracking IDs and observation ages, so they cannot establish exact ID persistence.

Matched real opposite-command branches show median visible coordinate separation of 0 pixels through 4 cameras, 2 pixels after 8, and 9 pixels after 16 for horizontal rank 0; the other ranks have zero median separation. This establishes delayed visible response without hidden motor parameters. It does not justify another coefficient sweep. Three-observation coverage in the preceding 16 cameras is similar before actual hits and natural ends (70.5% versus 71.5%), so aggregate dropout frequency alone does not establish the cause of misses.

Finish the frozen search and qualification first. The next justified representation intervention, conditional on remaining TRAIN misses following fallback, is **persistent visual binding**: bind the learned anonymous pair on a valid observed scene, then continue those public visual IDs and already-carried positions through missing-observation intervals, with explicit retirement/absence fallback. Do not re-sort all remembered ghosts into new roles. This preserves actual reward learning while using legal sensory memory currently discarded by the observed-only gate. No implementation or native test was performed here. Removing the opening baseline gate would be a separate prospectively fixed test; current feedback success does not establish opening performance.
