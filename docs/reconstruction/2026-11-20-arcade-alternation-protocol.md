# Alternating paddle games with one learner

Start with the sealed post-course Pong checkpoint and the brick-placement checkpoint at the end of chronological practice. Prefer the reward-only model if it improves on its own untrained prior on independent boards. Use the visually calibrated rebound model if it meets that test after the reward-only model falls short. Keep the existing camera tracker, role adaptation, interception relation, motor-order posterior, and timing model active. Start a new camera history and empty actuator queue at each serve. The alternative arms receive the same matched physical starts and rewards through the same controller interface. The routine reset delivers an initial camera frame without a game ID, schedule index, layout seed, button map, or delay.

The first frame supplies two possible cues. A visible paddle rail facing two or more rows of small rectangular targets activates the brick rebound model. Two opposed parallel paddle rails activate the carried Pong placement policy. Ambiguous images use centered interception. Lock the decision for the life, so clearing bricks cannot silently switch the score update. This engineered rule depends on the objects in the image and supports only the scene structures tested here. The rule has the same outcome for quarter-turn rotations of each supported layout.

The brick model receives every positive native brick increment in the selected life. The Pong model receives the ordinary terminal outcome on its selected lives. The bridge supplies camera entities, requests, elapsed physics time, and the signed terminal outcome to the common control path. The inherited between-life relation update uses bounded episode reward and duration. The evaluator records own hit notifications for return counts. Brick and Pong placement have separate state, with each receiving only observations selected by the scene rule. No backpropagation runs.

Each course consists of six blocks in the fixed order Pong, Breakout, Pong, Breakout, Pong, Breakout with six new starts per block. Five arena switches provide two re-entries for each game. Pong uses the original .35 opponent and normal buttons and timing. Its first serve in each block travels toward the controlled paddle, followed by alternating serve directions. Breakout uses previously unseen held-out layouts and balanced lateral serves. Both games use a 20-second limit. The first course uses ordinary buttons and timing in both games. The conflicting course reverses requests 0 and 2 in Breakout and applies a six-command queue. The observed interference reflects the combined change. The seeds are fixed in the evaluator and the policy has an independent random generator.

- **Shared.** Carry the last confirmed role and one active sensorimotor state directly into each new life. Once a saved role lacks enough image support, online causal probing verifies the new rail.
- **Role recall.** Also remember the most recent causally verified rail for each visible scene type. Before the first request, restore a remembered rail only if the same appearance cue and rail are present in the opening camera. Continue adapting the shared motor and timing state online.
- **Isolated.** Run the same learner as the shared arm, separately on the chronological Pong subsequence and Breakout subsequence. Both copies start from the same checkpoints as the shared arm, then receive the same starts as their game in the mixed course.
- **Context recall.** The optional fourth arm also retrieves the last visually supported timing and motor-order state once a known scene returns. Saving this prior requires the remembered role, at least two distinct requests, at least two pixels of observed paddle motion, and 85% posterior confidence in the active order. The retrieved belief remains subject to the same online estimator after a switch.

## Independent fallback after a direction error

The first played courses revealed that the inherited score-triggered relation could reverse after one opening miss and persist in the opposite direction. Preserve those runs and their score-only brick practice endpoint. On fresh starts, credit direction changes to evidence from deliberately requested and visually realized paddle motion when the current roles and motor estimate are reliable. A carried direction requires support on two separate failed lives before it can be revised. This holds learned direction through an isolated miss and still permits revision when repeated motion contradicts it. Use the independently qualified visual-rebound-and-score checkpoint in every fresh arm. In separate fresh cohorts, that practice endpoint scored 92 bricks after a return versus 79 for its untrained prior, with a paired per-life increase of 0.406 bricks and a 95% interval of 0.063 to 0.781. Keep the cue rule, starting Pong checkpoint, cap and number of switches.

The fresh ordinary and conflicting courses use fixed generator seeds 1958120401 and 706290303 respectively. A second geometry check excludes boards from both previous courses. Compare guarded and unguarded learners in a single alternating stream and a guarded learner in separate uninterrupted streams, with role recall on ordinary controls and context recall in the conflicting course. Show each re-entry block’s first five actual opportunities, all return rates, wins after a Pong return and bricks after a Breakout return. For ordinary retention, seek a pooled re-entry return rate of at least 90% in each game and a rate within ten percentage points of its isolated reference. For combined reversal plus lag, require at least 75% in each game. In either case, require a Pong win after a return and brick yield after a return across the two re-entry blocks per game before calling the resulting retention useful. Report the missed starts and observations of genuine direction correction separately.
