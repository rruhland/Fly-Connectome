# M1A pivot: persistent visual entity state

**Status:** Next opt-in architecture direction; no production change. This follows the failed [distributed predictive sheet](../experiments/2026-09-26-distributed-predictive-sheet-findings.md), the [generic contrast-surface ceiling](../experiments/2026-09-23-generic-grouping-findings.md), and the [multi-hypothesis path-bank failure](../experiments/2026-09-25-multi-hypothesis-assembly-findings.md).

The fast locally learned field remains a sensory motion primitive. Add a separate local ON/OFF contrast trace as low-level visual memory: signed event integration retains persistent appearance through quiet frames. Its clean component map may propose coherent regions, but **it is not the final representation**. Raw integration preserved clean moving and stationary shapes and crossed identical shapes, while false events created persistent phantom occupancy. The final state must therefore carry confidence and predictive evidence, not equate every occupied pixel or connected component with an entity.

The new latent consists of a variable number of persistent **entity hypotheses**. Each hypothesis stores a soft spatial support, a learned local appearance code, temporal context, a forecast of its own next sensory support, and confidence. Incoming local visual evidence competes for these hypotheses *online*. A confirmed continuation strengthens the responsible hypothesis's local association and dynamics through signed sensory prediction error and presynaptic eligibility; unsupported continuations lose confidence. Unexplained evidence can form a new hypothesis. At a visual merger or crossing, hypotheses persist separately and compete again when evidence separates. No true object count, identity, crop, direction, wall, intercept, reward, or Pong-specific feature enters inference or learning. No backpropagation is used.

This differs from the rejected path bank in three testable ways: candidates come from a persistent visual surface rather than isolated event fragments; the system emits its **current selected state** instead of post-hoc top paths; and local prediction error, not geometric smoothness alone, changes both association and forecast. Generic geometry and local event correlations may be fixed sensory primitives, but entity identity, confidence, appearance, and dynamics must depend on experience.

Implement as opt-in chunks, each left testable: (1) signed surface plus confidence-bearing local evidence, verified on clean and noisy event streams; (2) online hypothesis competition and continuity, verified on translated shapes, changed position/speed, two separated entities, and crossings without oracle selection; (3) local sensory prediction-error learning and full-frame next-event forecast, compared with fast-only, fixed continuity, and time-shuffled learning. Use the same 64 unlabeled generic training scenes and held-out transfer cases, then a separate noise/occlusion stress set. Score chosen hypothesis count, duplicate hypotheses, identity switches, coverage, activity outside true regions, direction decodability, and top-8/top-32 event forecast. Coordinates and identities may appear **only in evaluation**.

Do not claim success merely from clean connected-component count: zero-learning geometry already achieved that, and fixed continuity was strong in earlier tests. A useful M1A result must show a learned advantage over fixed and shuffled controls on either ambiguous/noisy identity continuity or transferable forecast, while retaining clean speed/shape performance and an autonomous state close to one hypothesis per moving entity. If a single isolated false event remains indistinguishable from a genuine isolated stationary pixel without renewed sensory evidence, report that information limit rather than encode a scene-specific rule. Only a concrete, passing architecture should be proposed for production promotion; that promotion requires user approval.
