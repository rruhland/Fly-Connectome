# Opt-in probabilistic visual candidate integration

This is preparation for review, not a production promotion or completion claim.
The user authorized experiments and requested no further prompts until a ready
candidate exists. Keep `src/` and production defaults unchanged.

The candidate separates three jobs:

1. Statistical frame/event evidence and multi-hypothesis association create
   observed tracklets. Engineered association is disclosed; learned local
   context associations provide hidden-state corrections from experience.
2. Bounded local episodic history/outcome associations provide multiple spatial
   futures, rather than a mean that can fall between mutually exclusive paths.
3. Observable delayed endpoints calibrate marginal intervals and visual
   reidentification probability. Neither is hidden-object existence truth.

Declared sensor is a grayscale frame at every camera sample plus events. No
rendered-intensity teacher, object labels, motion-family labels, game rules,
reward, or backpropagation. Learned relation and dynamics parameters are frozen
unless callers explicitly set `learn=True`. Current observations, carried
hypotheses and forecasts remain separate. Horizons count camera samples.

Implement in experimental scripts only, in dependency order:

- Add causal issued-mixture credit, cold-start prior, and rank interval export;
  test multimodal retention, immutable credit, bounded memory and no learning
  during inference.
- Add an opt-in streaming subclass and explicit versioned checkpoint; test
  exact frozen outputs, continuing-learning RNG state, unavailable samples and
  cached forecasts. No implicit component substitution on load.
- Package the trained observation/context/dynamics/calibration components and
  run end-to-end fresh scenes, multiple entities, gaps, contradictions and
  compute/memory measurement. Review causal/split integrity independently.
- Write a promotion report containing all passing and failed gates, sensor
  changes, probabilistic versus point acceptance, and measured-connectome
  limitations. Do not call synthetic transfer general robotics capability.

Point regression remains an unresolved requirement of earlier protocols. A
distributional candidate can justify a concrete proposed acceptance revision,
but cannot be presented as having passed that point gate. Measured graph inputs
remain optional until their added value and runtime justify inclusion.
