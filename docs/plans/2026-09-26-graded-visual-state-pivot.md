# M1A pivot: graded predictive visual state

**Status:** Proposed next opt-in architecture, not a production revision. It follows the clean two-stream learning gain, its weak zero-shot Pong/noise transfer, and the [absolute-refresh failure](../experiments/2026-09-26-absolute-refresh-findings.md). The recent results have exhausted useful binary confirmation and hard-refresh tests. Further sweeps of file lifetime, local radius, confidence threshold, or rank gain would be narrow testing without addressing the state mismatch.

The key observation is that generic visual information exists at multiple timescales. The fast locally plastic field predicts event details; persistent files preserve coherent support; occasional absolute contrast corrects event-memory ambiguity. Their *combination* improved clean prediction, and independently supported files improved native-cadence Pong. But the current state is a list of hard live/dead files with one center, one velocity, and one rigidly translated support. False evidence creates lasting extra files; binary confirmation hides real quiet entities; hard intensity refresh deletes real files and rebirths them. No scalar gate can express the uncertainty these cases require.

The next latent should be a variable set of **soft visual hypotheses**, each carrying a graded spatial support, signed appearance, confidence/evidence, and an event-time transition distribution. Incoming signed events and any absolute contrast are local evidence for or against each hypothesis. Neighboring hypotheses compete for overlapping evidence through local normalization/inhibition, while a small residual can start a provisional hypothesis. Predictive error updates the support, transition, and source reliability locally and online. A contradictory intensity observation lowers confidence and reshapes support; it does not instantly delete identity. A genuine quiet entity can retain a low-event but intensity-supported state. All state variables are generic visual quantities; no Pong ball, paddle, wall, intercept, object-count label, supervised direction, reward, or backpropagation enters learning.

The fast field remains an independent learned sensory predictor, with the measured T4/T5-related stream added as a source ablation once the soft state is credible. The file-level future should be a probability distribution over *where and when* local visual change is expected, not one displacement at the last observed interval. The two streams may compete through local learned reliability; the current global rank calibration is an opt-in information probe, not the assumed biological implementation.

Build and test this as three decisive opt-in stages, each with fixed/shuffled controls and no held-out tuning:

1. **State reliability:** Compare soft evidence assimilation with event-only files and hard refresh on clean, stationary-noisy, and moving-corrupted generic scenes. Score autonomous count, identity continuity, births, and recovery after occlusion. A useful candidate must retain clean state while sharply reducing noisy overbirth; forecast alone cannot rescue a bad state.
2. **Learned event timing:** Train local transition/hazard state on the same unlabeled generic streams. Compare against rigid translation, fast-only, and shuffled temporal credit on position, speed, shape, multiple entities, and raw Pong at both camera cadences. Require improvement at the native cadence without collapse at the coarser cadence.
3. **Connectome relevance and actionability:** Add frozen measured T4/T5 motion evidence as an input ablation, inspect whether it improves transfer across position/speed/direction, and test whether a fixed nonlearning readout can use the forecast. Do not add motor reward learning in M1A.

If a soft state still yields decodable motion but unreliable autonomous hypotheses or weak full-frame prediction, stop extending the entity-file family and compare a distributed recurrent predictive field with emergent segmentation. Any concrete production promotion will be reviewed with the user before changing the in-place M1A architecture.
