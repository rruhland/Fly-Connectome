# M1A next architecture: recurrent temporal state with separate sensory and event credit

**Status:** Proposed opt-in experiment, not a production change. M1A is not yet complete. This follows the [learned-observation success](../experiments/2026-09-26-learned-observation-model-findings.md), [frozen transfer failure](../experiments/2026-09-26-observation-model-transfer-findings.md), [multi-cadence tradeoff](../experiments/2026-09-26-multicadence-experience-findings.md), and [local selector failure](../experiments/2026-09-26-local-temporal-mixture-findings.md).

The strongest retained component is a generic, locally learned event-credibility model. Paired rendered visual change taught it to pass true signed events and suppress injected false events without object labels or backpropagation. It made a distributed predictor robust to unfamiliar noise levels. The current transition representation is the bottleneck: one shared local kernel learns slow or fast motion but overwrites the other; a local selector over separately trained kernels collapsed toward one pathway. Fixed equal fusion preserves broad generic coverage but loses sharply ranked native Pong predictions. Earlier sparse and low-resolution recurrent sheets also produced fragmented or spreading live state. More gate/decay/radius sweeps would repeat those failures.

The proposed next latent is a **full-resolution, locally recurrent visual population**, with several intrinsic integration timescales but no predefined direction, speed, entity, Pong, or feature-bank channels. The existing learned observer supplies continuous signed sensory evidence. Hidden units update from that evidence **and their own nearby previous activity** on every camera frame, including quiet frames. Local competition and homeostasis constrain total activity at each site rather than a global winner count or hard entity birth. A local transition learns to predict the next hidden state from neighboring presynaptic activity; an independent emission pathway learns when and where a visible signed event is expected. Hidden persistence is not itself treated as a visible event. Both pathways receive only their own local prediction error times presynaptic eligibility; there is no backpropagation through time or motor reward learning. The biological motivation is local recurrent motion memory with separate sensory observation and visible-change signaling. Its actual state content must arise from experience.

One bounded implementation should compare aligned local transition/emission credit with frozen and time-shuffled transition credit, a no-recurrence ablation, the current slow and multi-cadence fields, and their equal mixture. Train on unlabeled mixed-cadence generic scenes with the observation model frozen; no held-out or Pong example enters learning. Evaluate autonomous state continuity and full-frame next-event top-8/top-32 on changed position/speed/shape, separated/crossing patterns, original clean and corrupted generic scenes, stationary quiet/onset/offset, and raw Pong at both camera cadences. A state-reset test must show that recurrence actually contributes where history matters. Add frozen measured T4/T5 input only after the generic state clears these tests, with an explicit ablation, to assess whether the measured graph adds transferable motion information.

**Hard advance gate:** Require, on the same transfer sets, at least .617 clean-generic top-32, .572 corrupted-generic top-32, .376 changed-speed top-32, .307 separated-entity top-32, and .312 native-Pong top-32. These are 90% of the best relevant slow or diverse single-pathway results. Native Pong top-8 must reach at least the slow pathway's .072; equal mixture's .015 is unacceptable. Aligned recurrence must beat frozen/shuffled controls and improve the state-reset condition without uncontrolled quiet-frame emission. These are joint requirements, not metrics to trade against one another. Benchmark training and inference throughput alongside them. One architecture run plus a corrective fix for an implementation bug is enough; if it misses, do not run a parameter sweep. Reassess the predictive objective and latent family with the user before another experiment chain.

The current paired-intensity teacher is an additional assumption: training used every-frame rendered intensity changes while inference used intensity every eight frames. A production design would need to state how that signal is acquired online and verify its data/compute cost. No motor learning is proposed here; that remains M1B.
