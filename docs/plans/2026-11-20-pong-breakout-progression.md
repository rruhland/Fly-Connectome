# From Pong interception to Breakout

The starting asset is the carried Pong controller after its 96-point scoring practice and 64-point mixed course. Keep that checkpoint fixed before any Breakout frame reaches a learner. Use a native Breakout arena with a 64×64 binary camera and the same three requests, paddle dynamics and camera cadence as native Pong. This isolates which acquired knowledge can transfer when the paddle changes axis and the opponent is replaced by destructible targets. It is a custom game, so the results apply to this environment.

1. **Identify the controlled object.** Rotate the Pong camera through four orientations and add static silhouettes. An agent can examine shapes, try requests and measure motion. Evaluate which visible tracks it selected against physics outside the learner, then count actual first and later returns. The camera tracker, Pong weights, paired starts and native returns stay fixed for the comparison.
2. **Try Breakout without tuning.** Compare the complete Pong state, motor/arrival knowledge with blank shot values, frozen decision parameters, a learned-from-reset controller using the same structural family, a numerically uncalibrated learner, and passive play. Keep the first five opportunities, time to first sustained rally and failed lives in the denominators. The independent qualification has its own locked schedules and criteria. Already knowing how to bind a paddle is part of the scaffold and should be disclosed for every arm that shares it.
3. **Learn what earns bricks.** Compare an online shot learner with its own untrained prior, centered interception and unchanged Pong aim. Count bricks per life and per minute after a return, returns per opportunity, and held-out layout performance. Sparse remaining layouts can expose differences when most trajectories hit a brick on a full board. Distinguish score feedback, dense public visual evidence of rebound, and any engineered geometric prior.
4. **Alternate games.** Carry one session across unlabeled changes. Compare with the same policies played continuously in each game. Record the first return on re-entry, brick yield, Pong scoring and any interference from conflicting controls. Document exactly which components are shared and what the software uses to recognize a visual context.

The object-based hypothesis is that a previously learned action effect and moving-object relation can be used again after the relevant objects are identified in a different scene. Object-oriented MDPs describe generalization through object interactions. Schema Networks tested zero-shot generalization across Breakout variants. The new experiment tests transfer from Pong into Breakout and separates the acquisition of interception from the acquisition of brick-directed shots.
