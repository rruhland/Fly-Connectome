# Proposed generic M1A visual architecture

**Status:** Experimental proposal only. Do not change production M1A without user approval. This supersedes the withdrawn Pong-specific motion/world-state proposal.

## Objective and boundaries

M1A should convert ON/OFF event-camera evidence into a useful representation of coherent visual patterns and their likely future activity. It should work independent of the evaluation environment's object names or physics. Do not encode ball or paddle identity, image-column crops, walls, collision classes, intercepts, simulator state, or any game-specific target in M1A. Pong may be one held-out evaluation environment. M1B remains motor learning; a fixed controller can later test whether M1A forecasts are actionable.

Use no backpropagation. Preserve the measured connectome graph and transmitter signs as a biological reference; mark additional computational motifs explicitly rather than claiming they are measured synapses. Prior opt-in T5c/d activity shows that the graph can supply motion-selective signals, but subtype-rate direction was insufficient for small dots. The opt-in spatial event map and local displacement competition show stronger generic translation transfer across shape, position, contrast, and two speeds. Their learned scalar efficacy did **not** beat a matched fixed control.

## Candidate information flow

1. **Local visual primitives.** Keep signed ON/OFF event fields and local decaying sensory memory. Compute retinotopic, polarity-specific coincidence assemblies at multiple nearby spatial offsets and time lags; local competition preserves the strongest supported hypotheses at each site while allowing different regions to express different motion. Record connectome T4/T5 responses beside these assemblies. The initial 1/2-pixel, one-frame, 7×7 competition is an experimental operating point, not a fixed universal scale or supervised velocity label.
2. **Coherent visual state.** Link nearby activity by spatial continuity and similar local motion over time. Maintain persistent occupancy and uncertainty when events temporarily stop, and allow multiple overlapping or independently moving groups. Groups are inferred from visual evidence; there is no semantic class, designated target object, privileged screen location, or simulator coordinate. The [generic grouping baseline](../experiments/2026-09-23-generic-grouping-findings.md) shows why persistence is necessary and why indefinite raw event integration is noise-fragile. Compare local support/confidence with occasional absolute sensory refresh in opt-in tests, including genuine small objects, before choosing a production memory mechanism.
3. **Predictive state.** Forecast future visual activity or group state at several camera-frame horizons from the coherent state and surrounding visual context. Learn local transition efficacies or recurrent state using delayed visual observations and local eligibility/error only. Distinct context-sensitive local channels may be needed where one scalar synapse receives contradictory credit. Calibrate uncertainty and abstain when evidence is ambiguous. A fixed local extrapolator is a required matched control: learning must improve a held-out condition that fixed motion continuation cannot explain.

This order separates perception from prediction without forcing early L1/L2/L3 cells to supervise their own future activation. It also avoids hand-labeling direction or velocity; displacement-sensitive activity can emerge from event coincidences, and downstream circuitry can use it as needed.

## Shortest evidence path before promotion

1. **Generic scene suite.** Extend the opt-in event-camera tests to varied shapes, polarities, scales, positions, speeds, two independent movers, crossings, partial occlusion, stationary visual context, trajectory changes, and sensor noise. The generator may know hidden trajectories only for scoring. Establish performance and throughput of the full proposed front end, not just the isolated kernel.
2. **Grouping and memory experiment.** Test whether visually derived local motion plus persistent occupancy keeps separate entities distinct through crossings and brief occlusion, without ground-truth identity at inference. Score association switches, localization, visibility confidence, and recovery on held-out generated scenes. Compare to a simple event-only continuity baseline.
3. **Learning experiment.** Use repeated but varied generic visual interactions with visible local context (for example, moving patterns around arbitrary stationary shapes). Compare frozen, fixed extrapolation, and locally learned context-sensitive forecasts on held-out positions/shapes/interactions. Require a meaningful improvement at multiple horizons, no degradation on ordinary translation, causal updates, and no autograd. A context rule should be promoted only if it beats the matched fixed mechanism, unlike the current scalar efficacy.
4. **Out-of-distribution check.** Apply the same inference code unchanged to Pong event streams and at least one non-Pong visual sequence. Evaluate representation and forecast, not game-object extraction. A deterministic, nonlearning controller diagnostic is optional; no reward learning is needed for M1A.

These are experiments first. Promote only a mechanism that passes its gate, with an explicit production diff and tests reviewed before changing the in-place architecture. Current evidence supports further work on generic visual primitives; it does not yet establish coherent tracking or learned world dynamics.
