# Proposed generic M1A visual architecture

**Status:** Experimental proposal only. Do not change production M1A without user approval. This supersedes the withdrawn Pong-specific motion/world-state proposal.

## Objective and boundaries

M1A should convert ON/OFF event-camera evidence into a useful representation of coherent visual patterns and their likely future activity. It should work independent of the evaluation environment's object names or physics. Do not encode ball or paddle identity, image-column crops, walls, collision classes, intercepts, simulator state, or any game-specific target in M1A. Pong may be one held-out evaluation environment. M1B remains motor learning; a fixed controller can later test whether M1A forecasts are actionable.

Use no backpropagation. Preserve the measured connectome graph and transmitter signs as a biological reference; mark additional computational motifs explicitly rather than claiming they are measured synapses. Prior opt-in T5c/d activity shows that the graph can supply motion-selective signals, but subtype-rate direction was insufficient for small dots. The opt-in spatial event map and local displacement competition show stronger generic translation transfer across shape, position, contrast, and two speeds. Their learned scalar efficacy did **not** beat a matched fixed control.

## Candidate information flow

1. **Sensory access.** Keep signed ON/OFF events, local decaying sensory memory, and measured T4/T5 responses available. Fixed local event correlations may serve as low-level sensory primitives and explicit controls. They must **not** define the final motion code, object state, or prediction rule.
2. **Learned recurrent visual state.** Repeated local microcircuits receive raw sensory activity through initially uncommitted local synapses. Sparse competition and local Hebbian/homeostatic plasticity can form visual feature selectivity from experience; recurrent eligibility and each cell's predictive mismatch can learn temporal dependencies. The latent units should be free to encode whatever local visual structure improves prediction, including motion, persistence, texture, or interactions. No neuron is assigned an ON/OFF motion direction, object identity, speed, or game role by the implementation.
3. **Coherence and memory.** Interactions among neighboring latent units should support visual continuity, multiple simultaneous patterns, and uncertainty through brief missing evidence. The [generic grouping baseline](../experiments/2026-09-23-generic-grouping-findings.md) is a diagnostic ceiling only. Its explicit centroids, displacement estimates, and raw event integrator should not become M1A's learned representation. The noise failure shows that recurrent memory needs confidence or renewed sensory evidence.
4. **Predictive readout.** Decode likely future sensory activity or latent activity at several camera-frame horizons from the learned recurrent state. Delayed observations update local synapses using local eligibility and prediction error, without backpropagation. A matched frozen recurrent circuit, shuffled-time control, and fixed-correlation/extrapolation control are required. Learning must improve prediction and latent transfer beyond these controls before promotion.

The learned recurrent population is the central M1A representation. Correlation filters and explicit trackers can help test what information the sensory stream contains, but cannot substitute for evidence that recurrent plasticity discovers reusable structure. This order avoids forcing early L1/L2/L3 cells to supervise their own future activation or assigning direction/velocity labels to latent channels.

The [first learned-latent tests](../experiments/2026-09-23-learned-latent-homeostasis-findings.md) provide a narrow positive sensory-code result but expose a recurrent-learning failure. Homeostatic local Hebbian coding improved held-out direction readability, while a feedforward-selected code plus separate recurrent predictor failed to fit even training trajectories well. The next candidate must let recurrent activity influence the current inferred state and must distinguish conflicting local temporal contexts in its eligibility/credit; do not promote the current dictionary or recurrent rule as a working M1A representation.

## Shortest evidence path before promotion

1. **Generic scene suite.** Extend the opt-in event-camera tests to varied shapes, polarities, scales, positions, speeds, two independent movers, crossings, partial occlusion, stationary visual context, trajectory changes, and sensor noise. The generator may know hidden trajectories only for scoring. Establish performance and throughput of the full proposed front end, not just the isolated kernel.
2. **Latent discovery experiment.** Train a small, opt-in retinotopic recurrent circuit on raw event streams with no motion or object labels. Freeze it and test whether its state transfers across shapes, positions, polarity, and timing. Compare untrained, recurrent-frozen, time-shuffled, and fixed-correlation controls. Report forecast quality *and* whether simple post-hoc probes can read useful visual factors from the latent state; probes never train the circuit.
3. **Grouping and memory experiment.** Test whether interactions among learned latent units preserve separate patterns through crossings and brief occlusion, without ground-truth identity at inference. Score association switches, localization, visibility confidence, and recovery on held-out generated scenes. Compare to the explicit continuity ceiling and instantaneous-event baseline.
4. **Learning experiment.** Use repeated but varied generic visual interactions with visible local context (for example, moving patterns around arbitrary stationary shapes). Compare frozen, fixed extrapolation, and locally learned recurrent forecasts on held-out positions/shapes/interactions. Require a meaningful improvement at multiple horizons, no degradation on ordinary translation, causal updates, and no autograd. A learned circuit should be promoted only if it beats the matched fixed mechanism, unlike the current scalar efficacy.
5. **Out-of-distribution check.** Apply the same inference code unchanged to Pong event streams and at least one non-Pong visual sequence. Evaluate representation and forecast, not game-object extraction. A deterministic, nonlearning controller diagnostic is optional; no reward learning is needed for M1A.

These are experiments first. Promote only a mechanism that passes its gate, with an explicit production diff and tests reviewed before changing the in-place architecture. Current evidence supports further work on generic visual primitives; it does not yet establish coherent tracking or learned world dynamics.
