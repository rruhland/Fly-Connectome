# Air hockey, changed Pong and an arm with a moving camera

The earlier cross-body experiments did not include air hockey. This pass asks whether game experience changes the next game's actual results, and whether the previous arm learner can work from a new RGB view. All learning is online without backpropagation. Air hockey must permit planar mallet movement, puck impulses, wall rebounds, goals at both ends and play against an opponent. Judge score, wins earned after contact, saves and interaction cost. Count timeouts and matches that never reach a hit.

* Forward transfer begins from actual Pong play. Compare the acquired state to a reset of the same learned component. Compare an air-hockey-practiced learner with its pre-practice state on identical new matches. Report which features and tactics the designer supplied.
* Reverse transfer compares the same starting Pong learner after hockey practice, without extra practice, and after more Pong. Use actual changed Pong physics and evaluate opening and later performance separately. A target coefficient close to a practiced coefficient can produce immediate gains. Faster adjustment needs evidence beyond that effect. Keep independent opponent/shot and wall-model explanations open.
* For reaching, render RGB images and move the camera independently of the arm. Compare updates to stale motor calibration, and retain the physical four-tick hold criterion. Charge probe commands and timeouts. Separately test whether registering common visible landmarks can preserve the previous five-coefficient reward preference after a camera change. This test uses the 64 archived carriage source checkpoints, independent target layouts, and the three-joint position arm. Compare updated image registration, stale image registration and a fresh preference. Do not supply target geometry or true goal identity to any controller.

Development and confirmation seeds must be distinguished. Controls must receive the same available information and have the same target interaction budget. Distinguish simulating a camera and arm from operating hardware.

The directional camera test uses target schedule 434850, one new layout per each of 64 previously learned rules, with the same posture, targets, target motor RNG and rule across all four conditions. A second run keeps the camera at the previous location. Three colored fiducials are measured in an additional source-side registration exposure. One target exposure estimates the transform without consuming motor commands or receiving target reward. The control conditions keep the old transform, start preference weights at zero, or use weights acquired from shuffled source feedback. All conditions use raw RGB for controlling the endpoint and carry no motor priors.

An independent deployment course uses 16 first-to-seven hockey matches against the moving guard. Each point starts with a neutral, randomly directed center-line faceoff. The 32-point cap includes scoreless nine-second timeouts. Compare the frozen deployed checkpoint with the same Pong wall model and empty hockey reward memory. Both get the same start for every shared match/point index. Count wins, losses, capped games, unassisted serve goals and goals after the learner touched the puck. Training and evaluation never share these seeds.

The first-to-seven comparison will run against both the training-style laneguard and the separate default moving guard on identical neutral-faceoff schedules. This exposes any change in match outcomes when the defense changes.

The independent adjustment-rate test fits a scalar from causal next-bounce prediction errors on previously played source games. Both conditions enter new Pong with exactly the same ordinary Pong coefficient and motor state. Only the update rate crosses games. Alongside extra ordinary Pong practice, include fixed intermediate gain and direct latest-observation controls. Use native batched Pong, seed 3911060, sixteen streams per course with wall coefficients .39→.79, .79→.39, or 1→1. Each phase has three bank-return scenarios with a narrower paddle and one native opening with a standard paddle. Count actual returns separately from how rapidly the wall estimate changes. Declare these variations together when reporting play outcomes.

Camera projection and color segmentation were refined during development. Both moved and stationary arm checks will be repeated with the frozen camera on new target schedule 712640.
