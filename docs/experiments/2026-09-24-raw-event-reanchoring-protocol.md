# Raw-event sensory access after blank intervals

The previous local visual state receives only same-polarity event coincidences. In all eight archived brief-disappearance cases, the first reappearance frame (t=10) has 116 raw ON/OFF events in aggregate but **zero** coincidence-input activity; first appearance at t=2 is likewise invisible. Before redesigning the latent transition objective, test whether this sensory blind spot accounts for part of the failed re-anchoring.

Train the same 24-unit competitive local dictionary and delayed local predictive-error synapses from the same 96 unlabeled diverse clean episodes, same seed, local 5×5 field, one-frame target, and rates. Change only the sensory input from 16 coincidence channels to 18 channels: raw ON/OFF events plus the original 16 coincidence maps. The predictive target contains those same 18 channels, but the **registered event forecast decodes only the predicted coincidence channels**, exactly as in the prior learner. Thus raw events can alter learned state selection without adding a direct raw-event output path to the primary metric. No motion, shape, object, or game labels enter learning. Compare a matched random 18-channel dictionary and a time-shuffled target control, and reproduce the archived 16-channel learner.

Evaluate unchanged on 48 unseen single patterns and the frozen independent, crossing, speed-change, disappearance, and noise suites. Report event F1 by family and both speeds, post-reappearance t=10 to t=11 event F1, first-sighting code activity, quiet false alarms, and direction readability as a post-hoc probe. Useful evidence requires at least +0.15 post-reappearance F1 and +0.05 whole-disappearance F1 versus coincidence-only, no more than 0.03 loss on unseen clean and independent motion, and a material learned-code margin over random/shuffled controls. If raw access fixes re-anchoring but not hidden-interval forecasting, the next architecture experiment can target partial-observation state transition with sensory correction available. If it does not help, investigate why the learned dictionary ignores or misuses raw events before another recurrence design. This remains opt-in; production M1A is unchanged.
