# A source-local T2 signal survives the blank screen

The [preregistered frozen audit](2026-09-23-source-signal-protocol.md) ran from the pinned M1A checkpoint with no model, graph, or weight changes. The [machine-readable result](2026-09-23-source-signal-results.json) records input identities, all local/opposite-location and per-cell summaries, and the dot/bar/static controls. The T2 membrane-voltage differences reproduced the earlier subthreshold result at both x=18 and x=46 for both polarities; all T2 cells remained spike-silent in these probes.

Of the four causal high-pass candidates tested in each source class, **only positive T2 voltage relative to its own 250 ms exponential baseline passed the preset four-condition source screen**. Fractions of local moving-dot samples above the same cell's matched-blank p99 were 0.064/0.120 at x=18 ON/OFF and 0.090/0.177 at x=46, versus 0.009–0.010 on blank. Mean absolute local stimulus-minus-blank changes were 0.00132/0.00302 and 0.00218/0.00372, while opposite-location changes were at most 0.00005. The per-cell median signed change is near zero because the signal is sparse within each local group, but the positive-response tail reaches roughly 0.0045–0.0109 at p90. T2a and T3 did not pass at both locations and polarities. A positive high-pass current candidate missed the screen at x=18 ON and x=46 ON.

This is **a source-signal result, not transmission or learned prediction**. The T2 positive residual is causal and local, but a postsynaptic current from all T2 edges could still saturate on blank or fail to recruit Li15. The prior direct T2/T3→LC11 adaptive-voltage readout failed its own blank/output test, so this result does not override that failure. T2 bars produced stronger release-candidate modulation than moving dots, and OFF static dots drove a substantial T2 tail. Thus neither object selectivity nor motion specificity is established.

The next opt-in test will transmit only a bounded nonnegative release derived from this T2 residual along **every existing T2 outgoing edge**, replacing T2 spike output on those edges while retaining each edge's sign, magnitude, and delay. It will report the full downstream current distribution, particularly Li15, alongside matched blank and both dot locations/polarities. T2a/T3 remain spike-only in that first bounded test because their source variables failed the screen. If the T2→Li15 route cannot pass without blank saturation, expanding graded release to other classes is not justified by this audit alone; revisit sensory and cell dynamics as the approved amendment requires.
