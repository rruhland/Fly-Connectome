# Anatomically local Li15 release-state follow-up

The [all-cell Li15 audit](2026-09-23-li15-local-release-protocol.md) missed its four-condition positive-current screen at x=46 ON by 0.003 in above-blank sample fraction. Before attributing that to a missing biological signal, this bounded follow-up asks whether pooling all 21 Li15 cells included cells wired to the other tested location. No response label is used to define locality.

Infer T2 visual columns from its measured Tm2/Mi1 afferents, exactly as in the frozen source audit. Define x=18 and x=46 T2 source groups from the same retinal regions used there. Sum **measured contact counts** from each source group into each Li15 target. A Li15 cell belongs to a location group only if that location's incoming T2 contact mass strictly exceeds the other tested location's mass; ties are excluded. Freeze these masks before inspecting the graded response. The wiring-only inspection found nine Li15 cells in each dominant group and three ties.

Repeat the same frozen T2 graded probe and 250 ms causal positive/negative Li15 voltage/current residuals with the previously selected blank-only cap. Report source contact masses, cell counts, and the all-21 comparator alongside each local group's matched ON/OFF blank, dot, bar, and static results. Apply the *unchanged* source-information screen: one fixed candidate must have finite state, at least 3% local samples above its own matched-blank p99, at most 2% on blank, and at least 0.0005 mean absolute modulation in all four dot combinations. A pass would justify only a separately gated opt-in inhibitory Li15-output test; it cannot override the failed T2→Li15 transmission criterion or promote production architecture.
