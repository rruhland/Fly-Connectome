# One frozen extension beyond LPi targets

The LPi34/LPi43 probe showed clear T5-derived local feedforward direction signals, but their somata never spiked and predictive arrivals were absent in some otherwise valid motion cases. Before selecting a downstream learning target, run one fixed extension of the same frozen probe to **LLPC2, LLPC3, and VS** alongside the LPi controls. They are chosen from measured wiring before seeing dynamic outcomes: LLPC2 receives 18,661 T5c contacts with 1,128 predictive incoming edges; LLPC3 receives 21,613 T5d contacts with 893 predictive edges; VS receives 24,463 T5d contacts with 291 predictive edges. Keep all stimuli, gate-on/off states, signs, gains, and 8-tick timing unchanged. Report T5-derived and total local feedforward direction contrasts, postsynaptic spikes, and the count of actually arriving predictive edges at both calibration positions and withheld center/speeds. A candidate for local learning must show direction-bearing feedforward targets **and** nonzero predictive arrivals in each calibration and withheld condition; static graph connectivity alone is insufficient.
