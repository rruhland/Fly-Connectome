# Generic occupancy and grouping baseline

The opt-in diagnostic received only signed ON/OFF event maps. Integrating their local polarity into a persistent contrast field and grouping connected occupied pixels gave one visual component on **13/13** frames for each of four translated shapes at both contrast polarities, and for a stationary shape after its onset. Instantaneous event components had the right count on only **1/13** frames in each clean case: the leading/trailing event edges or quiet stationary period do not themselves form a stable object. Persistent local visual state is therefore necessary even in this simple suite.

For two visually identical same-polarity shapes crossing, occupancy showed two separate components on **12/13** frames and one merged component at full overlap. An explicit, generic constant-motion continuity baseline preserved two latent tracks on **13/13** frames and recovered the original identities after separation with no center error. This is a transparent **engineering ceiling**, not evidence that a biological local circuit or learned M1A representation has solved grouping. It uses no game semantics, but it does explicitly maintain group centers and inferred displacement.

The same raw integrator failed completely on a stationary shape with 10% event dropout and independent 0.1% false events per polarity/pixel/frame: component and track counts were correct on **0/13** frames, and mean tracked-center error was 11.49 pixels. False events can create long-lived phantom occupancy. A one-time false event and a genuine isolated persistent pixel can produce the same later event-only stream, so a fully general solution needs confidence/prior structure or a renewed local visual measurement; merely retaining every event forever cannot provide reliable visual memory. A later experiment should compare biologically plausible local support/confidence with occasional absolute sensory refresh, including small objects where spatial-size filtering would erase real evidence.

No production architecture changed. The successful clean tracker is a ceiling for grouping experiments, not an M1A candidate to promote as-is.
