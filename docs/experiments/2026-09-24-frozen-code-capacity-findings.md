# Frozen-code future-decoder capacity result

This evaluation-only diagnostic froze the experience-learned sensory and transition dictionaries, then fit a sparse ridge-linear map from their existing local 5×5 output field to the next observed ON/OFF event image. The offline solver is **not** an M1A learning rule and its weights must not enter production. The transition-code probe reproduced **34/48** held-out direction cases, confirming the same code as the earlier experiments.

On square training scenes, the linear readout reached **0.859 event F1**, compared with **0.362** for the local predictive-error readout. A readout on random transition codes reached **0.897** training F1. Every next event in both training and held-out scenes lay within an active unit's reachable local field (**100% coverage**). Thus output radius and raw event reachability are not the present limitation; the biological local credit/readout underfits a function that this local field can fit on training data.

Transfer was poor. On held-out plus/L/bar shapes, the learned-code linear readout scored **0.303 F1** versus **0.213** for random transition codes and **0.977** for the fixed low-level correlation control. The learned-code advantage was 0.089, below the registered 0.10 gate, and absolute F1 was far below 0.70. The learned decoder scored **0.229** at one pixel/frame and **0.351** at two. Its fixed threshold profile peaked at **0.309** (threshold 0.3), so output calibration is not the main held-out gap. This does not prove all decoders would fail, but the severe training-to-held-out drop shows the current learned code plus local linear readout is not sufficiently reusable across shape.

Two bottlenecks are now distinct: the tested local predictive-error update does not even fit the square training set, and a stronger evaluation-only decoder overfits that square experience. The next decisive experiment is to train the **same unlabeled circuit** on a diverse distribution of connected moving shapes, then evaluate on new held-out shapes and positions. If the frozen-code capacity ceiling transfers much better, focus on redesigning local predictive credit. If it does not, change the recurrent visual state/invariance mechanism before another readout rule. No production M1A architecture changed.
