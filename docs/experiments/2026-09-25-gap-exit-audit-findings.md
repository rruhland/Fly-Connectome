# The learned history is present during a gap but cannot forecast its exit

The [registered frozen-weight audit](2026-09-25-gap-exit-audit-protocol.md) separated the last blank frame → reappearance transition from the already measured observed reappearance → next-motion transition. Across 48 unseen-shape/direction/speed/contrast cases per window, each gap-exit target had **608 signed event pixels**. The early two-frame, familiar three-frame, and late four-frame windows all gave **zero true positives, zero false positives, and 608 misses** for the learned history readout, archived predictor, fixed raw control, and their simple fusion.

The learned code's decaying motion trace remained nonzero in **all 144 last-blank frames**, while the readout had **zero active sources** on every one. This follows from the current raw-onset gate: a new observed event is required to select a history unit and emit a forecast. After that observation arrives, the same learned readout predicts the following event at 0.427, 0.434, and 0.380 F1 for the two-, three-, and four-frame gaps. These are real learned, transferable **post-observation** forecasts, but the circuit does not yet bridge invisible motion with an autonomous future-event prediction.

The oracle calculation also limits the proposed reliability-gate direction. On full three-frame occlusion sequences, a selector that retains every correct learned-only event and rejects every learned-only false positive could improve fixed raw F1 from 0.716 to at most **0.747**. That is below the registered 0.766 target. The same oracle ceilings are 0.789 on early two-frame scenes and 0.721 on late four-frame scenes. Suppressing erroneous additions cannot recover event pixels the learned pathway never proposes. A reliability gate alone is therefore insufficient for this frozen circuit.

The next bounded capacity check should ask whether the **existing trace at the last blank frame** spatially covers and distinguishes the coming signed reappearance events under a local readout. Use a frozen, evaluation-only decoder trained on generic training shapes and test held-out shapes, directions, speeds, contrasts, positions, and gap lengths. If the information is present, test an opt-in continuously active local readout with online credit and quiet-frame controls. If it is absent, a learned recurrent transition must propagate latent state during missing evidence. Do not promote the current onset-gated circuit as a generic world model. Production M1A remains unchanged.
