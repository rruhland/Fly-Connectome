# Learned continuity and common-fate binding in the live visual state

**Status:** One bounded opt-in M1A architecture experiment. Earlier delayed-pair units carried transferable direction information, but their live state fragmented and temporal weights affected only forecasts. This test makes local temporal continuity and common-fate association part of state formation itself. It is the final test of this sparse paired-unit family before a keep-or-pivot decision; production M1A remains unchanged.

Freeze the fast predictor and aligned delayed-pair sensory code trained on the same 64 unlabeled generic scenes. Learn two spatially shared, local 5×5 kernels from sparse unit activations. A temporal kernel counts which unit/site follows each active unit/site at the next meaningful observation. A lateral kernel counts neighboring unit pairs that have a common locally observed displacement in the following observation. Normalize outgoing local counts per presynaptic unit. These are local Hebbian associations, with no gradient tape, labels, oracle object regions, reward, or Pong-specific input. At inference, current sensory winners, predicted continuations from the previous recurrent state, and lateral common-fate support jointly form the new bounded state. Quiet camera frames decay the state without inventing new transitions. The existing fast prediction plus the frozen pair-unit future decoder reads this state into a full signed event forecast. No future evidence is available at inference.

The aligned arm and a time-shuffled arm have identical initialization and training exposure; the latter shuffles future sparse observations within each episode before learning both kernels. A frozen-feedback arm uses the same live-state update with only fixed self-continuity and no lateral association. The original sparse paired state and fast-only predictor are references. All gains, footprint, thresholds, winner budget, training episodes, and evaluation cases are fixed before running.

Evaluate full-frame next-meaningful-event top-8/top-32 recall and precision on held-out generic, position, doubled-speed, changed-shape, separated, and crossing scenes. Evaluate the fixed offline 3×3 direction probe. More importantly, measure significant live-state activity outside offline object neighborhoods and connected components per active frame: a lower component count alone is insufficient if the field spreads beyond the moving evidence or merges crossing entities. Oracle centers are used only after inference. Report paired-case wins, not only aggregate recall.

For a keep decision, the aligned field must beat both shuffled and frozen fields on speed and shape forecasting, preserve fast-only top-32 recall within three points on each, retain at least 14/16 spatial direction accuracy on both, reduce excess components on separated movers to at most 0.5/frame, keep outside-neighborhood activity at or below 30% there, and avoid a crossing collapse. Otherwise reject this sparse paired-unit family as the current M1A direction and pivot to a substantially different representation architecture. Do not tune or branch into nearby variants on this held-out set.
