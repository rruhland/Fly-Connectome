# Frozen predictive-input support for the T5 motion target

Before trying another local learning rule, measure what the existing **measured predictive edges into T5c/d** physically carry in the successful opt-in Tm9-release/T5-order circuit. Use the pinned checkpoint, unchanged graph/signs/delays and no training. Replay up/down vertical bars at y=10/y=22 speed one and withheld y=16 speeds one/two, starting each case from the same blank-calibrated state. Select local T5 cells by the established anatomy-to-retina field map; preserve eight ticks/frame and matched opposite-direction event counts.

At each camera-frame boundary in frames 3–13, sample each T5 cell's signed predictive current and count actual arriving predictive edges during the preceding eight ticks, with positive/negative signs and source classes. Define the target as the **next frame's** maximum local T5 order current (event if >0.05), and separately count next-frame T5 soma spikes. For each subtype/direction/location, report future event fraction, fraction of future events with a nonzero predictive current (>1e-6) or a recent predictive arrival, and mean absolute/signed predictive current on event versus quiet samples. Include blank/static controls for source activity if inexpensive; no fitted decoder or parameter sweep.

A basic capacity prerequisite for a local frame-horizon credit rule is at least 50% predictive-current support on future gate events in each calibration and holdout condition, and a reproducible event-versus-quiet predictive-current difference in the expected direction. This is **not** an online-learning pass. If support is absent, do not spend another eight-minute 40-episode run merely to increase learning rate or trial count; identify missing presynaptic arrival/timing first. If support is present, a separately versioned local rule can target the motion-selective T5 state while keeping all updates on measured incoming edges and no backprop.
