# One faster Tm4 release baseline, with new spatial/tempo controls

The [first physical Tm4 supplement](2026-09-23-tm4-graded-findings.md) nearly passed its moving/static gate but raised T5c static spikes. Test a single **50 ms** source-current baseline in the same opt-in release law, instead of the original 250 ms baseline. This shortens the duration of release after a sustained local current while keeping Tm4 and Tm9 neural dynamics, weights, graph edges, signs, delays, caps, spike output, eight neural ticks/frame, and the T5 order current fixed. The choice is one preregistered temporal profile, not a sweep.

Repeat blank-only cap selection over 0.01, 0.03, and 0.10 with the same finite-state, T5 impulse p99 ≤0.05, and blank T5 spike-rate <0.01 gates. Run the same matched baseline/supplement motion, static, and blank conditions at y=10/speed 1, y=22/speed 1, y=16/speeds 1 and 2 to permit direct comparison. Add **new controls** y=14/speed 1 and y=18/speed 2, without calibration on those labels. Use the same pinned checkpoint and anatomy-local T5c/d groups.

The same frozen-feature screen applies across all six cases: on baseline-defined T5d/up future-gate events at y=16/speed 2, Tm4 arm support must reach 55% and gain at least eight percentage points; both subtypes must preserve their opposite direction signs with absolute contrast at least ten spikes and per-cell majority agreement; preferred-moving/static spike ratio must be at least 1.5 and at least 90% of the comparator in every case; and blank T5 spike rate must remain below 0.001/neuron/tick. Report each component, including new controls, whether the screen passes or fails. A pass would justify a separately preregistered local afferent-plasticity experiment, not in-place promotion.
