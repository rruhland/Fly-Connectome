# Frozen sensory-plus-history full-scene check

The locally learned history forecast uniquely predicts post-gap motion across several interruption timings, while a fixed raw-event correlation control is much stronger on ordinary visible translation. Test whether these are complementary **at the forecast output**, without replacing the learned visual state with a hand-specified motion representation.

Load the frozen balanced-exposure models saved by `scripts/gap_timing_transfer.py`; do not retrain, tune, or change weights. Combine the fixed raw-event correlation forecast with the learned sign-conditioned history forecast by the same pixelwise maximum used in earlier opt-in comparisons. Compare fixed alone, fixed plus learned history, fixed plus random-history code, fixed plus learned unsplit code, and the archived correlation-input predictor with and without learned history. The fixed raw control is a low-level sensory primitive only; no direction channel, tracker, object label, or Pong semantic enters it.

Evaluate full next-event sequences on the unchanged unseen single-pattern and generic robustness suites: independent movers, crossings, three-frame occlusion, speed changes, and noise. Report F1, true/false positives, and quiet-target false alarms by family. Recheck exact reappearance and gap-quiet behavior on the same 48-case early two-frame and late four-frame windows using frozen weights. A viable combined forecast must improve full-sequence occlusion F1 at least 0.05 over fixed raw alone, improve exact reappearance by at least 0.10 over fixed plus random and unsplit controls in both unseen timing windows, avoid more than a 0.03 F1 regression in every other family, and keep quiet false alarms below 1.5 times fixed raw. If the learned component fails to add broad value, do not promote a fixed-primitive-dominated predictor as learned M1A.

No production architecture changes in this experiment. A passing result would justify preparing a concrete production integration proposal for user approval, followed by throughput and broader distribution checks before claiming M1A complete.
