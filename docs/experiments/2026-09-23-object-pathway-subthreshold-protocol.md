# Read-only T2/T2a/T3 object-signal test

The measured T2/T2a/T3→LC11 route is strong, but the current simulated T2/T2a/T3 cells do not spike under the frozen dot/bar probes. Test whether their existing *membrane and incoming-current state* contains an object signal before introducing any graded transmission or LC11 neuron into an opt-in model.

Use the pinned initial checkpoint with exact weights, fixed signs, 8 neural ticks/frame, 500-tick warm state, and matched ON/OFF blanks. Do not alter dynamics or plasticity. For T2, infer approximate columns from measured Tm2/Mi1 afferents; for T2a and T3, use measured Mi1/Tm1 afferents. Map only the afferent annotation centroids to the existing retinal hex grid. Report coverage and contact mass. These inferred columns are for readout only.

At x=18 and x=46, replay the same right-moving radius-1.5 dot and 3-by-13 bar for both event polarities, plus a static dot onset/offset control. At each of 144 neural ticks, compare per-cell voltage and total synaptic current with a blank restored from the same warm state. For each class and center, report local and opposite-location cell counts, local/remote mean absolute voltage modulation, signed modulation, peak per-tick local modulation and tick, and the analogous current values; preserve the compact 144-tick aggregate trace. Also report local spikes and event counts. The transit window is frames 3–14, matching earlier probes.

The prespecified screen for a useful subthreshold object signal is: for **each** polarity at **both** centers, at least one of T2, T2a, or T3 has dot transit mean absolute local voltage modulation ≥0.002 (0.2% of spike threshold), at least twice the same class's opposite-location modulation, and at least five local cells whose time-averaged absolute voltage modulation exceeds 0.002. These are conservative signal/locality checks, not a trained decoder or proof of motion selectivity. Compare dot to bar and static, but do not select a profile based on those controls. If the screen fails, do not implement an LC11 readout; investigate the upstream transduction and class dynamics instead.
