# Frozen-weight transfer across interruption timing

Balanced generic exposure raised the opt-in local history-plus-polarity readout to 0.434 exact F1 on the familiar three-frame gap, but whole-sequence occlusion improved only slightly. This experiment tests whether that online-learned representation generalizes to different **gap durations and times**, with no retraining on the new gaps.

Train the identical 192-episode balanced corpus and candidate/control set from the registered balanced-exposure experiment. Freeze all model weights. Generate unseen-shape center-position trajectories across four directions, two speeds, and two backgrounds, with three interruption windows: early two-frame gap `(6, 7)`, familiar three-frame gap `(7, 8, 9)`, and late four-frame gap `(8, 9, 10, 11)`. These give 48 cases per window; the new gaps have no examples in training. Use the same deterministic event camera and motion generator, no object or direction labels at inference.

At each window, report signed-event F1 and counts for a pre-gap ordinary-motion transition, the first reappearance-to-next-frame forecast, and the following motion transition. Report false-alarm pixels on quiet targets inside the gap. Compare the learned sign-split model with learned unsplit, random sign-split, local-history reset at reappearance, the archived learned correlation predictor, and a fixed raw-event correlation control. Do not change the learning rule, threshold, emission field, source code, or evaluation protocol after inspecting results.

Useful timing transfer requires at least 0.30 exact reappearance F1 for **both** new gap windows, a 0.10 F1 advantage over random and unsplit on each, and no more than twice the archived quiet false-alarm count plus one pixel per scored quiet frame within the gaps. The additive allowance keeps a zero-alarm archived baseline from making the gate mathematically impossible. Report the pre-gap and follow-up behavior regardless. Failure means the three-frame transition result is too specific for a production M1A world-state proposal; investigate temporal credit/state dynamics before promotion. This remains opt-in and changes no production code.
