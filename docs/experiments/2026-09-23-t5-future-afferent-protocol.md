# Is the passing T5 order state predictive of future measured input?

The 50 ms opt-in Tm4 release passes a frozen spike-direction gate, but the next learning target must not be defined solely by that same gate. On the unchanged pinned checkpoint and 50 ms Tm4/Tm9 opt-in circuit, replay the six position/speed cases from the [release experiment](2026-09-23-tm4-fast-release-protocol.md), with matching up/down moving bars, static bars, and bright blanks. Keep weights frozen and record physical feedforward-arrival increments on each measured T5c/d target, including Tm4 and Tm9 graded arrivals, while preserving ordinary spikes. No new model state or training is added.

At forecast boundaries in frames 3–13, read each T5 cell's own **causal pending order current** after the current frame's first neural tick. Define an independently measured target as whether that cell receives positive physical feedforward-arrival increment above 0.01 at any of the **next eight neural ticks**. Compare event-versus-quiet order-state means and ROC AUC for the preferred subtype/direction pair (T5c/up, T5d/down), for both the spike-only-Tm4 comparator and the fast Tm4 supplement. Report null-direction, static, and blank controls separately; do not tune the event threshold, T5 order gain, or any weights on these labels.

The representational preflight passes only if, for the supplemented circuit, each preferred moving subtype/case has at least ten future afferent events, event-state mean at least twice quiet-state mean, and event/quiet AUC at least 0.70 across all six cases. Also require the static fraction with pending order current >0.05 to be no more than half the matched preferred-moving fraction, and blank event fraction below 0.001. A failure means the frozen motion feature cannot yet serve this next-frame learning objective; it does not undo the prior direction-selectivity result.
