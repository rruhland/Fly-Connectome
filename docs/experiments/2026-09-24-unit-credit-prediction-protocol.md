# Unit-normalized local credit for history-gated event prediction

The learned history code makes direction locally readable at 599/608 held-out reappearance sites, yet the current event-emission update predicts only rightward motion. Its update divides each synaptic error contribution by the **total** number of active sources in a frame, coupling the update size of a unit to unrelated units elsewhere. This opt-in experiment tests one local credit change: for each presynaptic unit, average eligible 5×5 event error over only that unit's active sites, then apply the same learning rate 0.5 and clamp weights to [0,1]. No future label beyond observed camera events, backpropagation, or game semantics is introduced.

Train the same locally learned and random history dictionaries with the same seeds, episodes, and two passes. Train four event readouts for one pass on the same 96 clean plus 32 generic interruption/noise episodes: the original global-denominator rule on the learned code, the per-unit rule on an identical learned code, the per-unit rule on the random code, and a trained per-unit learned readout with trace reset before reappearance. Keep archived coincidence prediction and pixelwise maximum combination unchanged. Use the registered 0.5 event threshold.

Score unseen single patterns, the original five robust families, quiet-target false alarms, training interruption t=10→11, and the full 144-case held-out interruption suite across three unseen shapes, four directions, two speeds, two contrasts, and three positions. Report exact reappearance F1 and true positives by direction. A useful rule must achieve nonzero true positives in **every** direction, at least 0.05 absolute F1 over both the original rule and trained random-code control on the 144-case suite, clean single-pattern F1 within 0.03 of archived, and quiet false alarms below twice archived. If it fails, stop this credit variant and reassess the event objective rather than sweeping its rate or threshold. Production M1A stays unchanged.
