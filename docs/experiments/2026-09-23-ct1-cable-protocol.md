# Does CT1 cable geometry select a different local input arm?

Use the official MaleCNS v1.0 **CT1_L body 10009 SWC skeleton** and the previously deduplicated CT1-side Tm1/Tm9 input and T5c/d output sites. The official SWC and synapse coordinates are both in 8 nm voxel units. Cache the skeleton under ignored `runs/`, verify its node/parent tree and report each synapse site's distance to its nearest skeleton node. Stop if the median attachment error exceeds 125 voxels (~1 µm), if any output site has no cable path to an input site, or if pair counts differ from the raw connectome.

On the SWC tree, assign every input synapse to its nearest skeleton node. Use multi-source shortest paths weighted by segment length to find the cable-nearest measured input for every output synapse, including the endpoint attachment lengths. Keep all source body/column labels, T5 target identities, and synapse counts fixed. Compare cable-nearest to 3D-nearest assignments: source-body/column change fractions, cable-distance quantiles, and source-minus-target vertical hex offsets at y=10/y=22 and withheld y=16. Average offsets within each T5 cell and bootstrap cells with a fixed seed for 95% intervals, as in the prior offset audit.

A cable-local assignment is worth a frozen opt-in CT1 simulation only if it reverses the preferred-leading spatial sign **consistently**: T5c's cell-mean source offset becomes negative (source above), T5d's becomes positive (source below), with each 95% cell-bootstrap interval excluding zero at both calibration fields and the holdout. This is a conservative *screen for an inhibitory input arriving before null motion* under the current retina map, not proof of electrical branch identity. If it fails, stop the nearest-input CT1-shadow family; do not tune gain, radius, or k. No production change follows from this morphology audit alone.
