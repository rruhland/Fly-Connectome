# Event-only Pong state and forecast ceiling

This opt-in M1A diagnostic asks whether the existing 32×64 ON/OFF camera stream contains enough information to form useful ball state and forecasts before committing to a new neural readout. It makes no network or production change. Run 16 deterministic Pong seeds for 800 rendered frames each with a fixed zero motor drive. Reconstruct a binary occupancy map **only from camera events**; exclude the two paddle columns and take the centroid of remaining lit pixels as the visible ball observation. The tracker uses no simulator coordinates, velocity, object label, or reward at inference. Its scene assumptions (one ball and paddles at fixed x extremes) make it an engineered ceiling rather than a learned perception result.

At horizons 8, 16, and 32 camera frames, compare three forecasts: observed-position persistence, observed constant velocity from the current and eight-frames-earlier centroids, and privileged-state constant velocity (diagnostic ceiling only). Score Euclidean position error against actual future ball position on the **same eligible samples for all three methods**, requiring both visual observations and no rally reset before the target. Report sample coverage and error. Stratify by no direction reversal, wall reversal, and paddle reversal using privileged velocity **only for analysis**, never prediction. Also report event-only observation coverage and localization error. If observed constant velocity fails in free flight, characterize quantization/visibility before designing an online world-model rule. If it succeeds there but fails around reversals, a local event-triggered transition model is the next opt-in learning test.
