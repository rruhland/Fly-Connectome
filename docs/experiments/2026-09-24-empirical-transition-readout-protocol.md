# Empirical local-transition readout diagnostic

The learned transition population transfers some direction information across shapes, but delayed local predictive-error synapses fit even training trajectories poorly. Freeze the **same learned sensory and transition dictionaries** and estimate each existing local outgoing synapse as the observed frequency of a next-frame sensory-code event at its relative 5×5 target site, conditional on its presynaptic transition unit firing. This local co-occurrence table uses no labels, changes no topology, and is a diagnostic comparator rather than a proposed biological learning rule. Compare it with the saved error-rule result and a table whose future confirmation targets are shuffled while the ordered inputs and transition codes remain fixed.

Use the same 96-episode square training set, held-out plus/L/bar scenes, frame targets, polarity and speed breakdowns, and fixed-correlation sensory control. No rate or threshold tuning. If the empirical table materially improves held-out next-event F1 (at least +0.15 absolute over 0.188) **and** training fit (at least +0.15 over 0.362), the current predictive-error credit/normalization deserves replacement. If it remains weak, that only weakens the case that this one-step local transition code is sufficient; the table is not an optimal decoder, so it cannot prove insufficiency. Record candidate MSE and fixed-threshold F1, and leave production M1A unchanged.
