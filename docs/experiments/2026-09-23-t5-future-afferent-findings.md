# Raw future T5 afferent arrivals are dominated by blank activity

The [independent-target preflight](2026-09-23-t5-future-afferent-protocol.md) replayed the passing 50 ms Tm4 circuit without changing any weights or dynamics. Instead of calling T5's future order gate the learning target, it measured the **next-frame physical feedforward-arrival increment** on the same measured T5c/d cells. The [result](2026-09-23-t5-future-afferent-results.json) preserves the prior frozen direction-feature pass, but the predeclared future-afferent screen **fails**.

The raw positive-arrival threshold of 0.01 labels roughly **24–28% of bright-blank samples as events**, reflecting autonomous presynaptic activity even with almost silent blank T5 spiking. On preferred moving trials, the supplemented T5 order state's event/quiet ROC AUC is only **0.575–0.613** at one pixel/frame and **0.508–0.517** at two pixels/frame, below the required 0.70. The 250 ms Tm4 comparator is worse (about 0.529–0.556 at speed 1 and 0.440–0.458 at speed 2), so the faster physical source helps but does not rescue this raw objective. Static order activation is lower than moving activation; the dominant failure is the noisy future-arrival label and weak fast-tempo separation.

Do not train against this raw target or treat the passing motion-feature gate as proof of prediction learning. The next narrow diagnostic is to pair each trial with its matched bright-blank physical arrival trace and ask whether **stimulus-driven arrival deviation** is distinguishable at the same forecast horizon. That offline pairing is a capacity test, not a runtime learning rule; if it helps, test whether a causal cell-local baseline can approximate it without access to a replayed blank. If it fails, reconsider the target/horizon before designing afferent plasticity. Production architecture remains unchanged.
