# History-selective code gated by raw first sightings

The concatenated raw+trace dictionary discarded opposite pre-gap histories: its t=10 winner sources were identical despite different trace input. This opt-in representation test makes a substantive, bounded change: raw ON/OFF activity gates **where** a history code may fire, while competitive unit identity is learned from the prior motion trace alone. The trace is still a decaying record of the existing unlabeled learned coincidence latent. No direction, shape, object, Pong, or future label trains the code; post-hoc labels are used only for evaluation. There is no forecast readout in this first test.

Freeze the same 24-unit learned motion population, 0.8 per-frame trace, and eight-pixel pooling radius. Train an eight-unit history-only competitive dictionary with two local Hebbian/homeostatic passes over the same 96 clean plus 32 generic interruption/noise episodes. At sites with raw events and no current coincidence, expose the spatially pooled trace to that dictionary; without trace it receives zero. Compare to the same eight-unit random dictionary and to a reset-trace ablation. Keep the event sequence and seeds fixed.

First test a matched left/right reappearance pair with identical t=10 camera input. Require the learned code to choose different unit sources at least half of common active sites; count source differences for random and reset controls too. Then form a simple **evaluation-only** per-episode histogram of selected units at reappearance. Fit direction prototypes from four training shapes and test on three unseen shapes over four directions, two speeds, and two contrasts (48 cases). Direction labels never update the visual code. A useful learned representation should reach at least 75% held-out probe accuracy and exceed the random dictionary by at least 10 percentage points. Report active-site coverage and effective unit use.

If either gate fails, do not train another event forecast from this code or sweep its radius, decay, or unit count. If both pass, proceed to local delayed-event prediction with reset and zero-history controls. Production M1A remains unchanged.
