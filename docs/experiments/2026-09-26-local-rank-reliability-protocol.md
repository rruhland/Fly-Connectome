# Locally learned reliability for two-stream visual forecasts

**Status:** Registered opt-in M1A readout experiment. The [two-stream comparison](2026-09-26-complementary-prediction-findings.md) found strong complementary top-32 coverage, but fixed equal-rank fusion diluted high-confidence entity predictions in the top eight. Production code and connectome anatomy stay unchanged.

Train the existing fast sensory field and signed diagonal affinity on the same 64 unlabeled generic streams. Replay those streams with online entity files. For each stream's ranked, positive next-event predictions, a shared source/polarity/rank synapse estimates the chance that its predicted pixel appears in the next meaningful event. Update that estimate with the **local** observed-minus-predicted event error at that pixel; do not backpropagate through either predictor. Rank competition is an opt-in normalization probe, not a claim of biological implementation. Train a time-shuffled-credit readout on exactly the same predictions with unrelated future event observations. Freeze both readouts for the held-out transfer audit; entity state continues its ordinary local online update within each episode.

Compare fast-only, entity-only, fixed equal-rank fusion, aligned learned reliability, and shuffled-credit reliability on the same generic held-out, calibration, changed-position, changed-speed, changed-shape, separated, and crossing cases. Score signed full-frame top-8/top-32 next-event recall and top-32 precision, retaining per-case hits. Record learned reliability by stream/rank/polarity. No true count, identity, object crop, direction label, game concept, reward, or held-out-selected parameter enters training or inference. Do not sweep rank budget, priors, smoothing, or gain on transfer cases.

**Decision rule:** The learned readout is a useful M1A direction only if it beats shuffled credit and stays within three top-32 recall points of equal fusion on generic, changed speed, changed shape, and separated cases, while improving top-8 recall toward entity-only on those transfer sets. If it cannot, do not promote a rank-based readout or hand-tune its blend; investigate a local predictive context mechanism instead. Even a passing readout does not fix false entity births under event noise or crossing identity, and production promotion still requires separate review.
