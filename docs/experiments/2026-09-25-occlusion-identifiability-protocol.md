# Is exact reappearance timing identifiable from the visual stream?

The passive-trace emitter and two local credit rules failed to produce a reliable complete-scene forecast. Before choosing the next recurrent-state target, test a generic causal ambiguity in variable-duration occlusion. Generate the same moving pattern with identical position, direction, speed, contrast, and disappearance start, but hide it for two, three, or four camera frames. If two episodes have identical ON/OFF event histories up to time *t* yet different next events, no deterministic visual-only model can be correct on both; a world state must carry a distribution over visibility while it propagates possible hidden motion.

Use the existing deterministic event-camera scene generator with the three held-out shapes, four directions, two speeds, both backgrounds, and three positions. For each of 144 scene configurations, generate gap windows `(7,8)`, `(7,8,9)`, and `(7,8,9,10)`. Compare the two- and three-frame episodes through frame 8 and their frame-9 targets; compare the three- and four-frame episodes through frame 9 and their frame-10 targets. Report exact input-prefix identity and signed target-event disagreement counts. No model is trained, no hidden simulator variable enters a predictor, and no production code changes.

If all or most prefixes are identical while targets differ, the next opt-in architecture should learn a compact hidden motion state separately from a calibrated sensory visibility/event head and be evaluated with probability-sensitive scores as well as thresholded event F1. This is a statement about the test distribution's available information, not proof that a particular neural implementation can learn it. If prefixes differ, inspect the sensor signal before asserting intrinsic uncertainty.
