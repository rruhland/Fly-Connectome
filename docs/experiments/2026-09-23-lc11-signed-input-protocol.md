# Full measured-input check of the LC11 shadow readout

The excitatory-only T2/T2a/T3 shadow readout failed because autonomous voltage variation drove blank release. The anatomical audit showed that many other selected M1 neurons also contact LC11, including sources with inhibitory transmitter assignments. This final bounded opt-in comparison tests whether those **measured signed inputs** can suppress false output or expose dot-specific modulation.

Start from the adaptive 250 ms source-local baseline and the same `0.05, 0.10, 0.25` release fractions. Expand the shadow bank's incoming edge list from T2/T2a/T3-only to **every** raw MaleCNS contact from a pinned M1 neuron to a traced right LC11 cell, retaining `gain × contacts`, each source's pinned transmitter sign, and one-tick delay. Non-T2/T2a/T3 sources transmit their unchanged frozen-network spikes; only the existing T2/T2a/T3→LC11 contacts use bounded graded output. No other source is graded and there are no new edges. The isolated bank still lacks LC11 outgoing/feedback connections and uses a common 5 ms input-current decay, so this is a test of signed input balance rather than a complete LC11 physiology model.

Report excitatory and inhibitory measured contact mass, source-class activity, spike-only readout, matched blank/dot current and spikes. Apply **exactly** the previous x=18 ON/OFF dot criteria: at least five excess spikes per polarity, blank rate <0.01, finite state, and peak active fraction ≤0.20. Only the smallest passing release fraction may advance to frozen x=46/opposite-direction/bar/static checks. If none passes, stop the LC11 point-soma readout branch and propose a specific temporal or compartmental model based on the measured failure, rather than another gain, rest-current, or time-constant sweep. This remains an opt-in experiment and does not alter production architecture or plasticity.
