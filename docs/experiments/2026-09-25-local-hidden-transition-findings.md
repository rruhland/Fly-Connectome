# Locally learned hidden transition: a useful motion state, not yet an event forecast

**Status:** Opt-in experiment. Production architecture unchanged. Protocol: [local hidden transition](2026-09-25-local-hidden-transition-protocol.md); machine-readable [results](2026-09-25-local-hidden-transition-results.json).

A zero-initialized, translation-shared 24→24 local recurrent transition learned from one pass over 96 clean moving-pattern episodes. Its input was the saved locally learned 24-unit visual code. Each update used only the previous local state and the next locally visible latent mismatch; no backpropagation, motion label, object ID, simulator state, or Pong rule entered learning. Hidden state was never emitted as a camera event.

On 144 unseen visible shape/position/speed/contrast cases, one-step latent **spatial occupancy** F1 was **0.792** over 1,440 scored frames (predicted/target active-site ratio 1.25). Frozen zero weights and episode-shuffled credit produced no predictions at the 0.5 threshold. This establishes that the locally learned transition transfers across position and unseen shapes for this controlled moving-pattern task.

On 432 paired gap cases (144 per gap length, including two translated positions per condition), the last-blank hidden-state occupancy F1 was **0.585 / 0.504 / 0.315** for two-/three-/four-frame gaps. Active-site ratios were **0.92 / 0.71 / 0.44**—no state explosion. Static holds from the first blank frame scored **0.178 / 0.072 / 0.074**; frozen and shuffled transitions scored zero from the second blank frame onward. A post-hoc centroid readout showed displacement in the correct direction in **132/144, 141/144, and 99/144** cases respectively. Four-frame state survived in only 102/144 cases, so longer memory remains limited.

Resetting hidden state at gap entry barely reduced F1 (**0.567 / 0.500 / 0.300**). The first disappearance observation can seed motion state anew. Resetting immediately *after* that observation eliminated later blank-frame activity. Thus recurrence causally propagates a learned moving state, but the current test does **not** show that pre-gap recurrent memory is necessary when the disappearance event remains visible. The occupancy and centroid readouts are evaluation-only; they do not constitute a learned visible-event forecast.

The transition chunk clears its predefined visible and gap occupancy thresholds and beats static persistence. Advance to a separately scored visible-evidence likelihood on matched-prefix uncertain histories. Keep this transition opt-in while testing whether a local head can express calibrated event probability without turning every hidden-state continuation into a false camera event. The four-frame attrition and weak pre-gap reset effect must remain explicit in any later joint forecast claim.
