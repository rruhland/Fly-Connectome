# Event-versus-quiet local credit audit at T5

The 40-episode vertical T5 pilot updated 1,050 measured predictive edges but barely changed held-out event prediction; 132,941 of 151,260 nonzero proposals were negative. Rerun the **same frozen 40-episode training sequence and rule** without evaluation, accumulating each confirmed next-frame proposal by its own postsynaptic local target: event if `|feedforward arrival| > 0.01`, quiet otherwise. Keep the original eta, eligibility, source/gate profile, graph, signs, and synchronization. Confirm that the run reproduces the original updated-edge count and weight-change scale.

Report event/quiet nonzero proposal counts, positive/negative fractions, signed and absolute proposal mass, and per-edge event/quiet sums for every measured T5c/d predictive edge. Define a conflict edge only when it received both categories with **opposite signed cumulative proposals**. Report counts of both-category and conflict edges, the direction of the conflict, and aggregate cancellation `1 − |event_sum + quiet_sum|/(|event_sum| + |quiet_sum|)` on those edges. This is a diagnostic of local credit, not a new learning rule. A majority of both-category edges in conflict would justify a bounded opt-in local event/quiet balance experiment; weak overlap or same-sign credit would instead point toward eligibility timing or objective magnitude.
