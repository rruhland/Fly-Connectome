# Learned local transition-unit experiment

The prior winner-selection feedback did not resolve one-pixel/frame prediction or beat a time-shuffled control in latent readability. Test a distinct opt-in circuit whose **unassigned local transition units** receive both the current learned sensory code and nearby code from the preceding camera frame. Sparse competitive Hebbian/homeostatic plasticity learns which spatiotemporal conjunctions recur; no unit is assigned a direction, speed, object, or game role. A separate local synapse from each active transition unit to nearby next-frame sensory units changes only after the visual observation arrives, by postsynaptic predictive error × the active presynaptic unit's eligibility. The current sensory dictionary is learned from raw events, then frozen before transition-unit learning so the experiment isolates the new population. No backpropagation or production M1A change.

Use the same square training distribution and held-out plus/L/bar shapes, positions, speeds, and polarities as the prior probes. Train the transition dictionary first, then the predictive synapses, both from ordered event streams. Compare a random frozen transition dictionary, a matched predictor trained with **shuffled confirmation targets while seeing the same ordered sensory stream**, the previous recurrent-inference result, and the fixed local-correlation predictor. Post-hoc direction labels may train a small nearest-centroid readout solely for evaluation. Report transition-unit occupancy, four-way held-out probe accuracy, next-latent and next-event F1 by speed/polarity, threshold profiles, training fit, and runtime. Treat this as promising only if the learned transition code transfers materially beyond its random dictionary and predictive learning beats shuffled future credit for **both** speeds; the fixed correlation remains a difficult sensory ceiling on simple translation.

Stop after this comparison. If the learned transition population still cannot predict its own training sequences well, re-examine the local credit objective and sensory-to-latent target alignment instead of tuning another scalar rate.
