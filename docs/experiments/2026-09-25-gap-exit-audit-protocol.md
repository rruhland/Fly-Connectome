# Audit the forecast before reappearance, not only after it

The balanced online history learner predicts the next event **after** a raw reappearance event is observed. Whole-scene fusion barely improves a strong fixed sensory control. Before testing a reliability gate, measure what the frozen learner predicts on the last blank frame, when the reappearance event is still in the future. The code is raw-onset gated, so the expected limitation is zero emission despite nonzero decaying motion history.

Load the saved balanced weights without retraining. On the unchanged unseen-shape early two-frame, familiar three-frame, and late four-frame gaps, score three transitions separately: last blank frame → reappearance, observed reappearance → next motion event, and following motion event. Report target-event counts, F1, learned source counts, and whether the local motion-history trace persists at the last blank frame. Compare learned history alone, the fixed raw-event control, their pixelwise maximum, and the archived correlation-input predictor. Also calculate from the existing full-scene result the best F1 possible if an oracle rejects every *extra* false positive from the frozen learned output while retaining all its extra true positives; this bounds any selector that only gates those additions.

If the last-blank-frame forecast is absent while the trace is present, classify this circuit as **observation-conditioned post-gap prediction**, not autonomous gap bridging. In that case, a reliability gate cannot meet the registered +0.05 full-scene occlusion target if its oracle ceiling is below that target. The next opt-in architecture experiment should let locally learned predictive state produce activity during absent evidence, with controls for drift and quiet false alarms. This audit changes no model weights or production files.
