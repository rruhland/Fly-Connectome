# CT1 inhibition aligned to each T5 cell's local feedforward event

The geometry-routed CT1 shadow failed the whole-episode null-suppression gate. Opposite bars traverse the same locations in reverse order, so separately test whether its current is correctly phased around *each T5 cell's own* excitatory arrival. Keep the frozen checkpoint, measured geometry route, current/release parameters, T5 gate, contact totals, signs, and delays fixed. Start every off/on moving trial from the same blank-calibrated state. Use the existing y=10/y=22 speed-one conditions and withheld y=16 speeds one/two; bright/static controls and equal event counts have already been checked in the parent frozen experiment.

For each anatomy-local T5c/d cell and each up/down trial, use the **off arm's** largest positive non-CT1 feedforward-arrival increment between ticks 24 and 119 as its anchor. Include cells whose peak is at least 0.005 in *both* directions. The shadow-injected CT1 current is excluded from this anchor by construction. At each direction's own anchor, compare on-arm CT1 inhibitory impulse in ticks −8…+8, especially pre-event −4…0 versus post-event +1…+4. Also compare off/on spikes within ±4 ticks around that anchor, and record whether CT1 changes the ordinary feedforward arrival at the anchor. Use the same cell set for preferred and null motion (T5c prefers up, T5d down).

A potentially useful local timing signal requires, at both calibration fields and both withheld conditions for each subtype, greater **pre-event** CT1 inhibition in null motion for a majority of cells with nonzero CT1 current, at least 10% fewer null-window spikes, and at least 90% retained preferred-window spikes. Report failures as failures; do not change the existing whole-episode rescue result or tune any parameter. If pre-event null bias fails despite anatomically null-side inputs, the next question is CT1 source-release timing or electrical branch dynamics, not another scalar gain sweep.
