# First learned-local-latent result

This opt-in circuit learned a 12-channel local sensory dictionary from raw recent ON/OFF event patches and learned nearby latent-to-latent transitions using delayed **postsynaptic latent prediction error × presynaptic local eligibility**. Neither direction nor object labels entered training. It made 96 online training episodes and then froze all synapses.

The held-out plus/L/bar four-way direction probe did **not** show reusable structure. The complete sensory-plus-recurrent state scored **13/48 (27.1%)**, versus **19/48 (39.6%)** for a temporally shuffled recurrent control. The learned sensory code alone scored **20/48 (41.7%)**, below the random initial dictionary's **23/48 (47.9%)**. The learned recurrent forecast scored **0.129 next-event F1**, versus 0 for shuffled temporal credit but **0.977** for the fixed local-correlation control. Nearly all one-pixel/frame cases scored zero, repeating the cross-tempo weakness seen in the scalar triplet learner. This circuit cannot be promoted as an M1A representation.

The dictionary did change (mean absolute synaptic change 0.099), but only 7/12 channels were used on held-out scenes; effective channel count was 6.78. It used winner-take-all without the homeostatic balancing called for in the architecture proposal, so dead channels and uneven polarity/tempo coding are plausible contributors. The next bounded diagnostic is **one** homeostatic competition variant, with all other training and evaluation conditions fixed. If that does not materially improve cross-shape latent transfer and slow-tempo prediction, stop tuning this small prototype and reconsider the local learning objective/state organization.
