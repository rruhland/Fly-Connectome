# T5 afferent history is available, but one fast Tm4 arm and static specificity remain limiting

The [same-target frozen comparison](2026-09-23-t5-arm-capacity-protocol.md) used the exact future T5 motion-gate samples from the [recurrent-capacity audit](2026-09-23-t5-predictive-capacity-findings.md). The script asserted identical cell/event counts and recurrent support for every condition. The [result](2026-09-23-t5-arm-capacity-results.json) shows a large support difference: local Tm4/Tm9 current-plus-delayed residual history was present on **94.7–99.7%** of next-frame gate events across the position/speed tests, versus **20.7–51.2%** for recurrent predictive current. Tm9 alone covered **92.2–99.0%**. Tm4 covered **52.5–73.2%** in 15 of 16 moving subtype/direction/condition cases, but only **46.9%** for withheld y=16, two-pixel/frame **T5d upward** motion.

Arm-history magnitude was **3.8–7.3× higher on future event than quiet samples**, and the already computed local order current was higher on event than quiet in all 16 moving cases (roughly **6–26×**). Thus the existing measured afferents and local timing state carry much more usable forecast-time information than the sparse T5-to-T5 recurrent pool. This is an availability/association observation, not a trained predictor. The strict predeclared upstream-capacity screen **fails** because of the one Tm4 coverage shortfall, so the proposed afferent-plasticity run should wait for a source-state check rather than relaxing its threshold after the fact.

The static-bar control matters: its future T5 gate events also had essentially complete arm-history support. A rule that merely teaches T5 to reproduce its own gate could reinforce some static responses. Any local learning experiment must measure moving-versus-static selectivity and blank safety alongside anticipation, and use a target that preserves temporal order rather than only gate occupancy. The next bounded audit should determine whether Tm4 has subthreshold local current when its outgoing spike-driven arm is absent in the fast T5d/up holdout. If so, one opt-in graded Tm4 release experiment on the same measured edges is biologically and computationally narrower than inventing a new timing network. Production topology, signs, delays, and learning remain unchanged.
