# Homeostatic learned-latent result

One bounded homeostatic-competition variant made the unlabeled sensory dictionary substantially more usable. Its effective held-out channel count rose from **6.78 to 11.20 of 12**. A post-hoc nearest-centroid direction probe trained only for evaluation on square sequences reached **33/48 (68.8%)** on held-out plus, L, and bar shapes, versus **23/48 (47.9%)** for the matched random initial dictionary and **20/48 (41.7%)** for the first learned variant. No direction labels entered the visual synaptic updates. This is preliminary evidence that local sensory plasticity can discover reusable spatiotemporal structure, from one fixed seed and this limited synthetic distribution.

The recurrent component did **not** meet the M1A objective. The complete sensory-plus-recurrent state scored **32/48 (66.7%)**, while its temporally shuffled recurrent control scored **33/48 (68.8%)**. Held-out next-event F1 at the registered 0.5 threshold was **0.147**, compared with **0.977** for the fixed local-correlation control. Direct next-latent F1 was only **0.045** (0.002 at one-pixel/frame speed). The circuit fit its *training* square trajectories poorly too: event F1 **0.234**, latent F1 **0.288**. Thus the main failure is not merely held-out-shape transfer.

A post-result threshold diagnostic tested 0.05, 0.1, 0.2, 0.3, and 0.5 without changing training. The best held-out event F1 was **0.283** and best latent F1 **0.214**, both at 0.2. Output amplitude explains part of the 0.5-threshold score, but not the large prediction gap. The shuffled-time control remained much worse in event prediction, so the causal update contains some useful temporal signal; it is far from a working recurrent world state.

The next architecture experiment should change the state/credit organization rather than tune this prototype's penalties or rates. In this circuit the sensory winner code is selected without recurrent feedback, so recurrence predicts a code but does not help **form** the current latent state. Local synapses also receive a shared scalar mismatch across incompatible temporal contexts. Test a genuinely recurrent inference state, with local competition and context-dependent eligibility, against this frozen prototype and the fixed low-level sensory control. Require both better latent transfer and materially better next-event/next-latent prediction on training and held-out scenes before production promotion. No production M1A code changed.
