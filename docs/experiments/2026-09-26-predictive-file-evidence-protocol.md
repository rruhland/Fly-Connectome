# Predictive evidence for file birth, survival, and local future events

**Status:** Registered opt-in architectural experiment after the [zero-shot transfer failure](2026-09-26-zero-shot-visual-transfer-findings.md). An audit of one Pong seed showed that native-cadence entity files usually emit a nonempty rigid forecast yet rarely hit the next event; coarser cadence had many entirely empty file forecasts. This is more than a silent-neuron or one-tick issue. The current files also overbirth under false events because every new confident surface region is immediately a long-lived live entity.

Test a unified hierarchical-evidence hypothesis. A newly unexplained sensory region begins as a **provisional** file, still able to match subsequent local evidence. It becomes live when either its own continuation is reobserved or an independently trained fast-field forecast supported its birth at the same signed local pixels. A provisional file with no confirmation expires after 20 frames, the approximate 99th-percentile clean reobservation gap measured only on the 64 generic training streams. For a live file, combine its existing rigid translated-support forecast with fast-field future-event evidence restricted to a three-pixel neighborhood of its own observed support. This keeps the file's persistent identity and limits borrowed evidence to a local receptive field. All support and updates are visual and local, with no backpropagation or object labels. The fast predictor and learned diagonal affinity are trained on the original 64 unlabeled generic scenes and frozen for transfer; no Pong or noisy test exposure is used for fitting.

Compare five opt-in file arms: original immediate/rigid; provisional confirmation with rigid forecast; immediate birth with local fast-conditioned forecast; both confirmation and local fast-conditioned forecast; and both with time-shuffled fast support. Evaluate full-frame signed next-event top-8/top-32 recall, live-file count and total births on generic clean position/speed/shape/multiple-entity/crossing cases, four Pong seeds at both camera cadences, and the same held-out corrupted generic streams as the prior audit. For corrupted input, score against clean next events. The original fast-only field is the independent reference. No object count or identity enters inference. A stationary true mark with only one isolated event may remain provisional and indistinguishable from an isolated false mark; report that limit explicitly.

**Decision rule:** Continue this family only if the combined arm materially reduces noisy live-file overbirth, beats shuffled support, improves Pong file-only forecast beyond the rigid baseline without sacrificing clean speed/shape, and retains useful generic entity state. If confirmation merely hides genuine small/static entities or fast conditioning only duplicates fast-only predictions, reject this version rather than sweep lifetime, radius, or fusion gain on held-out sets. Production promotion still requires user review.
