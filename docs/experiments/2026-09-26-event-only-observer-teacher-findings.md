# Event-only observer teaching and sparse-frame sensor audit

**Decision:** Keep both input options explicit. Event-only local agreement can train the observer enough for the *clean* context task, but it does not yet support robust noisy M1A.5. Sparse intensity frames help noisy inference somewhat, yet do not solve the observer's original privileged training-teacher assumption or the current state tracker’s noise sensitivity. Production M1A is unchanged.

The existing observer was trained with every-frame exact rendered-intensity changes. The opt-in comparison observer instead used only causal same-polarity neighboring/recent event agreement as local credit on 64 corrupted generic training streams. No clean event, rendered intensity, object label, or future target entered that observer's update. On separate corrupted scenes, mean strength at true/false arriving-event sites was **.876/.062** for the privileged observer and **.959/.259** for the event-only-taught observer at the familiar corruption level (.1 dropout, .001 false-event rate). At heavier corruption (.2/.002), it was **.817/.068** versus **.947/.311**. An untrained observer gives .5/.5. The event-only rule keeps more true activity but admits substantially more false activity; these are averages over 858 true/1,242 false events at familiar noise and 751/2,554 at heavy noise.

Each observer then trained the same local context-memory association from visible experience. Both reached **16/16 clean top-32 hidden-location hits**. The table shows noisy held-out top-32 hits out of 16 using the original low-level event admission threshold:

| Observer training | Familiar noise, events only | Familiar noise, events + sparse frames | Heavy noise, events only | Heavy noise, events + sparse frames |
|---|---:|---:|---:|---:|
| Exact rendered-intensity teacher | 2 | 5 | 2 | 4 |
| Event-only local agreement | 2 | 3 | 1 | 1 |

Sparse frames arrive every eight camera frames and contain only the visible rendered scene. They are an additional input channel, not a cost-free replacement for event sensing. They improve the privileged model from 2/16 to 5/16 at familiar noise, but remain far below the clean 16/16 result. They do not provide the exact *every-frame* intensity-change target used to train that observer. The event-only learning arm avoids that privileged teacher, but its weaker false-event rejection and the tracker’s fragile proposal/association step leave noisy hidden-state localization almost absent.

One preselected stronger admission threshold (.4 instead of .05) was tested against the measured true/false event-strength gap. With the privileged observer it lost a quarter of the clean context and constant-motion cases (12/16 rather than 16/16), while familiar-noise context stayed at 2/16 event-only and 5/16 with sparse frames. The event-only-trained observer kept clean context at 16/16, but familiar-noise event-only remained 2/16; sparse frames reached 4/16. This rules out a simple global cutoff as the repair. The next substantial experiment should replace brittle binary event admission and greedy tracklet association with a locally updated, confidence-weighted multi-entity belief state that can suppress isolated false events, preserve weak true ones, and revise identity after missing evidence. It should be tested once across noise, occlusion, multiple movers, shape/position transfer, and disappearance, then compared with the frozen sensory and engineered tracking controls. Do not tune more thresholds on this data.

Reproduce with `.venv/Scripts/python scripts/run_event_only_observer_teacher.py`; [raw results](2026-09-26-event-only-observer-teacher-results.json) contain both training methods, both sensor arms, both admission thresholds, and the clean transfer/disappearance checks. The context-state code remains opt-in research code.
