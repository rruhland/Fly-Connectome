# Bounded current-driven Tm9 transmission to T5

The [frozen T5 arm-order audit](2026-09-23-t5-arm-order-findings.md) found nearly absent Tm9 arrivals in local T5c/d at x=46, despite a strong local Tm9 OFF current residual at its source. This opt-in test replaces Tm9 spike output with a bounded nonnegative release fraction derived from **that cell's own total synaptic current**, through every existing Tm9 outgoing edge. It keeps recorded signs, delays, pathways, and contact-scaled magnitudes and makes no in-place architecture, learning-rule, or checkpoint change.

Use the pinned checkpoint and the already calibrated opt-in Tm4=Tm9=0.85 rest currents for comparison with the T5 arm-order run. Warm 500 no-event ticks with ordinary spikes, then for each release cap restore the same state. The source release is `clip((I_i(t) − EMA_250ms(I_i)(t−1) − q99_i)/0.02, 0, cap)`; `q99_i` is that Tm9 cell's positive-current residual 99th percentile over the last 128 warm ticks. This source state is causal and local; no stimulus label, direction, future event, Pong state, or trained readout enters it. Try caps 0.01, 0.03, and 0.10, settle 256 no-event ticks, and select the largest with finite state, p99 absolute added T5 impulse no more than 0.05, and blank T5 spike rate below 0.01 per neuron/tick in the last 128 ticks. Stop if none qualifies.

At the selected cap, restore the same settled state before matched bright blanks, right/left moving OFF bars, and static OFF bars at x=18 and x=46, 18 frames and eight neural ticks/frame. Tm9 source groups use direct anatomical columns; T5c/d local target groups use the fixed Tm1/Tm2 afferent-column inference. Report local and opposite-location Tm9 release, per-cell T5 added impulse, total current, voltage, spikes, blank activity, and bar/static controls. The **partial Tm9→T5 transmission screen** requires both moving directions at both locations to have local Tm9 release above its matched-blank p99 in at least 5% of source samples, local T5c and T5d mean absolute added-impulse modulation at least 0.0005, and each subtype's p90 per-cell absolute voltage modulation at least 0.002, with the selected blank limits preserved. Passing justifies rerunning the fixed eight-tick arm-order diagnostic on this opt-in state; it does not pass T5 direction selectivity or M1A learning.
