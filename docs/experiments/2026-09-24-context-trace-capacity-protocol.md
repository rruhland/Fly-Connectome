# Frozen local capacity of temporal context at reappearance

The locally trained trace pathway received different inputs for opposite histories but emitted identical forecasts. This evaluation-only diagnostic asks whether its **frozen learned context units** contain future-event information at all. The readout below uses offline least squares solely as a capacity probe; it is not an M1A training rule and cannot be promoted as local learning.

Recreate the same trained trace and zero-trace eight-unit populations with the same seeds and 96 clean plus 32 interruption/noise episodes. Freeze them. Fit the existing 5×5 sparse local linear decoder using only t=10 source activity and t=11 raw events from generic interrupted sequences of four training shapes, four directions, two speeds, and both polarities (64 cases). Test on the eight frozen disappearance cases built from **unseen diamond/ring shapes**, and on a matched opposite-motion pair whose t=10 camera input is identical. Include the trained trace code with its trace reset just before t=10, and the separately learned zero-trace code. Keep the threshold at 0.5 and report training/held-out F1, local reach, source-unit differences between paired histories, and forecast differences. No decoder gradients enter the latent.

If the trace code exceeds both reset and zero-trace controls by at least 0.15 absolute held-out F1 and gives different useful forecasts for the matched pair, its representation is sufficient for this local readout and the online credit/objective is the immediate blocker. If the trace code itself is nearly identical across matched histories or all frozen local decoders fail held-out prediction, the context representation remains inadequate. Intermediate results leave both causes open. Do not tune the threshold or reuse the offline readout as a production predictor.
