# Local competition for generic visual transitions

The [unlabeled triplet learner](2026-09-23-generic-local-transition-findings.md) lost all one-pixel/frame predictions because faster motion also activated its one-pixel coincidence. Test one architectural hypothesis in an **opt-in experiment**: each local 7×7 neighborhood chooses the strongest of eight same-polarity, one- or two-pixel event displacement coincidences. Only the winning coincidence emits a prediction and receives delayed local visual credit. No object, direction, speed, future-position, or game label enters the learner. The kernel size is an experimental locality choice, not a claim about measured connectome cells.

Reuse the exact training distribution, learning rate, held-out shapes/position, targets, and unit-efficacy control from the original test. Add a separated two-mover scene in which the movers have different directions **and speeds**, plus the same static controls. Success requires every held-out shape × speed × polarity combination to achieve F1 above 0.8, the mixed-speed scene to exceed 0.8, and no repeated static false predictions. Compare the overall score with the original 0.699 learned and 0.847 fixed-unit controls. Do not promote this mechanism based only on the simple translation task; later gates must cover noisy scenes, coherent grouping, occlusion, changes in trajectory, and longer horizons.
