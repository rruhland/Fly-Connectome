# Bounded opt-in T3 small-target operating-point check

Primary fly experiments implicate T2/T3 inputs to LC11 in small moving-object detection, with T3 providing excitation and responding to both ON and OFF transitions ([study](https://pmc.ncbi.nlm.nih.gov/articles/PMC7210872/)). The pinned M1 graph contains T3 but intentionally excludes LC11. In the existing frozen dot/bar audit all 976 T3 cells emitted zero spikes. This experiment tests whether T3 itself can carry useful small-object events before considering any graph expansion.

Keep the pinned graph, weights, signs, delays, sensory projection, 8 ticks/frame, and plasticity-off full-graph model. Change only T3 rest current **in memory** at `0, 0.85, 0.95, 1.05, 1.15`, one value at a time. Restore from a 500-tick no-event warm state for each matched dot/blank probe. Infer each T3 cell's approximate retinotopic column from its existing Mi1/Tm1 afferents, reporting coverage and contact mass; never use that inferred location as neural input.

Calibrate only at x=18 on a radius-1.5 moving dot, one direction, both ON and OFF. Select the smallest current with at least five **excess local spikes** versus matched blank for **both** polarities, finite state, and blank T3 rate below 0.01 spikes/neuron/tick. If no value passes, stop. If one passes, freeze it and evaluate the opposite direction, x=46 held-out location, and 3-by-13 bar/static controls. Report local and global responses, event counts, and motion/static differences. Do not tune on direction, x=46, Pong, or prediction loss. No in-place roster change, LC11 addition, or learning-rule change occurs in this experiment.
