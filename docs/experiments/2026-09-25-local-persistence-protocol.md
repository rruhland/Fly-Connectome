# Bounded local hidden-state persistence branch

**Status:** Opt-in architecture experiment; production remains unchanged. The [variable-cadence update](2026-09-25-variable-cadence-transition-findings.md) changed weights but did not support native event timing.

Keep the successful fast-motion sensory dictionary and learned local transition frozen. Add one local leaky hidden-state branch with a four-camera-frame time constant (decay `exp(-1/4)`): where current local sensory evidence is absent, the hidden state takes the stronger of the usual learned motion continuation and a decayed copy of its own previous state. Current sensory evidence still reanchors the state. The branch has no object, velocity, occlusion, or Pong labels; it is intrinsic local memory, not a visible camera event. Use the existing transition weights to forecast next latent activity. Compare this single registered decay with the unchanged fast transition and previous-code persistence. No parameter sweep.

Evaluate native-rate Pong event-camera streams using the four-frame local sensory trace, plus independent and crossing generic scenes using the original adjacent-frame input and paired generic three-frame disappearance scenes. Report active-frame latent occupancy F1 and predicted/target active-site ratios. Require native F1 at least 0.10 above previous-code persistence, independent/crossing F1 within 0.05 of the unchanged transition, and no more than 2× target active sites in any family. If these fail, stop simple hold/decay variants and reconsider the hidden-state temporal representation; do not promote this branch to production.
