# Event-derived state and a local transition rule work in bounded Pong tests

The [event-only Pong ceiling](2026-09-23-m1a-pong-state-ceiling-protocol.md) reconstructed the ball from ON/OFF events without feeding simulator state into inference. It used a deliberately engineered interior-column crop to exclude paddles; this is a diagnostic ceiling, not a neural object representation. Across 16 seeds × 800 zero-drive frames, it observed the ball on **89.3%** of frames with mean localization error **0.0083** screen units. On the same eligible samples, observed eight-frame velocity improved 16-frame free-flight position error **0.07385→0.03071** versus persistence, and 32-frame error **0.14694→0.05347**. The [machine result](2026-09-23-m1a-pong-state-ceiling-results.json) includes 8-frame scores, privileged-state velocity ceilings, coverage, and wall/paddle strata. Around reversals, ordinary extrapolation was substantially worse.

The separate [local event-correlation control](2026-09-23-m1a-event-correlation-protocol.md) used same-polarity causal coincidences at one- and two-pixel offsets with an eight-frame trace. It changed no graph weights or production architecture. It decoded **20/20** dark-square directions and **4/4** bright-square directions over the tested positions/speeds, with zero matched static false alarms and zero blank scores. A moving bright square creates both ON and OFF events, so that control does not isolate ON-pathway sufficiency. On the same 16×800 Pong stream, x-direction evidence was active on **45.2%** of frames and correct-sign **98.5%** of those; y evidence was active on **20.8%** and correct-sign **78.2%**. The [result](2026-09-23-m1a-event-correlation-results.json) shows that a simple shared local temporal motif restores small-object direction in the controlled task, but its sparse and less reliable vertical Pong evidence cannot by itself sustain continuous state.

The [online local wall-transition test](2026-09-23-m1a-local-wall-model-protocol.md) issued visual forecasts, retained each local reflection feature, and updated one gain only when the future **event-derived** position arrived. It trained on seeds 0–7 and froze before testing seeds 8–15. At 16 frames, the learned gain was **0.801** after 275 visual update examples; held-out wall-reversal error fell **0.04639→0.01553** versus observed constant velocity, while free-flight error changed **0.03069→0.02961**. At 32 frames, the gain was **1.001** after 502 examples; wall error fell **0.09411→0.05293**, with free-flight **0.05344→0.05003**. A fixed unit-reflection comparator was similar to the learned 32-frame result but worse at 16 frames. Paddle-reversal error remained high. The [result](2026-09-23-m1a-local-wall-model-results.json) records common-mask sample counts and errors. The reflection feature uses known image bounds and a simple fixed form; learning only fits its gain. It is evidence that delayed local visual error can improve a useful forecast, not proof of a general world model.

Together these tests justify an M1A architecture discussion, not an immediate claim of completion. A fixed event-local motion motif supplies reliable controlled direction; an event-derived state supports useful free-flight forecasts; and a no-backprop local update transfers a wall correction to held-out trajectories. Still missing are position-independent object association, reliable vertical motion evidence on sparse Pong frames, learned paddle-collision forecasting, a fixed-controller actionability check, and an integrated CPU-speed measurement. Reward-modulated motor learning remains M1B.
