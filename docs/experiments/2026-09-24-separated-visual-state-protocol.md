# Separate local latent continuity from visible-event prediction

Test an opt-in state-space extension of the learned correlation-input visual code. Freeze the successful 24-unit unlabeled competitive dictionary. At each frame its event-driven winners are the **observed** latent activity. A separate local recurrent synapse bank predicts the next latent activity; that prediction can remain active when observed primitives are blank. Update recurrent synapses only where new local sensory evidence permits comparison with observed winners. Predict next visible ON/OFF events through **separate local synapse banks** from observed and predicted-only latent sources. Update these event-emission synapses from next-frame observed event error, including quiet targets. All synaptic credit is local and delayed one frame; use no backpropagation, object labels, motion labels, or new graph claims. The predicted latent is internal state and is never itself emitted as a camera event.

Train from the same frozen dictionary on the 96 existing varied clean episodes plus 32 generic interruption/noise episodes built solely from training shapes. Compare: (1) recurrent state plus two emission banks, (2) the same local emission rule with recurrence disabled, and (3) the established local primitive-prediction learner retrained on the identical 128 episodes. Keep the archived 96-episode learner as a reference. Evaluate on the original 48 unseen-shape cases and the frozen independent-mover, crossing, speed-change, disappearance, and noise suites. Report training F1, held-out F1 by family, quiet-target false-alarm pixels, and latent activity on blank-input frames. A fixed sensory correlation forecaster remains the external control.

The recurrent candidate is useful only if it raises disappearance or noise event F1 by at least 0.05 over **both** matched controls, retains clean-single and independent-mover F1 within 0.03 of the matched primitive learner, and keeps quiet-target false alarms within 20% of that learner. If recurrence has no measurable advantage over the no-recurrence emission arm, separate readout rather than temporal state caused any gain. If train fit is poor, stop before more expensive sweeps and diagnose the local credit/readout. This is an experiment; production M1A remains unchanged.
