# Paired-blank upper bound for the next-frame T5 afferent target

The [raw future-arrival target](2026-09-23-t5-future-afferent-findings.md) labels 24–28% of bright-blank samples as events. On the **same frozen 50 ms opt-in circuit**, pair each moving/static physical T5 feedforward-arrival trace with the bright-blank trace from the same settled network state, same cell, and same neural tick. Define the next-frame stimulus-driven target at forecast boundary `t` as `max_{u=t+8..t+15}(arrival_stimulus(u) − arrival_blank(u)) > 0.01`. Keep the causal T5 pending order current at `t` as the candidate forecast state. This paired subtraction is an offline counterfactual upper bound; it is not available to the live learner.

Replay the original four position/speed cases and the new y=14/speed 1 and y=18/speed 2 controls, up/down moving, static, and bright blank, from restored frozen states. No weights, graph edges/signs/delays, neural dynamics, release law, or order gain change. For each T5c/up and T5d/down preferred pair, report future target prevalence, event/quiet pending-order means, ROC AUC, and the corresponding raw-target AUC. Report null-direction and static target prevalence, so blank subtraction cannot hide broad onset responses.

The upper-bound screen requires at least ten paired future events per preferred subtype/case, event-order mean at least twice quiet-order mean, and event/quiet ROC AUC at least 0.70 on **all six** cases. Also require static paired-event prevalence below half the matched preferred-motion prevalence. Passing would only motivate a separate causal, cell-local baseline test; failing would rule out simple baseline correction as the remedy for this frame-horizon objective.
