# Frozen vertical T5 local-learning pilot

The axis-aligned opt-in T5 model has causal, transferable OFF vertical spike tuning, but no learned prediction. The preflight found measured predictive edges entering T5c/d and repaired the experimental captured feedforward-arrival target so it includes physically delivered graded Tm9 current. This pilot asks whether the existing **frame-horizon local prediction update** can improve T5's own next-frame afferent-current forecast. It is not Pong acceptance and does not change the production graph or learning loop.

Keep the frozen checkpoint, eight ticks/frame, Tm9 source-current release cap .10/scale .02, Tm4/Tm9 rest .85, T5 order current gain 8,000/cap 1.0, signs, delays, and all non-target weights fixed. Restrict the existing `FramePrediction` rule to measured predictive edges **entering T5c/d**; its update remains `eta_prediction × (next-frame local feedforward arrival − forecast) × causal local eligibility`, with the checkpoint's eta and bounds. Reward is zero. Run 40 contiguous 18-frame training episodes, cycling up/down vertical OFF bars at y=10 and y=22 at one pixel/frame. Do not reset neural state or eligibility between episodes; synchronize at each camera frame, preserving online learning. Record the number and sign of actual T5-edge updates, weight change distribution, local target event fraction, rate and stability.

Evaluate the trained weights and their own original frozen weights from the **same blank-calibrated neural state** on both training positions and withheld y=16 at one and two pixels/frame, with equal-event opposing trajectories. Score next-frame T5c/d feedforward-arrival prediction using all-target MSE, event-only MSE, quiet-only MSE, and signed event anticipation, with event defined as target magnitude above 0.01. Compare also with zero and one-frame persistence. A pilot passes only if trained weights beat their frozen comparator by at least 10% on held-out event MSE at both speeds, quiet MSE rises by no more than 10%, and event anticipation increases for both T5c and T5d without weight-bound or firing instability. If no T5 edges receive credit, report a credit-path failure; if updates occur but prediction worsens, report an objective/credit-conflict failure. Do not sweep gains or retrain to fit the holdout.
