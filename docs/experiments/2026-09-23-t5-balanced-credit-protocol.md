# Bounded local event/quiet balance at T5

The fixed 40-episode T5 credit audit found opposite cumulative event and quiet proposals on 740 of 999 synapses receiving both categories. Test **one** opt-in, postsynaptically local metaplasticity variant on the same vertical task. Do not change the physical network, measured graph, graded release, T5 timing current, frame horizon, target, eligibility, error sign, base eta, bounds, trial order, or evaluation set.

Each T5c/d cell maintains separate 0.98-per-camera-frame exponentially decaying counts of its own event and quiet confirmations, initialized to one each. At an event confirmation (`|local feedforward arrival| > 0.01`), multiply that cell's existing `eta × error × eligibility` proposal by `clamp(quiet_count / event_count, 1, 4)`; quiet proposals keep gain one. Update both local counts **after** applying the current confirmation. The cap four is fixed before this run from the prior audit's approximate 3.3:1 absolute quiet/event proposal-mass imbalance; it is not fitted on the held-out trajectories. Track gain distribution, event/quiet proposal mass, changed edges, and firing stability. This is a local rule amendment **only in the opt-in experiment**.

Train exactly 40 continuous episodes on y=10/y=22 up/down one-pixel/frame OFF bars, then compare balanced trained weights with the same frozen initial checkpoint on y=16 at one and two pixels/frame and on the training positions. Use the same metrics and pass gate as the preceding local-learning pilot: at least 10% improvement in held-out event MSE for both T5c/d and directions/speeds, quiet MSE no more than 10% worse, higher event anticipation, finite bounded weights, and equal camera and local target sequences. If this fails, do not sweep caps. Examine whether stronger positive event credit improved anticipation but raised quiet alarms, or whether the predictive current still could not express the local target despite credit.
