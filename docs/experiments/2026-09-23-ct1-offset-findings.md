# CT1's nearest input lies on opposite vertical sides of T5c and T5d

The [fixed synapse-offset audit](2026-09-23-ct1-offset-protocol.md) used the deduplicated CT1-side sites from the [geometry experiment](2026-09-23-ct1-synapse-geometry-findings.md). It averaged nearest-input minus target-column vertical hex offset **within each T5 cell**, then bootstrapped cells rather than treating contacts as independent. The [result](2026-09-23-ct1-offset-results.json) passes the prespecified subtype-opposed screen at both calibration fields and withheld y=16, using all sites and only pairs within 125 voxels.

At y=10/y=22/y=16, T5c's cell-mean nearest-input vertical offsets were **+0.72/+0.66/+0.68 hex**, while T5d's were **−0.82/−0.84/−0.83 hex**. The T5c-minus-T5d differences were **1.54/1.50/1.52 hex**; all three cell-bootstrap 95% intervals excluded zero (y=16: **1.46–1.57**). Restricting to CT1 input/output sites within about 1 µm gave nearly identical values. The retina projection maps increasing hex `r` to increasing image `y` (about **+1.15 image pixels per hex r**, controlling for hex q). In this screen, T5c prefers upward movement and T5d downward, so the nearest CT1 input is typically displaced toward each subtype's **null-motion side**. That directional interpretation is an inference from the fixed retina map and the frozen T5 response, not a direct recording of CT1 branch activity.

This explains why sending CT1 output from the T5 target's **same** inferred column could wash out null selectivity: the synapse geometry points to oppositely displaced input arms. It supports one bounded opt-in revision of the CT1 shadow. Assign each measured CT1→T5c/d output contact to the inferred column of its nearest measured Tm1/Tm9 input *on CT1*, leaving contact count, transmitter signs, two one-tick delays, blank-calibrated release, and the production graph fixed. Compare the same frozen off/on bar and holdout screen. A physiological branch identity still cannot be concluded from Euclidean proximity alone, and a frozen success would still need online-learning evidence before production promotion.
