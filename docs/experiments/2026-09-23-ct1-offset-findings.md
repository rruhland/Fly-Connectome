# CT1's nearest input lies on opposite vertical sides of T5c and T5d

The [fixed synapse-offset audit](2026-09-23-ct1-offset-protocol.md) used the deduplicated CT1-side sites from the [geometry experiment](2026-09-23-ct1-synapse-geometry-findings.md). It averaged nearest-input minus target-column vertical hex offset **within each T5 cell**, then bootstrapped cells rather than treating contacts as independent. The [result](2026-09-23-ct1-offset-results.json) passes the prespecified subtype-opposed screen at both calibration fields and withheld y=16, using all sites and only pairs within 125 voxels.

At y=10/y=22/y=16, T5c's cell-mean nearest-input vertical offsets were **+0.72/+0.66/+0.68 hex**, while T5d's were **−0.82/−0.84/−0.83 hex**. The T5c-minus-T5d differences were **1.54/1.50/1.52 hex**; all three cell-bootstrap 95% intervals excluded zero (y=16: **1.46–1.57**). Restricting to CT1 input/output sites within about 1 µm gave nearly identical values. The retina projection maps increasing hex `r` to increasing image `y` (about **+1.15 image pixels per hex r**, controlling for hex q). The input sites lie below T5c targets and above T5d targets in this screen. The subsequent [event-aligned audit](2026-09-23-ct1-event-aligned-findings.md) showed why calling this a functional “null-motion side” was misleading: preferred motion reaches these displaced inputs first, and the nearest-site shadow's inhibition precedes preferred rather than null events.

The opposed displacement justified one bounded opt-in nearest-site routing test, documented in the [geometry-shadow result](2026-09-23-ct1-geometry-shadow-findings.md). That fixed test failed null suppression. A physiological branch identity cannot be concluded from Euclidean proximity alone; the production graph and learning rule remain fixed.
