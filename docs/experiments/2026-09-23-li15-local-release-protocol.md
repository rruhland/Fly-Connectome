# Li15 local release-state audit after bounded T2 input

The [T2 full-edge pilot](2026-09-23-t2-graded-propagation-findings.md) caused Li15 subthreshold modulation but no Li15 spikes. This read-only follow-up asks whether Li15 itself has a causal, blank-separated local state that could justify a separately gated inhibitory graded-output test. It neither transmits Li15 release nor changes the production architecture.

Repeat the frozen T2 pilot exactly: the same checkpoint, measured graph, 500-tick ungraded warmup, blank-only cap choice from 0.01/0.03/0.10, 256-tick graded settle, matched ON/OFF blanks, and 18-frame dot/bar/static probes at x=18 and x=46. Retain eight neural ticks per frame and all signed graph weights. From the already captured Li15 voltage and total synaptic-current traces, calculate positive and negative residuals against a causal 250 ms exponential baseline initialized from each Li15 cell's settled state. A candidate is a possible **increase** or **decrease** of that cell's own release; actual inhibitory output would still use Li15's fixed transmitter sign.

For each candidate, report all 21 Li15 cells' matched tickwise dot-minus-blank mean, per-cell signed quantiles, fraction above each cell's own blank p99, and corresponding blank fraction, separately for both positions and polarities. Report bar and static controls too. A candidate passes this source-information screen only if one fixed variable has finite state, at least 3% of Li15 samples above its matched-blank p99, no more than 2% on matched blank, and mean absolute dot-minus-blank modulation at least 0.0005 in **all four** location/polarity combinations. This is a deliberately weak prerequisite for a future inhibitory-release pilot, not an M1A transmission or motion gate. If none pass, do not grade Li15's outgoing edges.
