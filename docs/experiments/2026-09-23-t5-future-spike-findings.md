# Future T5 spikes are motion-specific but weakly predictable one frame ahead

The [local-spike preflight](2026-09-23-t5-future-spike-protocol.md) used the same frozen 50 ms opt-in circuit and asked whether each T5 cell's pending order current at a camera-frame boundary predicts **its own spikes in the next eight neural ticks**. It compared against spikes in the preceding eight ticks, without altering weights or state equations. The [result](2026-09-23-t5-future-spike-results.json) fails the predeclared learning-target screen.

Preferred-motion future spikes are substantially more specific than raw afferent arrivals: moving event prevalence is about **8–12%**, while static prevalence is about **1–3%**. Yet order-state ROC AUC is only **0.617–0.675** at one pixel/frame and **0.519–0.565** at two pixels/frame, below the required 0.70. It exceeds recent-spike persistence AUC by only roughly 0.01–0.05, often short of the required 0.05 margin. T5c blank future-spike prevalence also exceeds the strict 0.001 bound in several conditions. Event-order means are generally higher than quiet means, so useful state exists, but this exact next-frame timing target is not reliably forecastable by the present scalar order state.

Do not start afferent plasticity on this one-frame target yet. One bounded horizon audit at 8, 16, and 32 neural ticks can test whether this is a timing mismatch on the **same frozen T5 circuit**, especially at the withheld faster speed. If it fails, stop target sweeps and revisit the learning objective or local temporal representation rather than increasing trials, gains, or update rates. The passing frozen direction-selectivity result remains valid; production learning and architecture are unchanged.
