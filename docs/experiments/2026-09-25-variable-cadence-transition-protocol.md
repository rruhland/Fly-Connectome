# Generic variable-cadence local transition learning

**Status:** Opt-in learning experiment following failed frozen temporal-support and event-clock controls. Production architecture unchanged.

Generate 18-frame event-camera episodes of five generic shapes (the four previous training shapes plus a single-pixel dot) moving through diverse positions, directions, both contrasts, and speeds 0.25, 0.5, 1, or 2 pixels per camera frame. Fractional movement is rasterized only by the camera scene generator; speed, shape, and trajectory labels never enter the learner. Compute the same four-frame local ON/OFF coincidence trace used in the native-rate diagnostic. Freeze the previously learned 24-unit sensory dictionary. Train the zero-initialized local recurrent transition and a copy initialized from the prior fast-motion transition for one pass using the existing sensory-gated local next-state mismatch, with no backpropagation.

Evaluate both learned arms against the frozen fast-motion transition and observed-code persistence on held-out native-rate Pong camera streams, using only event maps as model input. Also retest independent and crossing generic scenes using the original adjacent-frame input to detect lost reusable motion ability. Report active-frame latent occupancy F1, active-site ratio, and transition-weight change. A promising result requires native F1 at least 0.10 above both the frozen fast-motion arm and persistence, while losing no more than 0.05 F1 on independent or crossing generic scenes and keeping active sites below 2× targets. If this fails, do not tune a scalar threshold; examine whether one transition magnitude can express both subpixel/event-sparse and one-/two-pixel cadence or whether a genuinely local interval/multiscale state is needed. No production change from this experiment alone.
