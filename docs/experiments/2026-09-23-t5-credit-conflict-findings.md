# Event and quiet targets give opposing credit to the same T5 edges

The [frozen replay protocol](2026-09-23-t5-credit-conflict-protocol.md) reproduced the original 40-episode pilot exactly: **1,050 changed edges**, maximum absolute change **0.002874**, and target-event fraction **4.529%**. It retained the same measured graph, T5 timing current, local `FramePrediction` equation, learning rate, and trial sequence. The [result](2026-09-23-t5-credit-conflict-results.json) partitions each nonzero synaptic proposal by the *postsynaptic local feedforward target at confirmation*, using the pilot's fixed event threshold of 0.01.

Event confirmations produced **12,322** nonzero proposals, 11,327 positive and 995 negative, with signed mass **+0.1212** and absolute mass **0.2159**. Quiet confirmations produced **138,938**, 131,946 negative and 6,992 positive, with signed mass **−0.6975** and absolute mass **0.7066**. Both categories acted on 999 of the 1,050 updated edges. On **740/999 (74.1%)**, the edge's cumulative event credit was positive and its cumulative quiet credit negative; no edge had the reverse cumulative pattern. The aggregate cancellation of opposing signed mass on those edges was **50.9%**. This is a direct same-synapse conflict, not merely different ON/OFF cell pools sharing a global parameter.

The audit supports a single bounded opt-in metaplasticity test: let each T5 postsynaptic cell keep a running local frequency of event and quiet confirmations and apply a capped event-credit multiplier, while leaving the existing error × eligibility sign and measured edge magnitude intact. No global event count, class label, synthetic edge, or backpropagation is needed. The cap must be frozen before evaluation and the test must report quiet false alarms, because simply overpowering quiet credit could trade event anticipation for broad activity. The production learning rule remains unchanged pending evidence and user approval for any in-place promotion.
