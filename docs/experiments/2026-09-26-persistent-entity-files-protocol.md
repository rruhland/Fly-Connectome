# Online persistent entity hypotheses from a signed visual surface

**Status:** Opt-in M1A architecture experiment under the [entity-state pivot](../plans/2026-09-26-m1a-entity-state-pivot.md). Production code and measured graph are unchanged. The confident ON/OFF surface is a generic local sensory memory, not an object representation. Connected surface regions provide **proposals only**. Persistent entity hypotheses compete for proposals online and carry the representation used for prediction; no true entity count, identity, mask, direction, speed, or Pong concept enters inference.

Each hypothesis stores an appearance/support patch, polarity, center, recent observation interval, local displacement state, and confidence. On an active event-camera frame, proposals compete one-to-one for hypotheses using predicted spatial continuation and locally learned appearance. A match updates appearance and displacement from that hypothesis's own sensory prediction error. An unmatched confirmed proposal can start a hypothesis. When a proposal could be a merger of several predicted hypotheses, preserve the separate hypotheses through the ambiguous observation and resolve their identities when evidence separates. Quiet frames retain state without treating an unchanged surface as a new velocity measurement. A generic translation operator renders each hypothesis's predicted support; comparing it with the current signed surface yields the next-event ON/OFF forecast. All updates are local and online, with no backpropagation.

Compare aligned local error credit, temporally misassigned credit, and frozen displacement with the same surface and proposal stream. The earlier nonlearning `VisualContinuity` tracker is an engineering ceiling for clean grouping, not evidence of learning. Use 64 unlabeled generic streams for any shared local statistics and the existing held-out generic, position, speed, shape, separated, and crossing cases. Add the registered noisy stationary control from the surface baseline and a different-shape crossing case. Score the model's **own selected active hypotheses** every frame: count error, duplicates, identity switches, direction from their histories, localization, and full-frame next-meaningful-event top-8/top-32 recall/precision. Synthetic identities and coordinates are for evaluation only. Do not select the best path after the episode.

The architecture is useful only if it maintains approximately one live hypothesis per mover, preserves identities through clean crossings, beats frozen and shuffled credit on ambiguous/noisy identity or transferred forecasts, and does not lose the fast-only forecast on speed and shape by more than three top-32 recall points. An isolated false event and a genuine isolated stationary pixel may remain indistinguishable without a renewed observation; report that limit explicitly. If the aligned arm merely matches fixed continuity on clean scenes and fails noise or transfer, do not promote it or tune association radius/gain on held-out cases.
