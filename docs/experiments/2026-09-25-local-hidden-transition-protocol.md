# Chunk 1: locally learned hidden visual transition

The [factorized world-state plan](2026-09-25-factorized-world-state-experiment-plan.md) calls for hidden visual motion state that continues through missing evidence, independently of whether an event camera sees a pattern. This first opt-in chunk tests that state before adding a visibility or event head. It uses the saved locally learned 24-unit correlation-input motion code as sensory input and learns a new 24-to-24 translation-shared 5×5 local transition from experience. No direction, object, Pong, or simulator label trains the transition.

Initialize transition weights to zero. On visible generic training sequences, previous local latent activity is eligible for delayed credit from the next locally observed latent mismatch. Gate updates by current local sensory evidence so an occluded frame is not incorrectly treated as proof that the hidden pattern disappeared. Use the existing learning rate 0.5 and [0,1] weight bound. At inference, local sensory evidence reanchors the hidden state where it is present; elsewhere the learned transition advances the previous state. Hidden activity is **not** emitted as a camera event. A matched shuffled-credit transition receives unrelated episode targets at the same time indices; frozen zero-transition and two state-reset controls (at gap entry and immediately after the first disappearance observation) complete the comparison.

Train one pass on the existing 96 varied clean moving-pattern episodes. Evaluate one-step latent occupancy prediction on unseen visible shapes/speeds/contrasts/positions, then free-run through the same generic two-, three-, and four-frame gaps. For evaluation only, generate a paired unoccluded trajectory and compare predicted hidden-state spatial occupancy with its latent code at each blank frame; the counterfactual frames never enter model inference or learning. Report spatial occupancy F1 by gap duration and frame, active-site counts, whether a reset removes the gain, and the direction/magnitude of hidden-state centroid displacement as a post-hoc motion readout. Compare against frozen spatial holds from immediately before the gap and after the first disappearance observation: these controls distinguish motion propagation from mere persistence. Require learned visible one-step occupancy F1 to beat shuffled and frozen by at least 0.10, and hidden occupancy F1 at the last blank frame to reach 0.30 for two-frame and 0.15 for four-frame gaps without more than twice the counterfactual active-site count. Require a causal gain over a spatial hold before treating the state as learned motion through the gap. If these fail, redesign the local transition before building a visibility head. No production architecture change.
