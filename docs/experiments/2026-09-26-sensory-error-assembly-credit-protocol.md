# Future sensory-error credit for slow assemblies

**Status:** Bounded opt-in M1A experiment. The preceding two-timescale circuit reconstructed fast activity but trained its recurrent synapses to predict the next sparse slow winner. That objective improved neither shape transfer nor the fast field's forecast. This test changes the *local credit target*, without changing the frozen fast predictor, slow sensory motifs, topology, timescales, competition, or training scenes. Production M1A and the measured connectome remain untouched.

For each pair of meaningful event-camera observations, the frozen fast field predicts the next fast sensory state. A slow recurrent assembly also predicts a small local addition to that state using its existing local decoder. The arriving fast state supplies a local signed prediction error. Each candidate slow cell receives the error in its own 7×7 decoder footprint; its recurrent input synapses change by that cell's local error signal times presynaptic eligibility. Negative error suppresses unsupported additions. This is an explicit local three-factor rule using existing nearby sensory feedback, not backpropagation or a gradient tape. The event forecast decodes the *combined* fast-plus-slow predicted state. Slow activity still competes and persists across quiet frames as before.

Train on the same 64 unlabeled generic scenes. Compare (1) aligned future-fast-sensory-error credit, (2) the original next-slow-winner credit, (3) frozen slow self-persistence, (4) time-shuffled future-sensory-error credit, and (5) the fast-only predictor. All slow arms share the same learned sensory motifs, the same initial recurrent weights, and the same full-frame fast input. No directions, objects, speeds, oracle regions, rewards, or Pong-specific semantics enter training or inference. Do not tune weight bounds, projection scale, stride, decay, or forecast fusion on held-out results.

Evaluate next-meaningful-event top-8/top-32 recall and top-32 precision on held-out generic shapes and the registered position, doubled-speed, changed-shape, separated, and crossing cases. Use the already fixed 3×3 **offline** spatial direction probe, calibrated only on the 16 calibration scenes; it cannot establish autonomous tracking. Report significant slow activity outside offline object neighborhoods and extra connected components. Count paired scene wins rather than relying only on aggregate recall. A useful architecture foothold requires the sensory-error arm to improve on the original slow objective and shuffled control in both speed and changed-shape transfer, preserve the fast-only forecast within three recall points on those sets, and show no crossing collapse. If it fails, reject this local credit route without a parameter sweep and reconsider the representation/credit interface at a larger architectural scale.

Execution: test that local future sensory feedback strengthens a confirmed displacement and weakens an unsupported one; run the registered control comparison once; document the evidence, run focused and full tests, then commit and push a clean checkpoint.
