# Local event balance moves credit in the right direction but remains too weak

The [bounded opt-in protocol](2026-09-23-t5-balanced-credit-protocol.md) replayed the 40-episode vertical T5 task with one local metaplasticity change: a postsynaptic event-credit multiplier derived from each T5 cell's exponentially decaying event/quiet counts, capped at four. The existing frame-horizon error × eligibility sign, base eta, measured graph, physical T5 current, and frozen evaluation set stayed fixed. The first run was invalid because an advanced-index in-place update modified a temporary tensor rather than the stored counts; a regression test exposed this, the counters were fixed, and that gain-1 replay was discarded. The [reported result](2026-09-23-t5-balanced-credit-results.json) is the corrected run, with mean applied event gain **3.977** across 17,727 event-confirmed edge samples.

The corrected rule produced stronger but still bounded updates: 1,050 measured T5 edges changed, the largest absolute weight change was **0.01095** versus 0.00287 without balance, and total absolute proposals rose from 0.922 to **1.544**. All non-target weights stayed fixed. Camera inputs and T5 feedforward targets again matched the frozen comparator exactly. Event anticipation increased in every withheld subtype/direction/speed case, and quiet MSE stayed within the 10% limit.

The **learning gate nevertheless failed decisively**. At withheld y=16, event-MSE improvement ranged only **0.017–0.170%** across the eight T5c/d × direction × speed comparisons, far short of the required 10%. For example, one-pixel/frame T5c/T5d event MSE in the positive direction changed from 0.003932/0.004140 frozen to 0.003928/0.004133 trained; at doubled speed it changed from 0.004566/0.004678 to 0.004564/0.004675. This is a consistent *directional* effect, not effective online learning.

The same-edge event/quiet conflict was real, but a fourfold event multiplier only partially addressed it. The next bounded question is whether the measured recurrent T5 predictive edges can influence the next-frame T5 forecast enough at all: compare frozen and trained predictive currents and use a training-position-only weight-displacement sensitivity check before spending more time on trial count or gain sweeps. If greater displacement still fails, the bottleneck is predictive-path timing/representation, not merely a slow update. No production rule is changed.
