# T5's measured recurrent input is too sparse for the current frame-horizon target

The [frozen capacity protocol](2026-09-23-t5-predictive-capacity-protocol.md) replayed the successful opt-in Tm9-release/T5-order circuit without training. It compared physical predictive current at each frame boundary with each local T5c/d cell's **next-frame** motion-gate event and counted the actually arriving predictive edges. The [result](2026-09-23-t5-predictive-capacity-results.json) fails the predeclared basic-support prerequisite in 15 of 16 subtype × direction × position/speed cases; only y=10/down/T5c barely exceeds 50% current support (51.2%).

At the two calibration positions, only **26.6–51.2%** of future gate events had predictive current above 1e-6 at forecast time. At withheld y=16/speed one, support was **36.1–46.5%**; at speed two it fell to **20.7–34.3%**. Recent *actual* predictive arrivals supported only **15–32%** of event samples. Predictive-current magnitude was higher on future event than quiet samples, so the signal is informative **when it exists**, but scaling magnitudes or multiplying learning credit cannot create a missing presynaptic arrival. The bright blank had no gate events; the static-bar control still had many gate events and ~47–53% current support, another caution against treating this as learned motion prediction.

The arriving predictive sources explain the coverage limit. Positive arrivals onto T5c/d were almost entirely from **other T5 cells of the same subtype** (for example y=10/down: 235 of 237 T5c positive arrivals and 200 of 200 T5d positive arrivals). T5d sometimes also received fixed-sign inhibitory `LPi4b` arrivals (130–134 in the relevant conditions), but these were absent at y=22. This is predominantly sparse self/downstream recurrent activity, not a continuously available upstream cue before the next camera event. The earlier 40-episode local update changed 1,050 T5 predictive edges yet improved held-out event MSE only 0.017–0.170%; the new frozen support audit provides a plausible physical reason, without proving that every missing event is unlearnable through recurrence.

Do not run another long trial-count or learning-rate sweep on this objective. The next bounded capacity test should compare the **existing Tm4/Tm9 feedforward arm histories** at the same forecast times against the same future gate target. If those local histories have broad support and separate event from quiet across the position/speed holdouts, test an *opt-in* class-local plasticity rule on their measured T5 afferents, with no backprop and fixed topology/signs/delays. Only after a frozen and online-learning pass should an in-place architecture revision be proposed for approval.
