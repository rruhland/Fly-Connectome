# Does the history code contain enough information for local future events?

The learned history-gated units make motion direction readable at 599/608 unseen event sites, yet their online 5×5 emitter predicts only rightward reappearance. Direction readability alone does not establish next-event sufficiency. Before changing the local objective, freeze that code and fit an **evaluation-only** local linear readout of t=11 ON/OFF events from t=10 source activity. This readout is an upper-bound diagnostic, not a candidate learning rule; it never updates the visual code and is not eligible for production.

Recreate the learned and random eight-unit history dictionaries with the same seeds, local two-pass training, and 96 clean plus 32 generic interruption/noise episodes. Fit the same sparse damped least-squares 5×5 event readout on 64 interrupted cases from four training shapes, four directions, two speeds, and both contrasts. Evaluate on the frozen 144-case suite of three unseen shapes, four directions, two speeds, two contrasts, and three positions. Keep the registered 0.5 threshold and report F1, true/false positives by direction, training fit, and local event reach.

Test two **predeclared** representations of the same frozen source activity: (1) history-unit identity alone; (2) history-unit identity crossed with the currently observed raw ON/OFF polarity at that same site. The second gives separate local readout degrees of freedom to sensory sign without assigning motion direction or object identity. Match each against a random history dictionary, and reset the learned trace before t=10 as a causal control. Include the matched opposite-motion pair.

If the learned unit-only code reaches at least 0.40 F1 across all 144 held-out cases, exceeds its random control by at least 0.10, and has true positives in all four directions, then the online event objective/credit is the leading failure. If adding raw polarity raises held-out F1 by at least 0.10, the learned state needs that locally observed sign at emission. If both learned representations remain below 0.20 despite high spatial reach, direction is present but exact future ON/OFF location is not locally recoverable through this readout; change the representation/readout geometry before tuning the objective. Treat intermediate results as mixed and do not promote offline weights.
