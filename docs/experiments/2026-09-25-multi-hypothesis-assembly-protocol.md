# Delayed local evidence integration for motion assemblies

**Status:** One bounded opt-in architecture comparison, motivated by the failure of immediate one-to-one assembly assignment. Production model and measured graph are unchanged.

Use the same frozen event-linked learned sensory code, candidate extraction, and generic Hebbian transition affinities as the [first assembly experiment](2026-09-25-local-motion-assembly-findings.md). Change only the representation/inference architecture: each candidate may continue several local causal paths, and a path carries its recent motion history through quiet frames. A fixed short beam retains competing hypotheses per candidate. Local path scores combine bounded spatial proximity, smooth continuation of an already inferred displacement, and—only in the learned or shuffled arm—the corresponding locally learned transition affinity. At the end of the short visual episode, spatially overlapping paths compete for a sparse set of assemblies. No object identity, direction target, or oracle region is supplied at inference. This finite-horizon path calculation is a capacity experiment for delayed local recurrent competition, not a claim that the implementation is a biological neuron circuit or a production online algorithm.

Evaluate the identical position, speed, shape, separated, and crossing suites with the same post-inference object matching as before. Compare aligned Hebbian affinity, fixed proximity/smoothness, and shuffled temporal affinity. The result is useful only if aligned learning improves speed-two object direction and coverage over both controls without sacrificing separated movers, and the output remains sparse enough to represent multiple entities distinctly. If all arms improve equally, the gain is from fixed temporal smoothing; if none improve, candidate-level evidence or the assembly state itself is inadequate. Do not tune beam width, spatial radius, or score weights after seeing the test results. A generic pass would precede any native-stream run or production proposal.
