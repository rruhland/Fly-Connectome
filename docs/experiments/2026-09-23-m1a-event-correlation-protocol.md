# Shared local event-correlation motion control

The 3×3 square-dot trial showed that subtype-averaged T5 spikes detect movement but decode only 7/12 held-out four-way directions. Test a substantially different, **opt-in** local motion hypothesis before changing production architecture: keep separate ON and OFF event maps, retain a short decaying trace of each, and compute directed coincidences between a prior event at one pixel and a current same-polarity event one or two pixels away. The signed difference between opposite displacements gives a local x/y motion vector. Use one fixed eight-frame trace duration across all cases, no labels, no backpropagation, and no network weight changes. This control uses synthetic local pixel-neighbor interactions and is **not** claimed to be an existing measured T4/T5 edge implementation.

Run the identical square-dot moving, static, and blank event-camera sequences at vertical y=10/22/14/18 and horizontal x=18/46/32, speeds 1 and 2 wherever the prior dot trial used them, plus the bright-square conditions. Report four-way direction accuracy, abstention, and static/blank false alarms. Then stream the same event-correlation readout on 16×800 zero-drive Pong frames. Restrict Pong correlations to interior columns to exclude paddles, and score the sign of each axis only when its correlation is nonzero; report coverage separately from accuracy. Simulator velocity is used only for scoring. A high square-dot score with low Pong coverage would point to event cadence or object association, whereas poor square-dot score would reject this elementary bridge before production discussion.
