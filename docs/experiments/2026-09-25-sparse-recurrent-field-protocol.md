# Sparse recurrent visual field: decisive opt-in M1A experiment

**Question:** Can a spatially shared, locally plastic recurrent visual field learn a transferable motion state and a next-event sensory forecast from unlabeled event-camera streams, when the path-bank family could only retain duplicate trajectories?

**Scope:** This is an opt-in experiment in `scripts/` and `tests/`. Do not alter the production M1A implementation or measured connectome. No Pong object, direction, speed, trajectory, reward, or motor target enters learning or inference. There is no backpropagation or gradient tape. The first input is the signed two-channel event stream; the successful measured T4/T5 signal remains a later paired-input question.

**Model:** Eight spatially shared 5×5 sensory motifs compete locally for sparse activity over the full 32×64 field. A winning unit updates its sensory motif from the *local event reconstruction residual*, a local Hebbian-like dictionary rule. Its previous active field predicts the next meaningful-event field through a shared 7×7 recurrent kernel. Each recurrent synapse updates from its presynaptic activity and the postsynaptic unit's own prediction error. Recurrent support affects future competition. The same motif dictionary decodes the predicted field into a signed event forecast. Quiet camera frames retain state but are not independently used as next-event targets. All motif/transition weights are bounded; site selection uses fixed local competition, with no entity count.

**One-shot comparison:** Train on the same 64 unlabeled `generic_native_cadence.scene_events` episodes. Compare (1) aligned sensory and recurrent learning, (2) the same learned sensory motifs with frozen recurrent weights, (3) the same learned sensory motifs with temporally shuffled recurrent credit, and (4) a repeated-last-event forecast. Keep inference, capacity, and data identical across learned arms. No held-out tuning of sparsity, kernels, learning rates, or forecast threshold.

**Evaluation:** On 16 held-out generic scenes and the already registered position, doubled-speed, changed-shape, separated, and crossing scenes, measure next-meaningful-event top-8/top-32 target recall and false spatial activation, all from full-frame forecasts. Separately fit a frozen nearest-centroid direction probe on the 16 calibration cases and score each held-out set from the full-field state extracted *after inference* using synthetic object masks. That probe is an oracle-localized capacity check, not evidence of autonomous entity discovery. Report active-unit counts and the proportion of field activity outside evaluated object neighborhoods. A positive architecture foothold requires aligned learning to beat both frozen and shuffled recurrent controls on held-out next-event recall, reach at least 80% speed and separated-mover direction transfer, and avoid a crossing collapse. Otherwise stop this field variant without narrow parameter sweeps. Even a pass is not production-ready until an autonomous object-state and native-stream evaluation succeeds.

**Execution order:** (1) test local plasticity, translation sharing, competition, and quiet-state behavior; (2) implement the experimental field and verify focused tests; (3) run the registered comparison once; (4) write findings, run the full suite, and commit/push a valid checkpoint.
