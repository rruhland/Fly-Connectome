# Is CT1's local input offset subtype-specific?

Use only the deduplicated cached CT1-side synapse coordinates from the preceding geometry audit. For each selected CT1→T5c/d output contact, find its nearest selected Tm1/Tm9→CT1 input site and compute the input source's annotated optic hex minus the T5 target's afferent-inferred hex. Record vertical hex (`r`) and horizontal hex (`q`) offsets, separately for T5c/T5d at y=10, y=22, and withheld y=16. Keep all nearest pairs, and repeat the summary for pairs within 125 EM voxels (~1 µm); do not select a radius after seeing the data.

Avoid treating many synapses on one T5 cell as independent evidence: first average the vertical offset within each target cell, then compare subtype means. Use a fixed-seed, 1,000-resample bootstrap over target cells for the T5c-minus-T5d mean difference at each field. A stable subtype-opposed offset needs the difference to have the same nonzero sign and a 95% cell-bootstrap interval excluding zero at both calibration fields and the withheld field, in both all-site and near-site summaries. Also report whether each subtype's own mean offset lies on opposite sides of zero. If these conditions fail, do not replace the column shadow with a geometry-routed inhibitory shadow based only on Euclidean nearest neighbors. This is a static anatomical diagnostic, not evidence of motion tuning or learning.
