# Appearance-coded dynamics transfer

The generic patch-association state passes all four clean physical rotations in
its initial visible-frame capacity arm. Before treating that as reusable state,
change the relation itself: the visual mark always occupies the same side of
the approaching pattern, while a horizontal versus vertical four-pixel motif
determines the subsequently observed displacement. The renderer defines this
environment; the model receives only images/events. No cue identity, outcome
label or hidden trajectory is supplied to learning.

Use the unchanged association algorithm and the same four-orientation training
and held-out geometry/shape/speed splits. Run aligned, shuffled-outcome and
unlearned associations with current visible images as the declared sensor. This
is a representation-capacity test, not event-only acceptance. Require >=14/16
top-32 contextual hits per orientation and a material learning-control gap,
while retaining constant and two-mover regressions. Do not tune the receptive
field or cue motifs after the result. If it fails, identify that generic sensory
selectivity remains unestablished before attaching a forecast head.
