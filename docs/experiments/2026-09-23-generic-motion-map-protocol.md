# Generic local motion-map transfer probe

The previous M1A proposal is withdrawn because it built a Pong-specific object state and collision model. Before another production proposal, test whether the local temporal primitive itself represents **patterns moving through space**, independent of object identity and scene semantics. This is an opt-in experiment with no changes to the MaleCNS graph or production model.

Use the existing ON/OFF event camera and a fixed local coincidence operation: separately trace both polarities for eight camera frames, then at every pixel compare same-polarity past/current events at one- and two-pixel horizontal/vertical offsets. Preserve a signed spatial motion map rather than summing the whole field. The rule receives only events; object masks, trajectories, direction, shape, and speed are held by the evaluator, never fed into the motion rule. No backpropagation, fitted labels, hardcoded object type, or special screen region is allowed.

Run 18-frame sequences with four **unchanged shapes** (3×3 square, five-pixel-arm plus, irregular L, and a narrow bar) each moving in all four cardinal directions at one or two pixels/frame, on both bright and dark backgrounds, at two positions. Include shape-matched static onset/offset controls. Score each trial by the signed map within the current object's region over the active frames: four-way direction, wrong-axis energy, and fraction of motion evidence localized near the moving pattern. Then run two simultaneous separated objects with opposing directions and one static distractor; score each object's local map independently and report interference. Add a crossing/temporary-overlap case and score pre- and post-overlap separately, without assuming that identity is recoverable at the fully merged frame.

This test is decisive about a *spatial motion primitive*, not object discovery or online dynamics learning. Passing means at least 90% correct four-way direction over the single-object transfer grid, no static-control motion after onset, and correct independent signs for both separated moving objects. Failure should identify shape/polarity/speed/position patterns before any architecture discussion. Even a pass leaves generic grouping, tracking, and prediction as separate questions.
