# Bounded expanded-exposure check

The equal-budget diverse arm underfit even its training scenes. To test whether insufficient unlabeled experience explains that result, retrain only that same opt-in circuit from the same seed with 12 passes instead of three: 384 rather than 96 moving-pattern episodes at each stage. Preserve the first three passes exactly. The extra passes reuse square/plus/L/bar motion at the same four directions and two speeds while crossing previously missing contrast and position combinations. The model, local learning rates, code size, 5×5 fields, next-frame target, offline decoder, and held-out diamond/ring/zigzag cases stay fixed. This experiment changes only experience; labels remain scoring metadata.

Compare the archived 96-episode result to 384 episodes at the predeclared 0.5 threshold, with threshold 0.3 shown as a calibration sensitivity check. Measure training and held-out local-rule event F1, offline learned-code and random-code F1, direction probe, and results at each speed. Meaningful progress would be held-out learned-code decoder F1 at least 0.50 with slow-speed F1 at least 0.30 and local-rule event F1 at least 0.35. If extra exposure substantially fits training but held-out prediction stays poor, investigate representation/invariance. If even training remains weak, change temporal state and local predictive credit rather than spending another long run on this circuit. No production architecture changes.
