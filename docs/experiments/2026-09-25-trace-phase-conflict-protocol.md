# Do quiet and visible targets conflict with gap-exit prediction?

The one-pass continuous-trace local learner scored zero on every training gap exit even though an evaluation-only local decoder fitted solely at the trained gap exit reached 0.768 training / 0.516 held-out F1. The same online weights also receive delayed error on quiet and ordinary visible frames. This frozen-capacity diagnostic asks whether a **single shared local weight bank** can satisfy those phases simultaneously, before redesigning the update rule.

Freeze the saved learned motion code. Use the exact generic training shapes with 64 cases per two-, three-, and four-frame gap. At each episode collect the 24-channel trace and next signed-event target for: (a) last blank frame → reappearance; (b) preceding blank/disappearance frame → quiet target; (c) a pre-gap visible-motion transition; and (d) observed reappearance → next-motion transition. Fit the same 17×17 translation-shared ridge-damped local linear decoder and 0.5 threshold under three nested, evaluation-only target sets: **exit only**, **exit + quiet**, and **all four phases**. Fit the third set only if adding quiet does not already collapse training exit F1 below 0.20. No offline fitted weight enters online training or production.

Score each arm on its training gap exits and on the fixed unseen-shape three-frame multi-position suite plus unseen two-/four-frame center-position suites. Report F1, true/false positives, sample/positive counts, and quiet false alarms. A ≥0.15 drop in training and held-out gap-exit F1 when adding quiet would support incompatible phase demands for one scalar emission bank. If quiet retains capacity but visible/post-gap targets collapse it, the conflict is broader. If offline capacity survives all phases, the failed online learner's local eligibility/normalization/update rule is the likely bottleneck. These are diagnostic inferences only; no backpropagation or production architecture change.
