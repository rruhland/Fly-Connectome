# M1A.5 history benchmark: first control validity check

The constant-motion hidden-trajectory case is a sanity check, **not a qualifying M1A.5 benchmark**. A generic fixed constant-velocity tracker localizes the hidden entity in all 16 held-out single-mover cases and both entities in all 8 two-mover cases in both event-only and sparse-frame inference. The frozen observer's complete state also retains appreciable approach history: the full-state direction probe reaches 14/16. Thus occlusion by itself does not establish that the sensory system lacks the needed information, and it leaves no room to beat the tracker.

The visible-only spatial readout of the complete sensory state and the matched 48-plane leaky memory both score 0/16 top-32 hidden-site hits. This means a purely local occupancy decoder cannot move an edge trace into the hidden region; it does **not** mean that motion history is absent. The complete sensory-state distance between opposite approaches is about .26–.35 after normalization. Sparse intensity refresh does not change these conclusions. The oracle ceiling is 16/16.

These are deterministic clean cases. The probe was fitted on visible pixels in separate development trajectories; hidden sites were used only for held-out scoring. The frozen observer itself was previously fitted with exact every-frame rendered-intensity changes, so neither arm establishes teacher-free online learning. Reproduce with `.venv/Scripts/python scripts/run_visual_history_controls.py`; [raw measurements](2026-09-26-visual-history-control-results.json) include each pair distance and both sensor arms.

The first changing-motion split repeats an unlabeled 1/2/3-pixel displacement cadence behind the band, with held-out locations, shapes, phases, polarities and both directions. At the late hidden decision frame, the fixed constant-velocity tracker hits 12/16 top-8 and top-32 hidden locations; a literal constant-acceleration extrapolator hits 0/16. The full sensory and matched leaky local occupancy readouts hit 0/16. This leaves a small but genuine 4-case gap for a locally learned temporal transition. It does not prove that an arbitrary internal representation is needed: the complete sensory state retains history and an engineered tracker nearly saturates. The current benchmark therefore tests whether a learned generic dynamics state adds value *over* that strong tracker, plus whether it survives the already saturated constant-motion and two-entity regression cases.

Disappearance before reveal is observationally unknowable and must be scored as uncertainty, not as a forced correct/incorrect hidden trajectory. Contradictory evidence after the expected reveal and the observer's privileged teacher remain separate acceptance obligations. Production M1A remains unchanged.
