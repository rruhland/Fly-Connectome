# Read-only T4 input-arm separability before compartment dynamics

The opt-in graded Mi4 experiment stopped at its flash-current criterion. This next frozen diagnostic asks whether the *already active* Mi1/Tm3 central excitation and Mi9 offset inhibition contain a location-stable directional signal that a local passive conductance mechanism might express. No network dynamics or learning is changed.

Use the pinned initial full graph, measured delays/signs/weights, event camera, 8 ticks/frame, 500-tick warm state, matched blanks, and equal-count 13-position moving bars. Test both horizontal motion (vertical bar) and vertical motion (horizontal bar), in opposite orders at x=18 and x=46. Include an onset/offset static-bar control from the same warm state. The anatomical Mi9/Mi4 offsets imply that horizontal T4c/d and vertical T4a/b are the relevant opposite pairs; this expectation is fixed from the [geometry audit](2026-09-22-motion-stage-recovery-geometry.json), not selected from responses.

For each measured T4 neuron, maintain three causal input traces from existing arriving edges, using its current 5 ms decay and positive contact-weighted magnitudes: center excitation `E` from Mi1/Tm3, distal inhibition `I9` from Mi9, and proximal inhibition `I4` from Mi4. The latter is expected to be zero under the baseline model. Evaluate two fixed local functions without fitting parameters: `E/(1+I9+I4)` (conductance-style divisive response) and `E*max(0, I9_blank-I9)` (coincident disinhibition relative to that neuron's matched no-event trace). Compare integrated transit responses by T4 subtype and local retinotopic population; retain per-cell and per-tick values for inspection.

Only a reproducible opposed-direction contrast with the same sign at both locations, direction index at least 0.2, nonzero evoked signal, and a weaker static response would justify implementing a shadow compartment neuron next. A negative result does not prove no biological dendrite could work; it says these *current* active input streams and two simple local operations are not enough to justify that larger implementation. Do not use Pong score or a trained direction decoder to pick a result.
