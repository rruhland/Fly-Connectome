# Is a local Tm4 source state present when the T5 arm is silent?

The same-target T5 arm audit missed its 50% individual-Tm4 support threshold only for T5d/up at withheld y=16 and two pixels/frame. On the unchanged frozen checkpoint and opt-in Tm9/T5-order circuit, replay that up trial, matched down trial, bright blank, and static bar from the same blank-calibrated state. Keep graph/signs/delays, eight ticks/frame, gains, and weights fixed. Select local T5c/d cells by the existing anatomy-to-retina map and each cell's **measured Tm4→T5 feedforward afferents**; report how many cells have no such contacts.

At each camera-frame forecast boundary in frames 3–13, label a next-frame T5 gate event exactly as before (maximum local order current >0.05). Identify event samples with absent Tm4 arm history (current-plus-eight-tick-delayed absolute residual ≤0.001). For each target cell, read the contact-weighted mean of its Tm4 afferents' own signed synaptic current (feedforward + predictive + behavioral) and membrane voltage at that forecast tick. Subtract the matching cell/tick value from the bright-blank trial; this isolates stimulus-driven source state without adding a new release rule. Compare missing-arm events with supported events and quiet samples, plus the static control. Record positive-current-deviation fraction above 0.01 and source-cell spike fraction at the same tick.

Only if a majority of missing-arm event samples show positive source-current deviation above 0.01 **and** their mean positive deviation exceeds the quiet-sample mean by at least twofold should an opt-in Tm4 graded-release test be considered. A pass would show latent local input, not online learning; static responses still need explicit control. A fail means the upstream source itself lacks the forecast-time cue, so do not add graded Tm4 output solely to fill the missing arm.
