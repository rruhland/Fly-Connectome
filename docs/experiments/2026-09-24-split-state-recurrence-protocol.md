# Local hidden continuity after split sensory access

The separate raw branch sees first sightings and keeps the learned coincidence code intact, but has no history at reappearance. Two opposite-motion sequences can have identical t=10 input and different t=11 targets. This opt-in experiment tests whether an existing **locally plastic** hidden transition can retain useful context through three missing frames. It introduces no direction labels, object features, backpropagation, or Pong rules.

Use the unchanged 24-unit learned coincidence encoder plus the eight-unit learned raw-event encoder from the split-path test. Concatenate their activity as the observed latent. Reuse `SeparatedVisualState` with separate observed/imagined emission credit and its local latent transition update. Train on the same 96 clean and 32 generic interruption/noise episodes used in the earlier separated-state experiment. Compare: (1) split recurrent state, (2) identically trained split emitter without recurrence, (3) the trained recurrent model with state reset immediately before t=10, and (4) the archived coincidence-only online predictor. The reset ablation keeps all weights and current reappearance input, removing only prior episode context at that point.

Evaluate held-out unseen single patterns and the five robust families, exact t=10→11 reappearance on eight disappearance cases, false-positive pixels on quiet targets, hidden activity through blank input, and one matched left/right reappearance pair with identical t=10 input. The pair tests whether the recurrence expresses different forecasts from different histories. Use the registered 0.5 event threshold. Do not select weights or a threshold after seeing results.

A useful mechanism should gain at least 0.10 exact reappearance F1 over no recurrence and reset, keep clean single-pattern F1 within 0.05 of the archived learner, and avoid more than doubling the archived quiet false alarms. If it fails, do not tune this same transition through many narrow variants. Diagnose whether the hidden state actually survives the gap and whether it changes the pair's forecast; then choose a different temporal-context mechanism or learning objective. Production M1A stays unchanged.
