# Broad reappearance transfer check after narrow gate

The first online local readout passed its registered gate on eight held-out rightward disappearance cases: exact reappearance F1 was 0.138 versus 0.015 for a trained random code and zero for trace reset. It preserved clean prediction and quiet false alarms. However, its training interruption subset had zero true-positive pixels at the fixed 0.5 threshold. The narrow held-out suite may favor one motion direction. Before calling this useful learning, run the **same trained model and weights** against a broader frozen generic interruption suite.

Recreate the prior training identically. Evaluate three unseen shapes (diamond, ring, zigzag), four motion directions, speeds one and two, both contrasts, and three interior centers `(13, 27)`, `(16, 32)`, `(19, 37)`: 144 episodes. All have the same three-frame missing interval. Report exact t=10→11 F1 overall and by direction for learned history, trained random history, and learned history with trace reset. Also retain the original clean/robust evaluation. Threshold stays 0.5; no parameter or training-data changes.

For a transferable online predictor, require learned exact F1 at least 0.05 above both controls overall, nonzero true positives in **each** direction, and no material loss of ordinary held-out prediction. If only one direction works, treat the narrow success as directional bias and do not promote. If the broader gate passes, continue to larger variation and multi-frame forecasts before proposing production integration. No backpropagation or Pong semantics enter this check.
