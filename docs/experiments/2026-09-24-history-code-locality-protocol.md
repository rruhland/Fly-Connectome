# Where is direction readable in the history-gated code?

The learned history-gated population gave a 47/48 **episode-histogram** direction probe on unseen shapes, but its additive per-source local event-emission rule predicted only rightward reappearance across 144 varied interruptions. This evaluation-only probe asks whether direction is actually available to each local synapse or only to a small population pattern. It does not train the visual model with direction labels and does not produce an M1A forecast.

Retrain the learned and random history dictionaries with the same seeds, generic episodes, and two local passes. Freeze both. For 64 interrupted training-shape episodes, collect unit activity at each t=10 raw-onset site and fit nearest mean direction prototypes for three predeclared feature scopes: the site's one-hot unit, a 5×5 neighborhood of unit activity (matching the current emission field), and a 9×9 neighborhood. Test the prototypes on 48 interrupted episodes from three unseen shapes, four directions, two speeds, and both contrasts. Report site-level accuracy overall and by direction; also retain the existing whole-episode histogram accuracy as context. The labels train only these discarded evaluation probes.

Decision gate: if the single-site feature reaches at least 70% held-out accuracy, the code is locally legible and the online credit/readout rule is the leading failure. If the 5×5 feature exceeds single-site by at least 15 percentage points and reaches at least 70%, a local population-context interaction is justified. If only the whole-episode histogram works, the present representation is too distributed for this local emitter. The 9×9 scope checks whether the needed context exceeds the current emission field; do not tune its size after the run. No production change follows from probe accuracy alone.
