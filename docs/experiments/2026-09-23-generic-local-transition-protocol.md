# Unlabeled local event-transition learning

The fixed spatial motion map transferred across shapes. Test whether a similarly local, causal rule can **learn** a reusable temporal transition without object, direction, speed, or future-position labels. This remains an opt-in experimental learner, not a production architecture change.

For each polarity and each of eight cardinal offsets (one or two pixels in either direction), form a coincidence eligibility when an event at the source on the previous camera frame is followed by a same-polarity event at the offset on the current frame. Each eligible current event predicts a same-polarity event at that offset on the **next camera frame**. One nonnegative efficacy per polarity/offset is shared across positions as a repeated local motif; this weight tying is a computational hypothesis, not a measured MaleCNS synapse. At the next frame, update efficacy by `learning rate × local prediction error × stored eligibility`, averaged over eligible sites, clipped to [0,1]. No backpropagation, explicit motion label, simulator state, object mask, or eight independent tick targets enter the learner. Reset neural/event traces between episodes while retaining learned efficacies.

Train online on repeated 3×3-square translations spanning four directions, two speeds, two positions, and both contrast polarities. Freeze before evaluation. Test on held-out positions with square, plus, L, and bar shapes; compare next-frame event F1 and event-conditioned squared error with no-event, event-persistence, and fixed unit-efficacy controls on the **same frame targets**. Evaluate a separated two-object scene and matched static onset/offset controls. Primary success requires held-out event F1 to exceed persistence by at least 0.10 absolute, nonzero improvement for every shape and polarity, and no repeated static false predictions after onset. Report any direction/speed failures instead of tuning a sweep of learning rates. This only tests local next-event dynamics under simple translation; coherent entity tracking and longer-horizon prediction remain separate gates.
