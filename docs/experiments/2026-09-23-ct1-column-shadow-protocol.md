# Opt-in column-local CT1 shadow in the frozen T5 circuit

Build a separate experimental CT1 shadow around the unchanged opt-in Tm9-release/T5-order network and pinned checkpoint. It is **not** a graph-extraction or production-network change. Use the measured threshold-three Tm1/Tm9→CT1_L (body 10009) and CT1_L→selected T5 contact counts, existing excitatory Tm1/Tm9 signs, GABA inhibitory CT1 sign, graph gain, and one-tick delay per leg. Assign an input edge to the source's annotated optic column and an output edge to the target T5's afferent-inferred column; this is a compartment approximation, not a claim about exact synapse locations. Do not add any other source, edge, or inter-column CT1 interaction.

Each column receives the previous tick's Tm1 spikes and existing Tm9 graded release over its measured input contacts. Its local synaptic current decays with the network's 5 ms current constant. Use the already selected current-driven graded-release rule (250 ms blank baseline, blank p99 floor, scale 0.02, cap 0.10), with no fitted direction label or parameter sweep. Its release reaches T5 over measured CT1 output contacts one tick later as negative feedforward current. Calibrate the CT1 blank floor before all trials; start off/on comparisons from the same settled neural and shadow state. Keep the existing T5 local-order gate on in both arms.

Replay up/down moving vertical bars at y=10/y=22 speed one and withheld y=16 speeds one/two, plus bright blank and static bar. Record local T5c/T5d spike counts and mean CT1 inhibitory impulse by direction, matched event counts, blank/static responses, and release occupancy. An opt-in rescue requires at **each** calibration and holdout condition: CT1 current stronger in each subtype's null direction, at least 10% fewer null spikes, no more than 10% fewer preferred spikes, preserved subtype direction sign, and no blank-spike increase. If this fails, stop the fixed-profile test without adjusting cap, gain, or timing. Any pass would require synapse-coordinate compartment validation and later online-learning evidence before an in-place change could be proposed.
