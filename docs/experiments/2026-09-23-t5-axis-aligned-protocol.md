# Axis-aligned T5 physical-response test

The first physical order-current experiment failed its original horizontal T5c/d/static gate. That result remains failed. Primary functional maps instead associate T5a/b with opposed horizontal directions and T5c/d with opposed vertical directions ([Maisak et al., Nature 2013](https://doi.org/10.1038/nature12320)). This separate test changes only the **stimulus and evaluation alignment**. Freeze the same checkpoint, measured edges, transmitter signs, eight ticks/frame, Tm9 graded-source cap .10/current scale .02, Tm4/Tm9 rest .85, eight-tick Tm4/Tm9 order rule, 250 ms local baseline, blank p99 floor, current cap 1.0, and gate gain **8,000**. No gain is selected using axis-aligned responses.

At horizontal x=18 and x=46, move a vertical OFF bar left/right and score retinotopically local T5a/b. At vertical y=10 and y=22, move a horizontal OFF bar up/down and score local T5c/d. Each active trajectory has 13 frames, with the same 8 neural ticks/frame. Include matched blank and a static bar with the same onset/offset for every location, and confirm opposite directions have equal camera event counts. The static onset is a real contrast event and may elicit a response. It should not be required to be silent.

An axis passes calibration only if, at both positions, the two subtypes have opposite signed direction contrasts of at least 10 aggregate spikes, each subtype's sign is consistent across positions, more individual cells prefer that sign than the reverse, the preferred moving-bar count is at least 1.5× its own static-bar count, and blank firing is below 0.001 T5 spikes/neuron/tick. The actual camera x/y orientation relative to fly body axes is not assumed, so the required pair signs are determined by the first calibration position and must repeat at the second. If an axis passes, freeze its signs and test the withheld center (horizontal x=32 or vertical y=16) at both one and two pixels/frame with the same criteria. A pass would establish axis-consistent opt-in physical OFF motion expression; it would not establish T4 ON motion or local online prediction learning. An axis that fails calibration receives no held-out run or parameter sweep.
