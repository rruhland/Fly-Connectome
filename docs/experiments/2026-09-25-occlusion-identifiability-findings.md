# Variable occlusion duration makes exact visible-event timing uncertain

The [registered matched-prefix audit](2026-09-25-occlusion-identifiability-protocol.md) generated two-, three-, and four-frame disappearance episodes with identical moving pattern, start time, direction, speed, contrast, and position. It covered three unseen shapes, four directions, two speeds, two backgrounds, and three positions: **144** generic scene configurations. The comparison used only event-camera outputs; simulator parameters selected matched cases but were not predictor input.

For the two-versus-three-frame pair, **144/144** ON/OFF histories were exactly identical through frame 8, yet **144/144** next frames differed, with 1,824 signed event-pixel disagreements. For the three-versus-four-frame pair, histories were exactly identical through frame 9 in **144/144** cases, and their next frames again differed in **144/144** cases with 1,824 disagreements. At those decision points, the shorter-gap episode reappears and the longer-gap episode remains blank. No deterministic visual-only predictor can know which next event map will occur from the shared prefix.

This is a property of the new matched-start stress distribution, **not** a complete explanation for the current learner's failures on the earlier training corpus, whose gap starts differed. It does establish a requirement for generic M1A evaluation: maintain a latent belief about motion while visibility is uncertain, and score the likelihood of visible events with a proper probability-sensitive metric alongside thresholded F1. A model that outputs the correct hidden trajectory but expresses uncertain reappearance timing should not be treated as wholly wrong because one camera frame remains blank.

The next opt-in architecture experiment should learn a compact local recurrent transition for hidden visual state, separately learn a local observation/visibility head, and combine them only when predicting event-camera evidence. Use no object labels, direction channels, Pong semantics, or backpropagation in training; ground-truth trajectories remain evaluation-only. Frozen transition, state-reset, shuffled-credit, fixed sensory, quiet-frame, and calibration controls are required. No production M1A architecture has changed or been approved.
