# Frozen motion-afferent current-state screen

The prior Mi4 graded-voltage pilot failed its flash-current gate, while the new T2→Li15 analysis showed that a cell's **synaptic-current residual** can be more informative than its voltage residual. This read-only experiment tests whether the same distinction matters at Mi4, Tm4, and Tm9, the measured but spike-silent input arms for T4/T5. It changes no neuron, edge, weight, or learning rule.

Restore the pinned M1A checkpoint after its 500-tick warmup before every trial. Use the original event camera and eight neural ticks per frame. Probe a right-moving ON and OFF bar at x=18 and x=46, plus matching no-event blanks and static bars; use the same 18-frame/96-transit-tick intervals as the frozen motion-stage audit. For each source class, select local and opposite-location cells from its **direct anatomical column annotations** with the established retinal mapping. Record voltage, total signed synaptic current, spikes, and positive/negative residuals of voltage and current against a causal 250 ms baseline initialized from the warm state.

For each class/location/polarity/condition, report local and opposite-location matched stimulus-minus-blank modulation, per-cell signed-response quantiles, blank p99 exceedance, and peak local candidate tick. A source variable passes the information screen for Mi4 only if the same residual sign has at least 5% local samples above its own blank p99, no more than 2% on blank, and at least twice opposite-location mean absolute modulation for **ON at both locations**. For Tm4/Tm9 apply the same criterion to **OFF at both locations**. Report cross-polarity and static controls without fitting them. Passing would justify a separately bounded opt-in transmission test; it would not meet the T4/T5 feature or M1A learning gates. If Mi4 has no passing current candidate, do not repeat a graded Mi4 gain sweep.
