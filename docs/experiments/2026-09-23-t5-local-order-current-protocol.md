# Opt-in physical T5 local-order current

The previous Tm9 graded experiment found a transferable eight-tick Tm4/Tm9 order cue in individual T5 arm currents, but the score was an offline readout and T5 soma spikes were unstable. This frozen test asks whether a minimal **causal local interaction** can express the cue in the T5 membrane. It does not change the production network, graph, signs, delays, long-term weights, or learning rule.

For every T5 cell, maintain two 5 ms-decaying arm traces from its *measured* Tm4 and Tm9 afferent currents. Subtract each arm's local 250 ms running baseline. Compute the already preregistered eight-tick antisymmetric order, `Tm4(t−8)·Tm9(t) − Tm9(t−8)·Tm4(t)`, on those residual traces. A positive order above the cell's own blank p99 drives a bounded, nonnegative local current into **that same** T5 membrane at the next neural tick. This current does not create an edge, label a direction, or use an event target. The local floor is calibrated only on blank after the existing Tm9 source-release calibration. Test fixed gains 500, 2,000, and 8,000 with a 1.0-current cap; retain only gains whose 128-tick post-calibration blank T5 firing is below 0.001 spikes/neuron/tick and whose state remains finite. The fixed cap and gains are experiment parameters, not production recommendations.

Use the existing source-current Tm9 graded profile (`cap=.10`, current scale `.02`, Tm4/Tm9 rest `.85`), frozen checkpoint, and eight ticks per camera frame. At x=18 and x=46, replay matched bright blank, equal-event right/left moving OFF bars, and static OFF bar. Select the **smallest blank-safe gain** whose T5c right-minus-left spike count is negative, T5d positive at both locations, each subtype has at least five absolute spike contrast in local cells, and each absolute contrast exceeds its static excess-spike magnitude. Then hold that gain, floor procedure, and all parameters fixed for x=32 at one and two pixels/frame. The withheld screen requires the same contrast signs, per-cell median signs, at least five absolute spike contrasts, and weaker static excess at both speeds, while blank firing remains below 0.001. Report per-cell distributions, actual gate-current occupancy and magnitude, source release, and matched event counts. If no gain meets the calibration gate, stop without holdout or parameter search. A pass would establish opt-in physical OFF feature expression, not local online learning or M1A acceptance; T4 remains separately unresolved.
