# Can existing local history forecast an unseen reappearance?

The current onset-gated learner emits nothing on the last blank frame despite a nonzero learned motion trace. This frozen, **offline diagnostic only** asks whether that trace contains enough local spatial information to forecast the next signed event. Its decoder weights must never enter online training or production.

Use the saved balanced-exposure model and no weight updates to its learned motion/history circuit. Fit one translation-shared linear local readout from the 24-channel decaying motion trace at the last blank frame to the next frame's ON/OFF event map. Train on exactly 64 generic three-frame interruptions spanning four training shapes, four directions, two speeds, and two backgrounds at the training center. Use a 17×17 local field, matching the existing trace-context pooling radius, ridge-damped least squares, and the fixed 0.5 event threshold. The only supervised fitting is this evaluation-only capacity bound, not the proposed M1A learning method.

Before fitting, report whether target event pixels lie within 5×5, 9×9, and 17×17 fields of nonzero trace. Then score training cases; 144 held-out unseen-shape/direction/speed/background/position three-frame cases; and unseen early two-frame and late four-frame gaps. Report true/false positives, F1, target coverage, and performance by direction and gap. A zero-trace application of the same decoder is the causal control. Treat held-out familiar-gap F1 ≥0.20 with ≥0.80 geometric target coverage as evidence that a continuously active local readout is worth an online-plasticity experiment. Weaker linear transfer does **not** prove that no nonlinear or recurrent readout could work; it motivates testing learned state propagation rather than assuming a simple trace decoder is sufficient. No production code changes.
