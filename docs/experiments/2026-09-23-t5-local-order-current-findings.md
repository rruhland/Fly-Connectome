# Local order current changes T5 spikes, but the first physical screen fails

The [preregistered opt-in protocol](2026-09-23-t5-local-order-current-protocol.md) turned the previously transferable, offline Tm4/Tm9 eight-tick order score into a causal current in each measured T5 target. The source remained the frozen current-driven Tm9 graded model on its existing measured edges; all long-term weights, signs, delays, and sensory frame timing stayed fixed. The [result](2026-09-23-t5-local-order-current-results.json) includes per-cell spikes, local gate currents, blank-only thresholds, equal-event opposite trajectories, static controls, and a gate-off diagnostic. The full regression suite passed (359 passed, 4 skipped).

The local current has a genuine physical effect. With the gate off, the right-minus-left T5c spike contrast was -9 at x=18 but **+8 at x=46**, while T5d was -3/0. At gain 8,000, the contrasts became **-75/-63** for T5c and **+30/+50** for T5d. Blank T5 firing remained 2.33×10⁻⁶ spikes/neuron/tick. The gate was present on 20–39% of active local T5 cell-ticks, depending on subtype and direction. Its effect was not caused by learned weights or a trained direction readout.

The **predeclared physical feature gate failed**. At gain 8,000, the static bar produced 53/47 T5c spikes and 40/58 T5d spikes at x=18/x=46. T5d's direction contrasts of +30/+50 did not exceed these static excesses. No gain passed all four calibration conditions, so no gain was selected and the x=32 speed holdout was **not run**. The gate-off control itself had static responses of 17–23 spikes; the new current amplified a real visual onset, not merely blank noise. Static spikes were mostly concentrated in the early frames, but a late-window reanalysis did not give stable signs across both locations, so changing the scoring window is not a justified rescue.

This experiment also exposed an evaluation mismatch: it tested **horizontal** bar motion against T5c/d, whereas primary fly direction mapping places T5a/b in the horizontal channels and T5c/d in the vertical channels ([Maisak et al., Nature 2013](https://doi.org/10.1038/nature12320)). The observed T5c/d horizontal contrast is therefore not evidence of correctly organized fly subtype tuning. Preserve this screen as a failure and run a separate, axis-aligned opt-in test: horizontal T5a/b and vertical T5c/d, with a static-onset control evaluated as a stimulus response rather than assumed silent. Keep the same causal local current law, blank calibration, checkpoint, and measured edges. The separate CT1 audit also found that the pinned roster excludes the measured GABAergic route into selected T5 cells; an axis-aligned failure would strengthen the case to test that suppressive pathway with local CT1 compartments before another scalar gain sweep.
