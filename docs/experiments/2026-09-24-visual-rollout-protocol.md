# Closed-loop forecast horizon of the learned visual state

Freeze the successful 96-episode correlation-input latent learner and its matched random-dictionary control. At each evaluation frame t=3..10, score the existing one-frame primitive forecast against observed events at t+1. For horizons two through four, feed the predicted primitive image back as binary local activity at the fixed 0.5 threshold, with **no new sensory events and no weight updates**, and score its event image at t+h. Restore the true model state before processing the next real camera frame. Apply the analogous thresholded event feedback to the fixed event-correlation forecaster. Use the original held-out single-pattern set and the independent-mover, crossing, and speed-change families; keep the same anchor frames for all horizons.

Report F1 by horizon and family for learned, random, and fixed predictors, with recall and precision. This is an evaluation of the existing circuit's autonomous dynamics, not a new learning rule. If learned multi-step F1 remains useful and competitive with the fixed control, test whether its state bridges missing evidence. If it collapses rapidly, implement a distinct opt-in persistent local recurrent state before production promotion. No Pong semantics or labels enter the circuit.
