# Chunk 2: local likelihood of visible evidence

**Status:** Opt-in experiment under the [factorized world-state plan](2026-09-25-factorized-world-state-experiment-plan.md). Production M1A remains unchanged.

Freeze the [locally learned hidden transition](2026-09-25-local-hidden-transition-findings.md). Carry a local elapsed-evidence value with each hidden unit through the existing transition weights; reset it where current sensory evidence reanchors state. This timing trace never uses an occlusion label or known gap length. At sites where the transition predicts next hidden activity, train one shared local probability unit from hidden activity, nearby current evidence, and elapsed-evidence value. The delayed target is whether the next camera frame has any event within that site's 5×5 neighborhood. Use a local delta update from this observed error; no backpropagation through hidden state. The head predicts visibility probability, not a signed event map.

Train on clean and variable-gap episodes made from the four training shapes, with two positions, directions, speeds, and both contrasts. Use only event-camera input and local hidden state; shape, speed, gap length, and position select evaluation cases but never enter the model. Evaluate on the separate three unseen shapes and positions. At identical visual prefixes of two-/three- and three-/four-frame gap pairs, require exactly identical predicted probabilities, then measure Brier score against both possible outcomes. Compare with a fixed empirical hazard and a head trained with time-shuffled local credit. Also report ordinary visible and quiet-gap local Brier, candidate coverage, and calibration, so a low probability everywhere cannot pass by exploiting sparse pixels.

Treat this as successful only if the learned head beats the empirical constant-hazard and shuffled-time controls on held-out local Brier while staying calibrated on the matched ambiguous pairs (pair-level event probability near 0.5, Brier near the irreducible 0.25). If it fails, revise the local timing/evidence features or objective before any signed-event emission experiment. No production architecture change.
