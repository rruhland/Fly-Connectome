# Opt-in graded T2 propagation on measured edges

This is the first transmission test under the [approved visual-architecture amendment](../plans/2026-09-23-m1a-visual-architecture-amendment-proposal.md). It changes no in-place network or checkpoint. The [frozen source audit](2026-09-23-source-signal-findings.md) selected only T2's positive 250 ms voltage residual, so this first bounded run grades **all T2 outgoing edges** and leaves T2a/T3 spike-only. That distinction prevents a weak source candidate from being promoted simply because another class passes.

The experimental `GradedVisualNetwork` replaces spike arrivals from T2 on every existing outgoing edge with a nonnegative release fraction. For source cell `i` at tick `t`, release is `clip((V_i(t) − EMA_250ms(V_i)(t−1) − q99_i)/0.01, 0, cap)`, where `q99_i` is the 99th percentile of positive residuals during the last 128 of 500 no-event warmup ticks. It is computed only from that cell's past voltage; it sees no stimulus label, future event, Pong state, or readout error. Each edge retains its measured sign, delay, pathway, and current magnitude. Predictive excitatory arrivals retain the already established area-matched 20 ms kernel; other arrivals use their existing kernels. The state is opt-in and frozen: no weight update is made.

Candidate release caps are 0.01, 0.03, and 0.10. Calibrate each from the same restored 500-tick source state, then settle 256 no-event ticks with graded output enabled. Select the largest cap with finite state, p99 absolute T2-added Li15 impulse at most 0.05 over the last 128 ticks, and Li15 blank spike rate below 0.01 per neuron/tick. Motion labels do not influence cap selection. If none pass, stop. The cap is a fraction of the original spike impulse, so this is a bounded pilot rather than a new free weight.

For a passing cap, restore the identical settled graded state before 18-frame, eight-tick/frame matched ON/OFF blank, moving dot, moving bar, and static dot probes at x=18 and x=46. Report local/opposite-location T2 release, T2 spike counts, and direct graded impulse, total signed current, voltage, and spikes for Li15, MeLo10, TmY19a, and MeLo8, including per-cell distributions. Check graph/checkpoint identities, unchanged weights, finite state, transmitter sign, and low blank output. A **partial T2→Li15 transmission screen** requires, in all four moving-dot conditions, local T2 release at least 5% above its matched-blank p99, Li15 mean absolute graded-impulse modulation at least 0.002, and Li15 p90 per-cell absolute voltage modulation at least 0.002. This is not the amendment's full transmission or motion-feature gate; MeLo10 depends mainly on T2a, which did not pass the source screen. Bar/static controls are characterized, not required to be silent.
