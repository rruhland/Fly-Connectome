# A temporal state transition over learned local pair identities

**Status:** Opt-in M1A architecture test. The predictive-pair assemblies acquired transferable spatial direction information, but directly decoding their future templates did not transfer forecasts to new speeds/shapes. This experiment freezes those learned identities and asks whether a separate locally plastic temporal state transition, followed by a **signed** correction of the fast predictor, can turn the code into an effective world state. It changes neither production M1A nor the measured connectome.

Train the same frozen fast field and aligned-pair slow identities on the same 64 generic unlabeled scenes. At each meaningful event, a slow unit receives the *current* signed local fast-prediction error relative to the preceding event. A shared local decoder learns that error from its current sparse activity. A 3×3 recurrent kernel learns to predict the next sparse slow winner from the current winner using local next-state error and presynaptic eligibility. At inference, the transition predicts future slow activity, the signed local decoder maps it to an additive or suppressive correction, and the frozen fast prediction supplies the baseline. No future observation is used at inference; no labels, oracle object regions, rewards, Pong semantics, backpropagation, or gradient tape enter learning.

Matched controls use one identity/decoder: aligned next-winner transition, time-shuffled next-winner transition, and frozen self-persistence. All have the same initial weights and training exposures. Keep the direct paired-template forecast and fast-only predictor as reference architectures. Evaluate next-meaningful-event top-8/top-32 recall and precision on held-out generic, speed, position, shape, separated, and crossing scenes. Include paired case wins and the same fixed offline 3×3 spatial probe and autonomous activity/component measures. Because identity is fixed, slow state metrics should be identical across temporal arms; differences in forecast isolate the transition.

Run once without tuning on evaluation sets. A useful temporal pathway must beat both transition controls on speed and shape, preserve or improve fast-only recall within three points on each, and avoid a crossing collapse. If it fails, do not sweep recurrent gain or signed-decoder scale; change the architecture at the state/forecast interface or abandon this latent family.
