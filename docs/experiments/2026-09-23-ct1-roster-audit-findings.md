# The selected T5 circuit loses its measured CT1 inhibitory route

The [read-only audit](2026-09-23-ct1-roster-audit-protocol.md) compared the pinned checkpoint with the original MaleCNS contacts and body-level neurotransmitter evidence. [Results](2026-09-23-ct1-roster-audit-results.json) are reproducible with `scripts/motion_ct1_wiring.py`; the complete test suite remained at 357 passed, 4 skipped. It changed neither the checkpoint nor the graph.

The selected right-side T5 cells receive **3,356 measured edges / 80,978 contacts** from CT1 body **10009**, including 3,355 edges above the milestone's three-contact path threshold. The selected Tm1/Tm9 cells make **1,765 edges / 32,728 contacts** onto that same CT1 body, including 1,715 edges above threshold. MaleCNS annotates body 10009 as `CT1_L` by **soma** side and labels its transmitter GABA by ground truth. The pinned graph instead contains `CT1_R` body 10157; it has zero such contacts with the selected T5 or Tm1/Tm9 cells. The extraction rule requires visual cells to have `somaSide == 'R'`, so it excludes the anatomically relevant left-soma CT1 before roster selection.

This omission is plausibly material to T5 tuning. Braun, Borst, and Meier experimentally identify a Tm1/Tm9→CT1→T5 inhibitory motif that suppresses null-direction responses; removing CT1 broadens T5 tuning ([Current Biology 2023](https://doi.org/10.1016/j.cub.2023.05.007)). Yet CT1 is a broad arbor with locally isolated processes in that study, so simply inserting body 10009 as a *single point neuron* could mix distant columns and create a misleading rescue. The aggregated body-to-body weight table does not identify which CT1 contact belongs to which local process. Restoring its measured body and edges is therefore a separate opt-in anatomical/compartment test, with an explicitly inferred local mapping if attempted. No production roster change follows from this audit alone.

The immediate approved T5 experiment should still test whether the already measured, transferable Tm4/Tm9 order cue can affect the physical T5 membrane through a fixed local state. It must not treat the CT1 omission as proof that a T5 timing gate will work. If the gate fails, the missing CT1 suppressive route becomes a leading explanatory hypothesis rather than a reason to keep sweeping scalar gains.
