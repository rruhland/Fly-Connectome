# Frozen-code local future-decoder capacity test

Freeze the experience-learned sensory and transition dictionaries from the previous opt-in experiment. Build a sparse feature field: each active transition unit supplies a distinct feature at each site in its existing local 5×5 output neighborhood. Fit one offline ridge-linear decoder per future ON/OFF event polarity (ridge penalty 1, zero intercept) from square training episodes. This **evaluation-only diagnostic** may use a global linear solver; its weights must not enter M1A, and it is not a proposed plasticity mechanism. Compare a matched decoder built on random transition units, with the same raw sensory code, as well as the fixed event-correlation sensory control. No motion/object/game labels enter any dictionary or the decoder target; the only target is the observed next event image.

Use exactly the prior t=3..13 next-camera-frame targets and held-out plus/L/bar shapes. Report training and held-out event F1 at 0.5, a small fixed threshold profile, candidate MSE, performance by speed/polarity, and the fraction of next events inside at least one active unit's reachable 5×5 field. If the learned-code decoder reaches materially useful held-out prediction (F1 ≥0.70 and at least 0.10 above the random-code decoder), local credit/readout is the principal gap. If it fits training well but transfers poorly, the code overfits square trajectories. If even training fit or reachable coverage is weak, longer or richer temporal state is needed before another local plasticity rule. This is a capacity comparison, not a proof about all possible nonlinear decoders, and production M1A remains unchanged.
