# Do fast sensory predictions and persistent entity state carry complementary futures?

**Status:** Registered opt-in architectural comparison. Production M1A and the measured connectome remain unchanged. The generic held-out observation motivating this run was fast-only top-32 recall .360, coherent entity files .331, and equal reciprocal-rank fusion .523 at the same 32-site budget, with only 1.7 overlapping top-32 sites per event. That discovery set is now a **confirmation** set, not a new tuning set.

Use the existing fast locally plastic field trained on 64 unlabeled generic streams and the same learned-affinity entity files (the affinity is frozen after those streams; file dynamics still update online within each episode). For each next meaningful event, compare full-frame signed ON/OFF top-8/top-32 recall and top-32 precision from (1) fast field alone, (2) entity files alone, (3) an equal reciprocal-rank sum of the two forecasts, and (4) the same sum with entity forecasts time-shuffled across unrelated event observations. The rank sum is an engineering complementarity probe, **not** a proposed biological implementation or a trained final readout. No true object mask, location, count, identity, game concept, or reward enters it. Evaluate the same 16 generic held-out streams and controlled position, speed, shape, separated, and crossing sets. Preserve per-case counts and source top-32 overlap; no weights or thresholds are selected on the confirmation sets.

**Decision rule:** Complementarity is credible if equal fusion beats both sources on generic scenes and the shuffled control, while remaining within three recall points of the stronger source on changed speed, changed shape, and separated entities. If it only improves generic scenes by sacrificing controlled transfer, the next experiment should learn local context-sensitive arbitration from predictive error; do not tune a global blend on held-out cases. If fusion passes broadly, test whether a locally plastic arbitration layer can express it with no backpropagation. Neither outcome alone fixes noisy false entity births or clean crossing identity switches, so neither authorizes production promotion.
