# The nearest-site CT1 shadow inhibits before preferred events, after null events

The [event-aligned protocol](2026-09-23-ct1-event-aligned-protocol.md) kept the geometry-routed CT1 shadow and all frozen weights/kinetics unchanged. It anchored each local T5 cell to its strongest **non-CT1 feedforward-arrival increment** from the off arm, then examined the on arm's CT1 impulse and off/on spikes around each direction's own event. All locally selected T5c/d cells cleared the 0.005 anchor threshold in both directions. The [result](2026-09-23-ct1-event-aligned-results.json) fails the predeclared timing screen in all eight subtype/condition comparisons.

Across y=10/y=22 and withheld y=16 at two speeds, mean CT1 inhibition in ticks −4…0 before the local event was **0.0031–0.0044 per cell/tick during preferred motion** but only **0.0015–0.0023 during null motion**. Null-minus-preferred pre-event inhibition was negative in every comparison (**−0.00167 to −0.00271**). Only **41–52 of 150–195** cells with any pre-event CT1 current had more inhibition before their null event. The preferred-direction average CT1 impulse peaked at **+1 tick** relative to the feedforward anchor; the null-direction profile was still rising at the **+8-tick edge** of the sampled window. Local null-window spike reductions were mostly below 10%, and the one 11.6% case did not satisfy the full eight-part timing gate. Ordinary feedforward arrivals were recorded separately and excluded the injected CT1 current.

This corrects the prior [offset finding](2026-09-23-ct1-offset-findings.md)'s informal phrase “null-motion side.” In screen coordinates, T5c's nearest CT1 input is below its target and T5d's is above. A **preferred** moving bar reaches those displaced inputs *before* each T5 target; a **null** bar reaches them *after*. The frozen temporal result follows that order. The static opposed offset is real, but assigning CT1 output to its nearest input site selects an arm whose timing is wrong for null suppression. Euclidean proximity alone does not identify which CT1 input and output synapses share an electrically effective process. This inference does not claim that biological CT1 inhibits the preferred direction; it identifies a failure of the present nearest-site shadow.

The next useful step is anatomical branch tracing or a focused, separately preregistered physiology-grounded CT1 timing model. A scalar gain increase cannot reverse this phase order. The production roster and plasticity rule remain unchanged; there is still no evidence to promote CT1 or claim M1A online predictive learning.
