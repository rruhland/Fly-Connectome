# CT1 synapse sites are retinotopically organized, despite the broad body arbor

The [predeclared synapse-geometry audit](2026-09-23-ct1-synapse-geometry-protocol.md) queried only pinned-roster Tm1/Tm9→CT1_L body 10009 and CT1_L→T5c/d contacts from the public `male-cns:v1.0` neuPrint graph. A neuPrint `SynapseSet` traversal reaches one physical pair through multiple paths; counting **distinct pre/post site pairs** reconciled exactly with the original downloaded weight table: **32,728 inputs and 37,186 outputs**. The deduplicated CT1-side coordinates were cached under ignored `runs/`; the [summary](2026-09-23-ct1-synapse-geometry-results.json) includes the cache checksum and source identities.

For CT1→T5c/d output contacts in the withheld y=16 field, the nearest measured Tm1/Tm9 input onto CT1 was a median **80 voxels (0.64 µm)** away in 3D, with 95th percentile about **124–125 voxels (1.0 µm)**. Every output contact had an input within 5 µm, a permissive distance screen. The nearest input's assigned optic column was the same or one hex neighbor from the T5 target's afferent-inferred column for **45.3% of T5c** and **35.5% of T5d** contacts. Shuffling source body-to-column labels 100 times while keeping all contact coordinates fixed gave means **0.80%** and **0.76%**, with maxima **2.16%** and **2.43%**. The two calibration fields gave similar observed fractions (T5c 46.1%/40.5%; T5d 35.2%/32.6%). These are strong *spatial association* results, though the simple same-column model still misassigns more than half of each subtype's nearest partners.

The closest input was usually Tm9 (about 87% of these output contacts). Euclidean proximity cannot establish that two synapses lie on an electrically continuous CT1 process, and the T5 column itself is inferred. The fixed-profile column shadow's weak, direction-symmetric inhibition is therefore still a failed functional test. The next bounded anatomical question is whether the **retinotopic offset** from the nearest CT1 input to each T5c/d output has a consistent subtype-specific vertical sign across the two fields and holdout. If so, a geometry-routed *opt-in* compartment can be tested without assuming that CT1 simply mixes same-column partners; if not, a morphology or different motion-stage mechanism is needed. No production architecture change is supported yet.
