# Learned local transition-unit result

This opt-in circuit learned a local sensory dictionary from raw ON/OFF events, froze it, then learned a second population from ordered current/previous sensory-code neighborhoods. No direction, speed, object, or game labels entered either dictionary or the delayed local predictive-error update.

The transition population reached **34/48 (70.8%)** four-way direction accuracy on held-out plus/L/bar shapes with a post-hoc nearest-centroid probe, versus **15/48 (31.3%)** for its random initial dictionary. Its effective occupancy was **22.4 of 24** units. This shows experience-dependent, reusable spatiotemporal coding in the controlled scene. The prior learned sensory dictionary alone reached **33/48**, so the second population has not yet shown a large *additional* representation gain over its input.

Delayed local prediction improved next-event F1 over the matched shuffled-future control at **both** speeds: one pixel/frame **0.213 versus 0.008**, two pixels/frame **0.173 versus 0.033**. Overall held-out event F1 was **0.188 versus 0.023** shuffled; direct next-latent F1 was **0.055 versus 0.000**. That meets the experiment's narrow causal-learning comparison but is far from a useful forecast: the fixed local-correlation control scored **0.977** on the same simple translations. The learned predictor fit training square trajectories to only **0.362 event F1** and **0.286 latent F1**. A post-result threshold check peaked at **0.296 event F1** and **0.138 latent F1**, so calibration alone cannot explain the gap.

The first full run took **116 seconds** for 96 training episodes plus evaluation. An exact sparse active-site patch extraction reduced that to **49 seconds**, with every experimental metric unchanged; the parity test includes image borders. This is still an opt-in prototype, not a production throughput result. Do not promote it. The next decisive diagnostic is an empirical local transition table on the **same frozen transition codes and topology**, estimated from observed pre/post co-occurrences rather than the current scalar error update. If that table also predicts poorly, the code lacks the state needed to specify the future. If it predicts well, the local credit/normalization or code-to-sensory target is the bottleneck. This comparison should precede a new predictive mechanism.
