# Distributed predictive field: one architectural comparison

**Status:** Completed opt-in experiment following the [graded file-state failure](2026-09-26-graded-visual-state-findings.md); see [findings](2026-09-26-distributed-predictive-field-findings.md). Production M1A is unchanged.

Test whether a continuous spatial state can learn next-event prediction without object proposals, file birth, identity association, or an inferred true count. Every location keeps fast and slow signed event traces, a signed visual contrast belief nudged (not reset) by an occasional absolute observation, and a recurrent copy of its last predicted event field. A shared local spatial kernel maps that state to the next signed event. Each kernel weight receives only the product of its local source activity and local next-event prediction error; no gradient flows through the recurrence, no backpropagation, and no object/game labels or hand-coded motion bank enter learning. The kernel is the learned spatial-temporal representation; the traces and intensity are sensory primitives.

Train once on the same 64 unlabeled generic streams, with aligned absolute contrast every eight frames. Freeze weights for four clean and corrupted held-out generic scenes and the stationary noisy scene. Compare (1) learned aligned intensity, (2) identical learned weights without intensity during evaluation, (3) unrelated-scene shuffled intensity, and (4) a separately trained kernel whose next-event credit was shuffled within each training episode. Score full-frame top-8/top-32 next-event recall, positive forecast mass on target versus non-target sites, and state occupancy/false spatial mass. Use the prior fast field and graded file scores as external controls on exactly matched corrupted/clean streams. Do not change kernel size, trace decays, recurrence gain, learning rate, or intensity cadence after viewing held-out results.

**Decision:** A useful distributed candidate must improve corrupted top-32 recall over graded files (.331) without dropping clean top-32 below graded files (.466), while aligned learning beats shuffled temporal credit and unrelated intensity. If it does not, reject this simple local-kernel family rather than sweep rates or append another gate. Any production architecture still requires user review and later broader transfer tests.
