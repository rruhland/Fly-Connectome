# Balanced generic exposure makes online local interruption forecasts transfer

The [registered opt-in experiment](2026-09-25-balanced-interruption-exposure-protocol.md) appended 64 interrupted trajectories to the original 128-episode corpus. These cover four training shapes, four directions, two speeds, and two backgrounds at the training center. All candidates received the same 192 episodes. The learned history code, locally delayed one-frame event error, separate raw-ON/OFF emission banks, learning rate, threshold, and archived predictor were unchanged. No gradient, direction label, object label, or Pong-specific signal trained the circuit.

| Exact next-event F1 after interrupted reappearance | Archived | Learned unsplit | Learned sign split | Random sign split | Learned trace reset |
| --- | ---: | ---: | ---: | ---: | ---: |
| 64 added training episodes | 0.000 | 0.086 | **0.437** | 0.201 | 0.000 |
| 144 unseen-shape/position episodes | 0.000 | 0.114 | **0.434** | 0.175 | 0.000 |

The learned split candidate improved from **0.289 to 0.434** exact F1 compared with the first 128-episode run, passing the preregistered 0.40 gate. It scored 870 true positives, 978 false positives, and 1,290 misses across 2,160 target events. Its 0.320 F1 advantage over unsplit and 0.259 advantage over random both exceed the 0.10 control gate. Direction transfer is now broad: up 0.449 (216 TP), down **0.464 (213 TP)**, left 0.435 (261 TP), and right 0.388 (180 TP). The prior near-silent down direction was therefore substantially an exposure-coverage problem, not proof that this local code could not learn it. Resetting the motion-history trace at reappearance removed every exact true positive, establishing causal use of that local history.

Ordinary unseen single-pattern F1 remained 0.669, exactly the archived predictor's score. Quiet-target false alarms were 109 pixels versus 97 archived, below the registered 194-pixel limit. The broader robust-family scores mostly match the archived predictor: independent movers 0.681 versus 0.681, crossings 0.581 versus 0.583, speed change 0.634 versus 0.634, noise 0.486 versus 0.487. Generic occlusion as a *full sequence* reached only 0.444 versus 0.430 archived, and is below the earlier 128-episode candidate's 0.460. The strong exact reappearance result should therefore **not** be mistaken for a complete sustained world model. Its matched opposite-motion pair scored 0.286 F1; history separation is present, but individual forecasts still miss many events.

This clears the registered online-transfer controls for one specific forecast transition without changing production M1A. The next decisive check should vary interruption length and timing, including cases unlike the three-frame training gap, with frozen weights. Require useful signed forecasts before and after the gap, not only at the chosen t=10→11 transition, and compare a simple fixed sensory forecaster. If transfer is narrow, improve temporal credit or state dynamics before preparing a production revision. The Python experiment took 665 seconds, so exact-behavior implementation speed remains a separate production gate. No production architecture revision has been made or approved.
