# Distributed recurrent predictive sheet

**Status:** Registered opt-in M1A architecture pivot. The globally capped sparse paired-unit family is rejected: its motion code was decodable at known locations, but live state fragmented and learned continuity worsened transfer. This experiment replaces that slow stage. The fast locally trained predictor remains a frozen sensory primitive. Production M1A and the measured connectome remain unchanged.

At every coarse location with local fast sensory support, a sheet of 16 units carries a **graded, locally normalized mixture** of activations. No frame-wide winner budget, object detector, direction bank, or slot assignment is used. Each unit receives a shared 7×7 present-and-previous-fast patch and a shared 3×3 recurrent neighborhood. Subtracting the local unit mean and normalizing positive activations implements local competition; quiet frames decay the state. On meaningful observations, local sensory evidence and recurrent prediction jointly determine the *live* state. Recurrent continuation can occupy at most one coarse site beyond current sensory support, with amplitude bounded by the local prior, to limit unsupported trails.

The output synapses decode the state to an 11×11 **signed** correction of the frozen fast predictor. Delayed next-fast prediction error trains the output synapses through local state eligibility. The same delayed evidence contributes to local soft assignment during sensory-template learning, so latent identity can specialize for prediction. Present fast patches train feedforward templates by local weighted Hebbian averaging. A local next-state error times presynaptic eligibility trains the recurrent kernel. Training uses no gradient tape or backpropagation. Future observations are available only for delayed local credit, never for inference.

Train on the same 64 unlabeled generic scenes. The learned feedforward/output templates are shared by four sheets: aligned recurrent credit, time-shuffled recurrent credit, frozen self-recurrence, and zero recurrence. Compare against the identical frozen fast-only predictor. Use the registered held-out generic, position, doubled-speed, changed-shape, separated, and crossing cases. Report full-frame next-meaningful-event top-8/top-32 recall and precision, paired-scene wins, fixed offline 3×3 spatial direction decoding, activity outside offline entity neighborhoods, and connected components per active frame. For the distributed sheet, spatial occupancy means **summed local latent activity above 0.5**, rather than any one unit above 0.5; otherwise a valid distributed code would appear falsely silent. Oracle coordinates are used only after inference. No tuning on held-out results.

A useful M1A foothold requires the aligned sheet to beat shuffled and frozen recurrence on speed and shape, preserve fast-only top-32 recall within three points on both, retain at least 14/16 direction decoding on both, have at most 2.5 components/frame and 30% outside-neighborhood activity on separated movers, and avoid crossing collapse. Otherwise reject this sheet implementation without a parameter sweep. The next decision would then be whether explicit learned entity binding/object files or a different local learning objective is necessary, rather than returning to sparse global competition.
