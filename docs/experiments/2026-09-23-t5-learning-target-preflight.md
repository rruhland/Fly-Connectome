# Local T5 learning-target preflight

The axis-aligned T5 result is a frozen feature, not learning. Before training, the saved graph shows **1,013 predictive edges / 6,167 contacts into T5c** and **1,302 edges / 8,019 contacts into T5d**, mostly same-subtype recurrent or LPi sources. These are measured edges, so a layer-local next-frame predictor can receive eligibility without inventing a new connection. T5 has **zero direct edges to the externally observed L1/L2/L3 sensory targets**; an experiment measuring only sensory-target error would not directly credit a T5 output synapse. The original `FramePrediction` rule can score T5's own feedforward arrivals locally, while the `MultiContextTimedPrediction` variant narrows its forecast targets to directly observed sensory cells. This difference must be explicit in the next controlled task.

The opt-in graded network had a concrete observation mismatch: Tm9 graded release entered T5 `feedforward_current`, but `Activity.feedforward_arrivals` captured only spike arrivals. With `visual_target='input-arrivals-v1'`, the local plasticity rule would therefore learn against a target missing the Tm9 event that physically drove the cell. The experimental `GradedVisualNetwork` now adds **only its graded feedforward increment** to captured `Activity.feedforward_arrivals`; predictive/behavioral graded currents remain excluded from the observed target. Unit tests cover excitatory Tm9 and both transmitter signs on a T2 feedforward edge, as well as keeping a predictive graded edge out of the observed feedforward target. The physical state and frozen T5 experiment are unchanged because those probes did not request captured increments. Full regression: 360 passed, 4 skipped.

The next bounded learning test can now use the existing `FramePrediction` equation, local feedforward-arrival target, and measured predictive eligibility at T5c/d, with the T5 timing current fixed. It should compare trained and frozen forecasts on a held-out vertical trajectory and audit whether relevant T5 predictive edges actually receive nonzero updates. A failure with zero eligibility is a credit-path finding; a failure despite nonzero, sign-consistent local updates points to the learning objective or temporal supervision.
