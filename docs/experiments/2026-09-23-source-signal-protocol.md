# Frozen source-local release-signal audit

This opt-in analysis tests the first gate of the [approved M1A amendment](../plans/2026-09-23-m1a-visual-architecture-amendment-proposal.md) without changing the graph, neural dynamics, plasticity, or source checkpoint. Run `python scripts/motion_source_signal_audit.py` from the repository root. The script records checkpoint, annotation, and graph identities in `2026-09-23-source-signal-results.json`.

After the pinned 500-tick warmup, restore the same full neural state before every 18-frame probe. Use eight neural ticks per frame, polarity-matched no-event blanks, and moving dot, moving bar, and static dot at x=18 and x=46 for ON and OFF. Retinotopic source groups for T2, T2a, and T3 are inferred from their measured afferents as in the prior object-pathway audit; those groups are analysis-only and never fed to the network. Compare ticks 24–119, corresponding to the common transit interval.

Inspect each source's membrane voltage and total signed synaptic current (feedforward plus predictive plus behavioral). T2/T2a/T3 incoming edges are predominantly assigned to the simulator's predictive pathway, so a feedforward-only measurement would discard the relevant input. Candidate local release variables are the positive and negative halves of voltage or current relative to that same cell's causal 250 ms exponential baseline. The baseline is initialized from the restored warm state and updated only from prior/current local state. No event label, future sample, direction, or Pong state enters a candidate variable. This audit does not itself transmit release.

For every class/location/polarity/stimulus, report matched tickwise stimulus-minus-blank local and opposite-location response, source spikes, per-cell signed-response quantiles, and the fraction of local stimulus and blank values above each source's own blank 99th percentile. A candidate passes this *source-screen only* when, for all four moving-dot combinations, at least 5% of its local source samples exceed that source's matched-blank p99 and local mean absolute modulation is at least twice opposite-location modulation, with finite state. Passing is evidence to try opt-in transmission, not permission to promote the in-place model. Bar/static responses are reported as controls and are not assumed to be zero.
