# Local affinity binding: learned visual fragments or fixed connectivity?

**Status:** Registered opt-in M1A experiment. Production visual learning and the measured connectome remain unchanged. This follows the [entity-file result](2026-09-26-persistent-entity-files-findings.md): a short read-only audit found that most generic surplus files are born on the first frame from diagonally touching pixels that the four-neighbor sensory proposal rule splits. Long-lived files then preserve those fragments. The prior generic held-out and stress sets remain frozen.

Test a materially different explanation of the generic failure: the entity file may already have sufficient temporal state, but its initial sensory proposal graph may be too disconnected. Compare four arms with identical file matching, local displacement credit, and full-frame forecast:

1. Existing four-neighbor proposals.
2. Fixed eight-neighbor proposals, an engineering ceiling for this local geometry.
3. Locally learned diagonal affinity, shared across visual positions and learned from 64 unlabeled generic training streams. Each confident signed pixel predicts same-sign occupancy at one of four diagonal neighbors; local prediction error updates that offset/polarity's coupling. Bind a diagonal pair only when the aligned co-activity count exceeds a time-shuffled null by five Poisson standard deviations. Freeze the learned couplings for evaluation.
4. Time-shuffled affinity, using the same local update and threshold but unrelated target frames, to check whether experience-aligned visual structure matters.

No object identities, true masks/counts, trajectory labels, Pong semantics, or held-out-derived thresholds enter training or inference. This is a low-level sensory binding experiment; a learned affinity must not be mistaken for a complete entity representation. All arms retain the prior within-scene local motion update. Save the learned couplings and compare each arm on the same 16 generic held-out streams, controlled position/speed/shape, separated entities, clean crossings, different-shape crossings, and static noise. Score live-file count per active frame, crossing identity switches, and full-frame top-8/top-32 next-event recall/precision against the prior fast-only baseline. The clean forecast improvements must survive.

**Decision rule:** A promising reusable M1A step needs materially fewer generic count errors than four-neighbor and shuffled affinity, no loss greater than three top-32 recall points on changed speed or shape, and no worse clean crossing identity continuity. Report separately whether fixed eight-neighbor does as well; if so, this is mostly a sensory-geometry correction, not evidence that learned recurrent binding is necessary. If none reaches the trained fast-only generic forecast or robust noise count, do not promote this as a complete world-state. Do not tune neighborhood, threshold, or slot lifetime on the held-out cases. Move next to a substantially different reliability/continuity mechanism or visual refresh, rather than another small threshold sweep.
