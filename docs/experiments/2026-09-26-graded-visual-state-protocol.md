# Graded recurrent visual state under uncertain event and intensity evidence

**Status:** Completed opt-in Stage 1 of the [graded-state pivot](../plans/2026-09-26-graded-visual-state-pivot.md); see [findings](2026-09-26-graded-visual-state-findings.md). Production M1A, measured graph, and motor learning remain unchanged. This is a new state representation, not another file-lifetime or refresh-radius variant.

Each visual hypothesis holds a **soft signed spatial support**, local confidence/evidence, a center, and a locally updated continuation. Event input changes a continuous contrast belief; an occasional absolute frame nudges that belief toward the observed signed contrast without replacing it. Connected local evidence supplies proposals only. Existing hypotheses predict and compete for proposals; each accepted proposal changes the soft support by its own local prediction error. Confidence rises with repeated compatible evidence and falls gradually on unsupported evidence. A new proposal begins uncertain, while an aligned absolute observation can confirm a quiet genuine region. No fixed true count, identity, object mask, direction, Pong concept, reward, or backpropagation enters inference.

Train the low-level diagonal sensory affinity on the original 64 unlabeled generic streams and freeze it. Compare graded state with aligned absolute observations every eight camera frames, the same model with event input only, the same model with absolute observations shuffled across unrelated held-out scenes, the prior event-only entity files, and the hard-reset refresh arm. Use the same four clean/corrupted held-out generic streams and stationary noisy case. Score the **autonomous** number of live hypotheses, duplicate/birth count, and full-frame next-event forecast. Clean absolute frames may be reconstructed from the camera stream for the evaluator; they are sensory observations, not entity labels. During corrupted evaluation, model event input is corrupted while the aligned intensity channel remains independent and clean. Do not change support rates, confidence thresholds, the eight-frame schedule, or connectedness based on held-out results.

**Decision rule:** A viable graded state must keep clean wrong-count fraction near the prior event-only level (under 10%), cut corrupted wrong-count fraction below the hard-reset eight-frame arm, and improve corrupted forecast without losing clean forecast. If shuffled intensity also works, the model is exploiting marginal occupancy rather than aligned visual evidence. If the state still churns or suppresses quiet true regions, stop this implementation and reconsider the latent family before testing timing or Pong. A passing Stage 1 remains opt-in; production promotion requires user review after later timing/connectome transfer tests.
