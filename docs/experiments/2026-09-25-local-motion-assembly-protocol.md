# One-shot local motion-assembly experiment

**Status:** Opt-in M1A architecture experiment; no production promotion. The goal is to test a representation that consists of sparse, persistent local assemblies rather than an independently updated latent at every pixel. The user has authorized experiments without a separate approval request. The existing observed 24-unit code is retained only as sensory evidence; the rejected recurrent hidden state and event-forecast head are not reused.

Each camera frame yields sparse local candidate responses from event pixels and the observed learned code. A one-pixel local winner rule removes redundant adjacent candidates. A candidate has no direction, object, or game label. From 64 unlabeled generic native-cadence scenes, local Hebbian counts learn which feature pairs tend to recur at each displacement within a bounded spatial neighborhood across meaningful event frames. Normalizing those counts gives a shared local transition affinity. A token assembly carries its last position, feature mixture, and short activity history through up to eight quiet frames. Candidate-to-assembly competition uses this learned affinity and a fixed spatial proximity term; unmatched candidates start new assemblies. The same frozen sensory code and candidate stream feed a proximity-only association control and a temporally shuffled Hebbian-credit control. No backpropagation, global identity labels, or Pong-specific rule enters learning or inference.

One run will freeze all weights before evaluation on the previously registered position, speed, shape, separated-entity, and crossing suites. At inference each model receives the complete event stream with no object masks. Evaluation alone matches output assembly histories to synthetic ground-truth paths and measures object coverage, four-way direction accuracy, and identity continuity through crossings. A result counts as useful only if the learned assembly matches or beats the proximity control on the simple transfer sets, beats both proximity and shuffled credit on separated/crossing cases, and reaches at least 75% per-object direction accuracy on separated movers. If it does not, stop this implementation path rather than tuning radii, decay, or classifier thresholds; reassess the representation mechanism. A passing generic result would justify a separate zero-shot native-stream test before any production proposal.
