# Causal recurrent-inference probe

The homeostatic local sensory dictionary transferred across shapes, but its recurrent predictor did not help form the current latent code and fit even training motion weakly. Test one opt-in architectural change: at each current event site, choose the latent winner using learned sensory similarity, homeostatic excitability, **and 0.5 × the recurrent prediction formed from the preceding latent activity**. That prediction is causal and local; it uses no future event, motion label, or object identity. The same previous-site eligibility and postsynaptic latent prediction-error update then learns recurrent synapses. This makes the active code depend on both current sensory evidence and experienced temporal context. No production M1A code changes.

Keep 12 latent channels, 5×5 local sensory and recurrent footprints, the fixed training/held-out sequences, rates, three training passes, and scoring from the [homeostatic probe](2026-09-23-learned-latent-homeostasis-protocol.md). Compare to its saved zero-feedback result, a time-shuffled recurrent control with the same feedback rule, a random sensory dictionary, and the fixed correlation predictor as a low-level control. Require both a material held-out forecast gain (at least +0.10 F1 over 0.147) **and** a full-state direction probe at least +0.10 above the time-shuffled state before treating this as promising. Also inspect training fit and one-/two-pixel tempo separately. If the feedback only changes amplitude or improves one tempo at the other's expense, stop this variant and move to a more persistent recurrent state/error organization.
