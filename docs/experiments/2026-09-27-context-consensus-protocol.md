# Context-credit repair and promotion checks

User authorized the investigative fix and promotion conditional on passing gates.
The initial hypothesis of mismatched tracker history was rejected: four context
updates occurred, with zero timestamp mismatches. Only one was unconfirmed.
All four updates came from early period-four motion, with large conflicting
corrections. They become the nearest retrieval examples for normal crossing
motion. Blindly averaging these contradictory outcomes creates a false shift.

One bounded repair: retain the existing neighbors, weights, learning and memory
capacity. For each output axis, apply the retrieved weighted correction only if
all selected outcomes are nonnegative or all are nonpositive. Otherwise abstain
on that axis and retain the uncorrected carried motion. Zeros are neutral. This
is a conservative agreement rule, not a calibrated statistical confidence bound.
It adds no task labels, magnitude cap or tuned threshold. It does not disable
learning. Coordinate-wise consensus is not a claim of arbitrary rotation equivariance.

The one experiment on the previously failed trained checkpoint recovers 172/180
outage supports (registered requirement >=95%), preserves all identities and
cached forecasts, and preserves 64/64 spatial and 64/64 appearance relations.
