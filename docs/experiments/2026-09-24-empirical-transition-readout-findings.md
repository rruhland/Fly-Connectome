# Empirical transition-readout diagnostic

The diagnostic retrained the same unlabeled sensory and transition dictionaries; the transition-code probe reproduced **34/48** held-out direction cases, matching the prior run. It then estimated each existing 5×5 local outgoing weight from the observed next sensory-code frequency conditional on the active transition unit. This was an empirical comparator, not production plasticity.

The empirical table improved held-out next-event F1 to **0.298**, versus **0.188** for the delayed local-error rule and **0.151** for a matched table with shuffled future targets. Direct next-latent F1 rose to **0.224**, versus **0.055** for the error rule. Both speeds improved over shuffled targets (event F1 **0.256 versus 0.074** at one pixel/frame; **0.328 versus 0.194** at two). Yet training-set event F1 was only **0.369**, nearly unchanged from the error rule's **0.362**; training latent F1 rose from **0.286 to 0.395**. The registered +0.15 gate on both held-out event F1 and training event F1 was **not met**. The fixed local-correlation control remains **0.977** on these clean translations.

The event-F1 comparison is threshold-sensitive. At threshold 0.2, the shuffled table scored **0.280** versus **0.243** empirical; at the registered 0.5, empirical scored **0.298** versus **0.151** shuffled. This limits any claim that local co-occurrence solved prediction. It indicates some ordered predictive information in the learned code, but an independent one-step local transition table cannot turn it into a reliable future event map. It does not prove the state lacks sufficient information, since this is not an optimal decoder.

The next decisive diagnostic should hold the learned sensory/transition code **fixed** and fit an evaluation-only sparse linear future-event decoder over the same local source field. That is a capacity ceiling, not an M1A learning mechanism: it may use a nonlocal solver offline, but its result must never enter the circuit. If this ceiling is high, redesign local credit/readout and compare it against the ceiling. If low, add genuinely persistent temporal/context state before another plasticity variant. Do not promote the current circuit or fixed correlation into production M1A.
