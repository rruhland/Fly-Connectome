# Online local prediction from history-gated units

The unlabeled history-gated code distinguished matched opposite motions and transferred a frozen direction probe to 47/48 unseen-shape cases. This opt-in experiment asks whether those units can now **learn a future camera event**, using only local delayed event error and active synapses. It does not use the post-hoc probe or any offline decoder for training. There is no backpropagation, direction target, object label, or Pong-specific code.

Freeze the learned and random eight-unit history dictionaries from the previous experiment. Give each a separate zero-initialized 5×5 local ON/OFF event-emission bank. On each frame, credit the previous active history-unit sources with the difference between the observed event map and their prior emitted prediction, using the existing local update rule with one pass through the same 96 clean plus 32 generic interruption/noise episodes. Keep the archived 24-unit coincidence predictor intact and combine its forecast with each context bank by a fixed pixelwise maximum. Compare the learned dictionary, random dictionary, and the learned model with history trace reset immediately before t=10.

Report training and held-out next-event F1 for ordinary motion and the five robust families; score t=10→11 reappearance separately for training interruptions and unseen-shape disappearance cases. Report quiet-target false alarms and matched opposite-motion forecasts after identical current input. Threshold remains 0.5.

The primary gate is at least 0.10 absolute F1 advantage on held-out exact reappearance over **both** random dictionary and trace-reset controls, with non-identical useful forecasts for the matched pair. Clean held-out F1 should remain within 0.03 of the archived predictor, and quiet false alarms below twice its count. If only the frozen representation transfers but the local event readout fails, treat the learning objective/credit as the next bottleneck; do not sweep learning rates or thresholds. Do not promote this opt-in experiment to production without a separate architecture review.
