# Online local event prediction with sensory-sign-conditioned history units

The frozen learned history code crossed with **currently observed raw ON/OFF polarity** supported 0.923 future-event F1 on 144 held-out generic interruptions; history-unit identity alone supported zero. That offline decoder was a capacity bound. This opt-in experiment tests whether the same two locally observable variables can drive online local plasticity without importing any offline weights, gradients, direction labels, object labels, or Pong semantics.

Keep the 24-unit learned motion population, eight-unit locally learned history population, trace dynamics, 5×5 emission field, zero-initialized weights, learning rate 0.5, single pass of 96 clean plus 32 interruption/noise episodes, delayed local event-error update, and threshold 0.5. At each active history source, index a separate emission bank for raw ON versus raw OFF at that site. The original eight-unit unsplit emitter, a 16-bank polarity-split emitter over a random history dictionary, a trace-reset copy of the learned split emitter, and the archived coincidence predictor are matched controls. Combine context and archived forecasts with the same fixed pixelwise maximum.

Score the training interruption transition, unseen ordinary single patterns, five robust families, quiet-target false alarms, the 144-case unseen-shape/all-direction/all-position interruption suite, and the matched opposite-motion pair. Report true/false positives and F1 by direction. The readout must achieve at least 0.40 F1 overall on the 144 cases, at least 0.10 absolute F1 over both unsplit and random controls, nonzero true positives in all four directions, clean held-out F1 within 0.03 of archived, and quiet false alarms below twice archived to count as a viable online candidate. A smaller gain is promising but not promotable. If it underfits even training interruptions, the next separate experiment may add a balanced generic interruption exposure budget for all controls; do not change the threshold or learning rate in this run.

Only after an online candidate passes broad transfer and control gates should a concrete production revision be prepared for user approval. This experiment changes no in-place M1A architecture.
