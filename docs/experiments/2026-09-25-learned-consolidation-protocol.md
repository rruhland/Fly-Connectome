# Learned directional consolidation of local motion hypotheses

**Status:** Bounded opt-in M1A architecture experiment. The prior path-bank test proved a correct trajectory can survive, but only an oracle scorer chose it from four alternatives per mover. This experiment asks whether *local learned sensory dynamics* can drive that choice without object labels or a fixed direction bank. Production architecture and measured graph stay unchanged.

The same frozen observed sensory code and candidate stream are used. On 64 generic unlabeled episodes, a local Hebbian trace associates each candidate's feature with the displacement of a nearby same-polarity candidate at the next meaningful event, giving every feature a learned displacement expectation. No direction, speed, object, or game target is supplied. At inference, a short causal hypothesis bank scores each continuation by spatial proximity, generic smoothness, and agreement with that locally learned expectation. Similar co-moving paths compete; only the highest-scoring explanation survives within a local neighborhood. Compare an aligned learned expectation, a zero-expectation fixed control, and a time-shuffled expectation, all with identical candidate extraction, path capacity, and consolidation.

Score the model's *selected output tracks* on the registered position, speed, shape, separated, and crossing scenes, with synthetic object paths used only after inference for evaluation. Report direction accuracy over all objects, matched coverage, number of emitted tracks, and unmatched-track false discoveries. The learned arm must improve speed-two and multi-entity results over both controls and approach one emitted assembly per separated mover to count as an architecture foothold. If it does not, stop this family rather than tuning path width, spatial radius, or score scales. A passing generic result still requires a separate native-stream and online-latency audit before any production proposal.
