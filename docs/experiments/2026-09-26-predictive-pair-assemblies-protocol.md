# Predictive-pair assembly identity

**Status:** Registered opt-in M1A experiment. Earlier slow assemblies learned their identity by reconstructing the current fast field, then received a future-error update only in their recurrent weights. They transferred motion poorly. This test asks whether delayed local evidence about the *next* fast field can shape slow unit identity itself. Production code and measured connectome are unchanged.

Keep the same frozen, locally trained fast field and 64 unlabeled generic training scenes. A shared slow unit sees a 7×7 patch of present and preceding fast activity and predicts an 11×11 patch of the **positive residual** of the next fast activity beyond the frozen fast forecast. At each active local site, units compete using a score from present input and delayed future residual. The winner updates only its own input and output templates by a bounded local moving average. At inference, selection uses present input alone; the future input is never available to the model. Sparse spatial competition and decaying state are retained. There is no gradient tape, label, object region, direction, speed, reward, or Pong-specific variable in learning or inference.

Matched arms use identical initialization, scenes, winner budget, learning rate, and output decoder: (1) aligned predictive-pair assignment, (2) input-only assignment while learning the same future residual output, and (3) time-shuffled future-residual assignment/target. The fast-only predictor is the baseline. No recurrent transition is trained in this test: the issue under study is whether unit identity gains predictive specialization; prior recurrence could confound that result. If the identity result is positive, locally learned recurrence is a separate next step.

Run once against the existing held-out generic, doubled-speed, changed-shape, separated-mover, and crossing-mover scenes. Report full-frame next-meaningful-event top-8/top-32 recall and precision, paired-case wins, the fixed offline 3×3 spatial direction probe, and assembly activity/components outside offline object neighborhoods. The offline object coordinates are used only for evaluation. Do not tune on these sets. A compelling result needs aligned pairs to beat both controls on speed and shape transfer, preserve the fast-only top-32 recall within three points on each, and improve the spatial direction probe over input-only without a crossing collapse. Otherwise reject this identity rule and move to a substantially different representation, rather than sweep local variants.
