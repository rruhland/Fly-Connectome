# Causal recurrent-inference probe result

The opt-in feedback rule made the current latent winner depend on the previous latent forecast. The focused test verified that a prior event can change the next local assignment without access to a future observation. Training, sensory homeostasis, local predictive-error update, and held-out scenes matched the saved zero-feedback probe.

Feedback improved held-out next-event F1 from **0.147 to 0.218** and direct next-latent F1 from **0.045 to 0.157**, but missed the prespecified +0.10 event-F1 gate and remained far below the fixed low-level correlation control (**0.977**). The full-state direction probe scored **39/48**, while the matched time-shuffled recurrent control scored **41/48**. The recurrent state therefore did not show a specific learned temporal advantage. The one-pixel/frame latent forecast was only **0.030 F1**, versus **0.234** at two pixels/frame. A post-result threshold check peaked at event F1 **0.257** and latent F1 **0.257**, so output scale is not the main explanation. Training-set event F1 remained **0.313**.

This bounded change helps some local predictions but does not solve the conflicting temporal-context problem. Further gain/rate sweeps are not justified. The next distinct hypothesis is a learned local **transition population**: competitive units bind current sensory code with nearby prior code, then local predictive-error synapses learn which future code follows. Different tempos and visual contexts can occupy different learned units instead of forcing one scalar recurrent efficacy to satisfy them all. No direction channels or game semantics should be assigned. That hypothesis remains experimental; no production M1A code changed.
