# Learned local event credibility from paired visual evidence

**Status:** Completed opt-in architectural experiment; see [findings](2026-09-26-learned-observation-model-findings.md). The [distributed transition field](2026-09-26-distributed-predictive-field-findings.md) learned clean futures but admitted noisy events into persistent state. Production M1A is unchanged.

Train an independent shared local observation kernel on the original 64 unlabeled generic camera streams with synthetic event dropout/false events. Its input is the current raw signed event neighborhood and its own fast/slow filtered-event and signed-contrast history. Its target is the signed visual change independently available by differencing successive absolute camera observations from the same training stream. The local credit is observed change minus predicted event credibility times the local input patch. This is sensory self-supervision, not an object/motion label, future evaluation target, reward, or backpropagation. During evaluation, the observer receives only raw events plus occasional absolute visual evidence every eight frames; the clean future event is withheld for scoring. Its continuous credibility weights raw events before they enter a frozen locally learned distributed predictive field. No hand-selected hard event gate or entity slots are used.

Fit the distributed transition field once on the same 64 clean unlabeled streams. Compare (1) learned observer with aligned sparse intensity, (2) learned observer event-only, (3) learned observer with unrelated-scene intensity, (4) observer trained with time-shuffled paired-visual credit, and (5) the original raw-input field. Evaluate the same four clean/corrupted held-out generic scenes and stationary noisy scene. Score current-event reliability on raw event sites, full-frame future top-8/top-32 recall, and false visual/forecast mass. Keep training corruption and all local rates fixed across arms and do not tune after held-out evaluation.

**Decision:** This observer is useful only if it improves corrupted future-event recall beyond the graded-file .331 benchmark without losing clean future-event recall below the raw distributed field's .681, and beats shuffled observation credit. If event credibility improves but future prediction does not, stop this front-end pipeline rather than optimize a narrow gate. Any production promotion still requires broader transfer and user review.
