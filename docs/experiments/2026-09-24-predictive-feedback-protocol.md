# Frozen local predictive-feedback check

The learned correlation-input latent predicts future low-level primitive activity, but its prediction does not influence its next inferred state. Test a single opt-in frozen feedback interpretation: at each camera frame, combine the observed primitive with 0.5 times the prior predicted primitive wherever that prediction reached the existing 0.5 activity threshold, then run the same trained transition dictionary and local predictor. New observed input wins by elementwise maximum. There are no new edges, learned parameters, labels, or weight updates; the feedback is a diagnostic of whether already-learned prediction can sustain local state. Reset between scenes.

Retrain the 96-episode learner from the archived seed and verify the no-feedback arm reproduces its original 0.669 held-out event F1 exactly. Compare no-feedback and feedback on the original held-out scenes and frozen robustness suite, with particular attention to disappearance, sensor noise, crossings, and the previously strong independent-mover and speed-change families. Compare the fixed correlation control. Report event F1 at threshold 0.5 and whether latent activity persists during absent observed primitives. Meaningful improvement requires at least +0.05 F1 on disappearance or noise, no more than 0.03 F1 loss on independent movers or speed changes, and no obvious self-sustained false alarms. A failure argues for a separately gated or plastic recurrent state rather than simple self-feedback. Production M1A stays unchanged.
