# The current recurrent latent is not a reusable M1A world-state

**Status:** One-shot, opt-in frozen representation audit under the [registered protocol](2026-09-25-decisive-representation-audit-protocol.md). Production architecture and measured graph weights remain unchanged. The learned visual encoder/recurrent transition used local, no-backprop training on 64 generic fractional-motion scenes. The offline direction probe alone used labels. T4/T5 features were paired responses to the *same* event-camera streams from the frozen measured-connectome graph under the previously approved Tm4 supplement and T5 order-current dynamics; they are simulated spikes, not biological recordings.

One nearest-centroid probe was calibrated on 16 single-square scenes spanning all four directions, two positions, dark/bright contrast, and one-pixel/frame speed. It was frozen for held-out positions, two-pixel/frame speed, a held-out plus shape, separated pairs, and crossing pairs. Every input was the full 32×64 event stream. Object path regions were used only for offline feature extraction and scoring, so these are **oracle-localized capacity** results, not autonomous discovery or tracking. The paths are symmetric around each object's center and do not encode its direction. A fixed event-correlation code checked task decodability; sixteen training-label permutations controlled the frozen hidden decoder.

All modalities had nonzero activity in every case. The hidden state's four speed-transfer errors were horizontal: left 2/4 and right 2/4, while up and down were 4/4; dark and bright each scored 6/8. Shuffled-label hidden centroids averaged .344 position, .320 speed, and .344 separated-mover accuracy. Thus the aligned hidden state contains real motion information, but its recurrence *degrades* a perfectly decodable observed code at a simple speed change. The T4/T5 add-on does not repair that loss. Total T4 rate across all 84 object samples was only 0.262 versus 126.392 for T5, consistent with the prior ON-pathway silence. Crossing remains unresolved even with oracle regions for every learned or measured-graph feature; the fixed primitive retained direction information there.

**Hard recommendation: abandon the current per-site recurrent latent family as the M1A world-state.** It missed the preregistered 80% speed-transfer gate (75%), and prior four-frame forecast tests show poor native transfer even when local support is high. The observed dictionary's perfect scores on this small oracle-localized suite make it worth retaining only as a *sensory primitive/control*, not as proof of reusable entity state. The oracle regions and small sample counts make this an upper bound; they strengthen rather than weaken the decision not to promote the recurrent state. T4/T5 simulated spikes should remain a complementary measured-graph cue, not a replacement for a learned motion representation.

The next architecture proposal should replace per-site lag-stack/recurrent winners with **sparse local motion assemblies**: locally plastic groups that bind nearby sensory responses through temporal continuity, compete for overlapping evidence, preserve an assembly through quiet frames, and learn local transition/prediction from their own activity. Assembly membership and motion identity must emerge from event evidence; no Pong object labels, fixed feature bank as the final representation, or backpropagation. An approval-worthy production revision would first show frozen assembly transfer across positions, speeds, directions, contrast, separated and crossing entities *without oracle object regions*, then improve event prediction and quiet-frame specificity on generic and native streams. No further narrow tuning of the current latent or forecast head is recommended.
