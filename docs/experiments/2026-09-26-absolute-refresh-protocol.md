# Periodic absolute visual evidence versus event-only uncertainty

**Status:** Registered opt-in sensory-architecture experiment after the [predictive-file evidence result](2026-09-26-predictive-file-evidence-findings.md). This changes the *available observation*, not a gate threshold. A binary camera frame or sustained photoreceptor contrast is a generic visual signal; it carries information an event-only stream loses when a one-time false event is indistinguishable from a genuine static mark. Production M1A and measured topology remain unchanged.

Use the original 64 unlabeled generic streams for all fast-field and affinity learning. On held-out clean and corrupted generic streams, compare ordinary event-only files with files that receive a signed absolute-contrast refresh every eight camera frames and an every-frame refresh ceiling. The evaluator derives each absolute contrast frame from the **uncorrupted camera observation stream**, never from object identity, mask, count, trajectory, or game state; under corruption it is an independent simulated intensity observation, not information available to the event-only arm. A refresh replaces the local contrast estimate and removes a file only if its signed local support has no corresponding observed contrast in a small neighborhood. All arms still update displacement only from observed events. Score autonomous live-file count, births, and full-frame signed next-event top-8/top-32 recall against the clean next event. Include the stationary noisy case and four held-out moving generic scenes; use identical corrupted input for all arms. A clean-stream run checks that refresh does not erase genuine moving files.

**Decision rule:** Occasional refresh is justified as a sensory requirement only if it markedly reduces false live files and births in corrupted scenes without losing clean count or forecast. If only every-frame refresh works, or the refresh merely hides rather than corrects state, report that limit. Do not tune the eight-frame interval, support radius, or noise rates on held-out results. This experiment cannot by itself solve Pong event-time prediction or establish a final learned latent.
