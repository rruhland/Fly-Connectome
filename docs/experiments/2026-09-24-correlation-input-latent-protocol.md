# Learned local latent over motion-sensitive sensory primitives

The prior event-site transition code could read direction but failed to predict even with fourfold exposure. Test a substantially different opt-in state while keeping prediction local and unlabeled: compute fixed, retinotopic same-polarity previous/current event coincidences at the existing eight one- and two-pixel offsets. These 16 maps are **sensory input primitives**, not final motion channels or supervised targets. A 24-unit competitive local dictionary learns 5×5 current/previous primitive neighborhoods from diverse square/plus/L/bar sequences. The same local predictive-error synapses learn to forecast the next primitive image. Decode that forecast into a future ON/OFF event image by summing predicted primitive evidence per polarity. No direction, speed, shape, or object label enters any update.

Use the same 96-episode training corpus and 48 new-shape held-out cases from the equal-budget experiment. Compare a matched random dictionary with locally trained predictive synapses, and a learned dictionary whose predictive targets are time-shuffled. Evaluate next-event F1 at 0.5 by speed and shape, next-primitive F1, and a frozen-code offline local linear future-event decoder as a capacity diagnostic. Keep the fixed event-correlation forecaster as an explicit control. All models see the same events and target horizon. The offline decoder is not part of M1A learning.

Meaningful evidence for this state requires learned local event F1 at least 0.50 and at least 0.15 above both random-dictionary and shuffled-target controls at each speed. The offline decoder should reach at least 0.70 held-out event F1 and beat a random-code decoder by 0.10 before the state is considered sufficiently reusable. If capacity is high but local F1 low, revise local credit/readout. If capacity is low, change the state mechanism again. No production architecture promotion follows directly from this probe.
