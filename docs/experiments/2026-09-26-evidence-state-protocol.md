# Bounded evidence-state comparison

Opt-in experiments only; no production architecture change. Registered before
candidate evaluation. Preserve the event-only observer and the clean learned
context association. Neither simulator labels nor future observations enter the
state. No gradients/backpropagation.

Compare two different observation representations with a common bounded
association mechanism:

1. **Weighted event density:** local weighted centers instead of binary dilated
   components, which can join distant evidence through noise.
2. **Reconstructed surface:** connected contrast regions that contain current
   changes. This asks whether persistent appearance is a better association
   substrate than event clusters. It may fail from event-integration drift.

Each uses delayed confirmation of births and a four-hypothesis local association
beam with a missed-observation branch. Position/velocity remain engineered
control variables, not a claim of discovered latent structure. The previous
above/below context rule remains an explicitly specialized learning diagnostic.
The beam is an approximate local association, not a globally normalized Bayesian
multi-object posterior; output strengths are not calibrated probabilities.

Freeze one configuration per representation. Run aligned, shuffled-context and
unlearned controls with the same event-only teacher and training scenes. Score
the existing clean/noisy/heavy-noisy, constant, two-mover and disappearance gates
without changing thresholds. Report runtime. Unit tests check delayed birth,
causal continuation through missing evidence, separation of two streams and
state reset. Actual implementation errors may be repaired; failed scientific
gates do not license threshold sweeps.

If neither passes, reject this batch rather than extending the beam or tuning
cutoffs. Reassess the specialized context benchmark and the observer/state
interface before another learning mechanism. Even a pass requires broader
rotation/dynamics transfer, identity scoring, uncertainty calibration, measured
connectome ablation and a separate forecast test before M1A.5 acceptance.
