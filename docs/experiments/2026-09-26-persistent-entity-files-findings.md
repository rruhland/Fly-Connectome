# Persistent entity files learn clean local forecasts, but fragment under clutter

**Status:** Completed opt-in experiment under the [registered protocol](2026-09-26-persistent-entity-files-protocol.md). No production M1A code, measured connectome topology, or transmitter signs changed. The implementation uses no backpropagation, object labels, oracle crops, or Pong semantics at inference. Its connected signed-surface regions are fixed sensory *proposals*; persistent hypotheses supply the model state and forecast. The [raw results](2026-09-26-persistent-entity-files-results.json) contain per-case counts and all evaluated arms.

The aligned model learned a useful within-episode displacement state from its own matched visual observations. That made its next-meaningful-event forecast substantially better than shuffled or frozen local credit on controlled motion, including speed and shape changes and two moving entities. It did **not** establish a reusable M1A representation: generic held-out prediction remained below the trained fast-only field, and live hypotheses overfragmented in clutter and noise.

| Evaluation set | Fast-only top-32 recall | Aligned files | Shuffled credit | Frozen displacement |
| --- | ---: | ---: | ---: | ---: |
| Generic held-out (16) | **.360** | .273 | .267 | .004 |
| Calibration (16) | .588 | **.789** | .684 | .000 |
| Changed position (16) | .588 | **.789** | .684 | .000 |
| Changed speed (16) | .480 | **.857** | .743 | .000 |
| Changed shape (16) | .542 | **.843** | .730 | .000 |
| Two separated entities (8) | .312 | **.789** | .254 | .000 |
| Two crossing entities (2) | .354 | **.823** | .125 | .125 |

These are full-frame ON/OFF next-event rankings, not position or direction targets supplied to the learner. Aligned top-32 hits beat both fast-only and shuffled on every changed-speed (16/16), changed-shape (16/16), separated (8/8), and crossing (2/2) case. On generic held-out streams, aligned beat fast-only on only 6/16 and shuffled on 7/16. Its generic top-8 recall was .246 versus fast-only .171, but its top-32 recall was lower (.273 versus .360): some strong local peaks did not cover enough of the next event. The fast-only comparator had learned from 64 unlabeled generic streams; the entity files had **no shared long-term training** and learned displacement only online within each evaluation episode. Thus the clean advantage demonstrates local online adaptation, not cross-episode representation learning.

On clean controlled streams, aligned files maintained the expected count on every active frame. They localized all 144 single-entity observations in each transfer group, all 144 separated-entity observations, and all 36 crossing observations. Direction decoded from file histories was 16/16 for changed speed and shape, 16/16 for separated entities, and 4/4 for crossings. Yet frozen and shuffled arms also had exact counts and most of the localization on these easy streams. The fixed `VisualContinuity` comparator kept exact counts and **zero** identity-switch frames in clean crossings, while aligned files had **four** switch frames across the two crossing scenes. Clean counts therefore reflect easy surface geometry, not learned entity discovery. A different-shape crossing stress case favored aligned count continuity (13/13 frames versus shuffled 2/13 and frozen 8/13), but does not erase the clean identity switches.

The more representative failure is hypothesis birth under clutter. Across generic held-out active frames with two expected visual regions, the model averaged **2.46** live files and had the wrong count in **213/447** frames (47.7%). With three expected regions, it averaged **3.80** files and had the wrong count in **190/304** frames (62.5%). The expected counts derive from the synthetic scene generator's moving motifs plus optional static mark; occasional overlap makes this an approximate region-count audit. No active frame had zero files, so overbirth/fragmentation is a more plausible problem than absent state. In the registered static-noisy stream, all three entity arms had the wrong count on **13/13** active frames and ended with **five** files for one intended entity. The fixed local confidence surface did not reject sustained accidental false structure.

**Decision:** Keep the opt-in entity-file experiment as evidence that a local, online state can improve controlled forecasts, but do **not** promote this implementation to production M1A. The protocol's autonomous noisy-identity and generic-transfer criteria failed. The next substantial experiment should learn when local visual evidence confirms an existing hypothesis or warrants a new one, using generic streams and a local predictive-error/reliability signal. Compare aligned learning with fixed and shuffled credit on generic held-out clutter and crossing identity, while keeping the clean forecast gains. This targets the observed overbirth directly; tuning association radius or confidence thresholds on these held-out scenes would not establish transferable learning. The lower-level fast motion field may provide independent local evidence, but must remain a sensory primitive rather than a hardcoded final representation.

Reproduce with `.venv/Scripts/python scripts/run_persistent_entity_files.py`. One run, including training the fast-only baseline and the aggregate state audit, took about 36 seconds on this machine.
