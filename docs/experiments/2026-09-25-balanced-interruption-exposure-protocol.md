# Balanced interruption exposure for online local event learning

The first online polarity-conditioned history readout reached 0.289 exact future-event F1 on 144 unseen interruptions versus 0.088 for a random dictionary, but its training corpus contained only 16 interrupted episodes and the down direction reached 0.022 F1. An offline local capacity bound on the same source type reached 0.923 held-out F1. This opt-in experiment asks whether **coverage of generic interrupted motion**, rather than another architecture or parameter change, accounts for much of that gap.

Start from the same 128 episodes as the first online run. Append exactly 64 generic interrupted episodes: four training shapes, four directions, two speeds, and both backgrounds at the training center. Train the learned history dictionary and each online readout using the same 192 episodes and original pass counts/order seed. Retain eight history units, the raw ON/OFF-conditioned emission bank, zero initial weights, 5×5 field, learning rate 0.5, delayed one-frame local event error, 0.5 scoring threshold, and fixed pixelwise maximum with the archived predictor. Keep the unsplit learned-dictionary, split random-dictionary, trace-reset, and archived controls. No direction or object labels enter training.

Report exact t=10→11 F1 and true positives on the added training interruptions and the same 144 unseen-shape/all-direction/all-position cases, including each direction. Also report ordinary unseen single-pattern F1 and quiet-target false alarms on the same held-out suite. Compare with the archived 128-episode result. Treat the candidate as viable only if it reaches at least 0.40 exact held-out F1, exceeds both unsplit and random controls by 0.10, produces true positives in every direction, keeps clean F1 within 0.03 of archived, and produces fewer than twice the archived quiet false alarms. If added exposure fails to clear these gates, do not grow a narrow data or hyperparameter sweep; investigate the local objective/eligibility or temporal credit instead. This run changes no production M1A architecture.
