# One online local-error transition test

The event-only Pong tracker supports free-flight forecasting but its observed constant-velocity error rises around wall reversals. Test one small, opt-in transition rule on top of those event-derived observations. At each issue frame, estimate velocity from the current centroid and its value eight frames earlier. Extrapolate 16 or 32 frames. If the extrapolation crosses the top or bottom image boundary, form one local reflection feature equal to twice the distance beyond that boundary. Predict vertical position as `linear position + g × reflection feature`. Initialize `g=0` (ordinary constant velocity), then update the single nonnegative gain by a normalized local delta rule when the future event-derived centroid is observed. The update uses the issued feature and visual prediction error only; no simulator state, labels, reward, or backpropagation enter learning. Discard targets with a visual x jump larger than .3 as apparent rally resets, using observations alone. Keep a separate gain per forecast horizon.

Train chronologically on Pong seeds 0–7 for 800 frames each, then freeze gains and score seeds 8–15. Report update counts, learned gains, and held-out Euclidean/y errors for ordinary observed constant velocity, learned reflection, and a fixed unit-reflection comparator. Score same-rally free-flight, wall-reversal, and paddle-reversal samples separately; privileged rally/velocity information is for scoring only. A useful local rule must reduce held-out wall-reversal error without materially degrading free-flight error. If it fails, stop this rule rather than tune a series of rates or boundary windows. This is an experiment, not a production world-model revision.
