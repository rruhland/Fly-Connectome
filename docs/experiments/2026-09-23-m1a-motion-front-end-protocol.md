# M1A motion-front-end comparison

This opt-in experiment asks whether the frozen connectome-derived motion stage supplies a usable direction signal beyond its previously successful vertical OFF bar slice. It does not train weights or change production code. Compare three readouts on the **same event-camera sequences**: (1) T5c/d spikes from the previously calibrated 50 ms Tm4 supplement and local T5 order current, (2) native T4a–d and T5a/b spikes in that same network, and (3) a nonlearning event-state centroid tracker as an engineered ceiling. The tracker reconstructs the binary scene only from ON/OFF events; it never reads simulator coordinates.

Keep the pinned checkpoint, measured graph, existing signs/delays, eight neural ticks per frame, Tm4/Tm9 rest .85, Tm9 cap .10, Tm4 cap .10, 50 ms Tm4 release baseline, order gain 8,000 and cap 1.0 fixed. Calibrate all blank-dependent circuit state before capturing trials; restore the identical settled state before every trial. Verify long-term magnitudes remain bitwise fixed. Use the existing 18-frame 3×13-pixel moving bar and its static/blank controls, with polarity inversion for ON bars. The camera starts at the appropriate uniform background.

Use vertical OFF y=10/22, speed 1 only to set one fixed T5c/d opponent-score threshold. Evaluate vertical OFF at y=14/18, speeds 1 and 2; horizontal OFF at x=32, speeds 1 and 2; vertical ON at y=16, speed 1; and horizontal ON at x=32, speed 1. Both directions are run for each moving condition. Include a matched static bar for each axis/polarity and one blank trial per polarity. For each position/speed/polarity, report T4/T5 subtype spike contrasts, active-cell majorities, and moving/static counts; for the vertical OFF holdouts, report single-trial T5 opponent direction accuracy using only the fixed calibration threshold. Report the event tracker’s estimated displacement and direction on exactly these trials.

This is a diagnostic comparison rather than a universal benchmark. The vertical OFF circuit has previously seen the stimulus family, and the event tracker has an idealized uniform background and one connected object. A useful result is a frozen T5 signal that separates direction on both unseen y positions and both speeds while blank/static controls remain distinguishable. If horizontal or ON responses lack stable subtype tuning, stop trying narrow gain sweeps and prioritize a small shared event-correlation motion bridge for the next opt-in test. If the raw event tracker is substantially more reliable, use it as a state-estimation ceiling while testing whether connectome-derived signals add robustness under more realistic Pong occlusion and clutter.

## Post-hoc horizontal transfer extension

The initial x=32 horizontal OFF pair produced a substantial T5c/d opponent difference even though the earlier T5a/b horizontal calibration failed. Before interpreting that as an axis-general feature, run the same fixed network and stimuli at x=18 and x=46, speed 1, with identical static controls. These are explicitly exploratory follow-up cases, not part of the original screen. Keep the initial result file separate, and score whether subtype contrast signs and a single x=32-calibrated opponent threshold survive both additional positions. A position-specific sign reversal ends this branch.
