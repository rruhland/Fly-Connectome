# Generic event occupancy and grouping baseline

Test a **diagnostic**, nonlearning coherent-entity baseline on event-camera scenes without object identities at inference. Integrate ON minus OFF at each pixel into a persistent signed contrast field. Group nonzero occupancy by four-neighbor connectivity. Link components across frames using nearest predicted location from each group's observed history; when two groups merge visually into one component, retain both uncertain tracks through the ambiguous frame and test whether they recover after separation. This is a generic engineering ceiling, not a proposed biological mechanism or production M1A change.

Evaluate single moving shapes at both contrast polarities, a stationary shape that emits no continuing events, and two identical same-polarity shapes that cross. Repeat the stationary case with 10% event dropout and independent 0.1% false events per polarity/pixel/frame. Hidden generator paths are used only to score group count, center error, and identity preservation. Compare occupancy grouping with components formed directly from the instantaneous event map. Record failures rather than adding scene-specific rules.
